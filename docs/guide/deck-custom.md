# 自定义牌堆

本页面向骰主，介绍如何创建与维护自定义牌堆，包括文件格式、条目语法、图片条目、重载与排错。本插件不内置任何牌堆，所有牌堆都需要按本页创建或导入；也可以使用社区制作的 Dice! JSON 牌堆，使用前请自行确认授权。玩家使用牌堆命令的说明见[牌堆与随机表](./decks.md)。

## 创建牌堆文件

把 Dice! 格式的 JSON 文件放进插件数据目录的 `decks` 文件夹。按 localstore 的默认数据目录，它在宿主的 `data/nonebot_plugin_dnddicer/decks/`；宿主改过数据目录时以实际路径为准。

文件要求：

- 只读取 `.json`，编码 UTF-8（可带 BOM）；
- 顶层是 JSON 对象，键为牌组名、值为字符串数组；一个文件可以放多个牌组；
- 单文件不超过 1 MB，最多 200 个牌组；单个牌组最多 500 条，单条最多 1000 字，牌组名最多 40 字；
- 放好或修改文件后，由骰主私聊执行 `.draw 重载`。

完整示例：

```json
{
  "_title": "示例牌堆",
  "_author": "牌堆作者",
  "_version": "1.0",
  "_license": "MIT",
  "_source": "自制",
  "_brief": "示例牌堆的简介",
  "示例牌组": [
    "普通条目",
    "::2::权重为 2 的条目",
    "引用子牌组：{子牌组}",
    "内联掷骰：[2d6]",
    "带图片：\n[img:images/example/card.png]"
  ],
  "_子牌组": [
    "只在被引用时出现的内容"
  ]
}
```

`_title`、`_author`、`_version`、`_license`、`_source`、`_brief` 会在 `.draw 详情` 里显示。`_export`（或 `_keys`）可以只让列出的牌组出现在列表与搜索里，其余牌组隐藏但仍可被引用；以 `_` 开头的牌组始终隐藏，只能被其他条目引用。

## 条目语法

- `::N::` 是相对概率权重，不是数量。同一牌组里 A 写 `::1::`、B 写 `::3::`，B 被抽中的概率是 A 的 3 倍；省略或写 `::0::` 都按 1。权重超过 1000 按 1000 处理。
- 不放回模式下，带权条目仍然只算一条：抽中后整个条目移出本次池子，权重只影响它被抽中的概率与先后，不会变成多份。
- `{牌组名}` 嵌套抽取一个未抽过的条目（不放回）；`{%牌组名}` 每次独立抽取（放回）。嵌套不放回池抽空时会自动重洗；顶层默认不放回，抽空即停止。
- `[表达式]` 用骰娘掷骰引擎求值，替换为 `表达式=数值`，例如 `[2d6]` 会变成 `2D6=数值` 的形式。
- `_` 开头的牌组是隐藏牌组，不出现在列表与搜索里，只能被其他条目引用。
- `列表` / `搜索` / `详情` / `重载` 是管理子命令保留词，不能作为可见牌组名。
- 同一文件或不同文件内牌组名重复时，后加载的生效并记日志警告。

嵌套最多 8 层、单次展开最多 100 次；循环引用输出 `【循环引用：名称】`。

## 图片条目

条目可以同时包含文字与图片，也可以只有图片。图片用 `[img:images/相对路径]` 标记，按出现顺序发送。路径相对于 `decks/images/`：`decks/images/example/card.png` 写作 `[img:images/example/card.png]`。

```json
"示例牌堆": [
  "第一条：篝火旁传来的旧传闻\n[img:images/example/card.png]"
]
```

纯图片牌堆只写图片标记，例如塔罗牌：

```json
"塔罗牌": [
  "[img:images/tarot/00_fool.png]"
]
```

- 支持 PNG、JPG、JPEG、WebP，按文件内容判断格式，不看扩展名；单张不超过 4 MB，单次抽取总计不超过 8 MB。
- 一条最多 5 张图片，一次抽取最多 10 张；超出的改为占位文字。
- 只允许 `images/` 下的相对路径；禁止绝对路径、`..`、反斜杠、`~`、URL、base64 与 CQ 码，不跟随符号链接。
- 图片缺失或无法读取时，在对应位置输出 `【图片缺失：文件名】` 或 `【图片无法读取：文件名】`，记日志，不中断整次抽取。
- 含图片的多条结果会逐条发送，避免一条消息塞入多张大图；纯文字结果仍合并发送。

## 内容与版权

本插件不内置任何牌堆，`decks/` 下的 JSON 与图片都由骰主自行提供。请只使用你有权使用的文本与图片。

## 常见问题

**为什么没有内置牌堆？**

本插件不分发规则书或第三方站点的译文。牌堆内容由骰主自行准备，或使用你有权使用的牌堆文件；插件只负责读取和抽取。

**修改了 JSON 但骰娘没反应？**

请骰主私聊执行 `.draw 重载`，或重启宿主机器人。重载会给出每个文件的错误摘要；写错的文件只会被跳过，不影响其他牌堆。

**图片不显示？**

确认图片放在 `decks/images/` 下、路径与 `[img:...]` 一致，格式是 PNG、JPG 或 WebP，且单张不超过 4 MB。看到 `【图片缺失：文件名】` 多为路径不对或文件不存在，`【图片无法读取：文件名】` 多为格式或体积不合要求。

**支持 CQ 图片或网络图片吗？**

不支持。只认本地 `images/` 下的相对路径；CQ 码会被清洗为普通文字，不会发图。

**为什么牌堆列表里看不到某个牌组？**

名称以 `_` 开头的牌组是隐藏牌组，只能被其他条目引用；用 `_export` 或 `_keys` 限定可见范围时，未列出的牌组也会隐藏。牌组名与 `列表` / `搜索` / `详情` / `重载` 重名会被拒绝加载。
