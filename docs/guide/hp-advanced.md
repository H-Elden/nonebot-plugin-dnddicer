# HP 进阶与长休

本页面向**已经登记过角色卡**的玩家：把伤害结算与休整直接接到卡上。`.hp` 的伤害位置可以直接写卡上的武器项（掷伤与扣血一条命令），`.长休` 一键完成长休结算。

命令**仅限群聊**。示例取自示例团在碎星隘口遭遇战中的结算（队伍信息见[示例团与人物](./cast.md)）。

## 用卡上的武器掷伤害（.hp -X伤害）

伤害位置直接写角色卡 `$武器$` 段里的武器名，骰娘用**发送者本人**的角色卡取出该武器，掷出伤害并同时扣血；`副手` / `重击` / `偷袭` 后缀与 `±` 临时加值都支持（如 `-战锤重击伤害+1d4`），不必每次手写算式：

::: chat
阿岩 | .hp 骷髅a易伤 -战锤伤害
屠龙骰 | 布鲁姆用【战锤】造成了 10 点钝击伤害：
骷髅a: 当前HP减少[3]+2=5（易伤加倍→10）
HP:13/13 -> HP:3/13
:::

注：表头报的是**实际结算值**：单目标时按抗性/易伤折算（本例掷出 5 → 造成 10）；一发多目标时报掷出的原始值，折算逐目标在各自行里体现。

武器写法与 `.X伤害` 完全同款（后缀、临时加值、武器管理见[武器与攻击](./weapons.md)）。伤害位置只认「伤害」，写成「攻击 / 命中」会被拦下并引导：

::: chat
阿岩 | .hp 骷髅a易伤 -战锤攻击
屠龙骰 | 「战锤攻击」是攻击检定而非伤害掷骰，请用「战锤伤害」！
阿岩 | .hp 骷髅a -战锤命中
屠龙骰 | 「战锤命中」是攻击检定而非伤害掷骰，请用「战锤伤害」！
:::

DM 代不在场的玩家结算时，把**武器来源**写在尾部括号里（角色名支持模糊匹配、中英文括号皆可，也可以直接 @玩家）；完整代发说明见[血量与伤害结算](./dm-settlement.md)。

## 长休（.长休）

一次长休结算三件事：**HP 回复至上限**、**临时 HP 清零**（有剩余时会提示失效）、**回复一半生命骰**（回复量为总数的一半向下取整、至少 1，且不超过总数）：

::: chat
阿茶 | .长休
屠龙骰 | 薇拉进行了一次长休
生命值回复至上限(54)
回复0个生命骰, 当前拥有5/5个D10生命骰
白鸦 | .长休 @小满
屠龙骰 | 洛恩进行了一次长休
生命值回复至上限(37) 10点临时生命值失效
回复0个生命骰, 当前拥有5/5个D6生命骰
:::

生命骰信息来自卡上的 `$生命骰$`，格式为 `当前/总数 D骰面`：示例团刚建卡、生命骰还是满的（`5/5`），所以显示回复 0 个；若已消耗 3 颗（`2/5 D8`），长休回复 2 颗、变成 `4/5`。

DM 可代不在场的玩家收尾：`.长休 @玩家` 用该玩家的角色卡结算（见[代掷与代操作](./dm-proxy.md)）；无卡时给出真 @ 引导建卡。

## 与角色卡的联动

- `.hp` 改的就是卡里的 `$生命值$` 字段（格式 `当前/最大(临时)`，如 `54/54`、`20/30 (5)`）；`.init` 的 `HP:` 读数与 `.状态` 摘要都从这里取，字段写法见[角色卡与属性](./character-card.md)；
- `.长休` 结算会随卡保存：HP、临时 HP 与 `$生命骰$` 一起更新。

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `.hp [对象] -X伤害` | `.hp 骷髅a易伤 -战锤重击伤害+1d4` | 伤害位置直接写卡上武器项（后缀 / `±` 临时加值同 `.X伤害`） |
| `.长休` | `.长休`、`.长休 @玩家` | 长休结算（HP / 临时 HP / 生命骰） |
| `.武器名伤害` | `.刺剑伤害` | 单独掷伤害、不自动扣血，见[武器与攻击](./weapons.md) |
