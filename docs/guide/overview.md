# 命令总览

屠龙骰是专精 **DND5e / DND5r** 跑团的 [NoneBot2](https://nonebot.dev/) 骰娘插件（OneBot V11 适配器），为 QQ 群跑团提供一站式支持：掷骰表达式、角色卡与检定点命令、武器与攻击、HP 管理、先攻列表与战斗轮、规则查询。

本页是全量速查：先在[功能一览](#功能一览)挑功能、读[名称显示规则](#名称显示规则)与 [@ 提及目标](#提及目标-dm-代操作)了解通用约定，再到[命令总表](#命令总表)查写法；不知从哪下手就按[开始使用](#开始使用)的三步走。

> **版本**：v0.4.2。规则范围：**仅支持 DND5e/5r**。安装与配置见 [快速开始](./quickstart.md)。

## 名称显示规则

全插件的玩家名称显示统一按一条回退链取值，所有需要显示玩家名称的地方（掷骰落款、检定/豁免与武器攻击反馈、`.dnd` 属性生成、HP 相关反馈与列表、先攻入表名等）共用：

**角色名（`$姓名$`）→ 群名片 → QQ 昵称 → 「未知玩家（QQ号）」**

即优先取角色卡上的姓名；没有卡名时取群名片，其次 QQ 昵称；都取不到时显示 `未知玩家（123456789）`，便于定位到具体成员。自己触发的命令取消息自带的名称字段；显示他人名称时才查询群成员信息。

以示例团为例，小满的角色是洛恩，小鹿还没建卡（群名片「小鹿」，QQ 昵称「鹿角」）：

::: chat
小满 | .rd
屠龙骰 | 洛恩 的掷骰结果为 1D20=[7]=7
小鹿 | .rd
屠龙骰 | 小鹿 的掷骰结果为 1D20=[11]=11
:::

先攻列表与 NPC 血量的条目名**不参与**这条回退链：名称由使用者（一般是 DM）在入表时指定、按字面使用，也不会与玩家绑定（`@` 定位不到）。所以没卡的散客入表后，DM 直接用同一个名字结算即可：

::: chat
白鸦 | .ri+1 小鹿
屠龙骰 | 小鹿的先攻值是 1D20+1=[9]+1=10
白鸦 | .hp 小鹿 12/12
屠龙骰 | 小鹿: HP=12/12
当前HP:12/12
白鸦 | .hp 小鹿 -d6+2
屠龙骰 | 小鹿: 当前HP减少[5]+2=7
HP:12/12 -> HP:5/12
:::

## @ 提及目标（DM 代操作）

玩家缺席时，DM 要替他掷骰、结算、推进：多数带目标的命令都支持用 **@群成员**（下文记作 `@玩家`）指定目标，**直连该成员在本群的角色卡**，不受同名 NPC 与角色卡改名的歧义影响；@ 与名称可混写（分隔符 `;` 或空白）。此类写法只在群聊适用。

| 场景 | 写法 |
| --- | --- |
| 代结算 HP | `.hp @玩家 -4d6`、`.hp @玩家;地精 -d4`（AOE 混写）、`.hp @玩家易伤 -d8`、`.hp @玩家`（查看）、`.hp @玩家 @玩家2`（查看多名玩家） |
| 代长休 | `.长休 @玩家` |
| 代掷检定 | `.力量豁免 @玩家`、`.2#隐匿检定优势 @玩家`、`.先攻检定 @玩家`（以该玩家为归属入表） |
| 代掷武器攻击 / 伤害 | `.刺剑攻击 @玩家`、`.刺剑重击伤害 @玩家`（用目标角色卡上的武器项） |
| 代掷先攻 | `.ri+3 @玩家`（条目名取角色卡名并与该玩家绑定，重掷替换、回合提醒与 `.hp` 解析同步生效） |
| 按玩家定位条目 | `.init del @玩家`、`.init first @玩家`、`.init swap @玩家/兽人`、`.回合 @玩家`（改名后仍有效） |
| 查看他人角色卡 / 状态 | `.角色卡 @玩家`（或 `.角色卡 角色名`）、`.状态 @玩家`（**查看**对任何人开放；**记录/清除仅限本人**） |

约定：

- @ 目标需该成员**已在本群建立角色卡**，否则骰娘用 @ 回复并引导建卡（`.角色卡记录`）；
- `@机器人自身` 不作为目标（`@屠龙骰 .hp -d4` 仍按发送者自己结算）；
- 游离 @（未写在正确的目标位置，如 `.hp -4d6 @玩家`、`@玩家 .hp -4d6`）**不执行**并回纠正示例，避免误结算到发送者自己；`.ri` 的提示为「目标请写在表达式右侧」；
- `.ri 3#@玩家` 不支持批量写法（提示直接写条目名称）；`.hp del/clr` 与 `.npc` 是 NPC 专用命令，@ 到玩家会提示不适用（移除玩家先攻条目用 `.init del`）。

@ 能用在哪些命令、在哪些位置生效、游离 @ 如何处理：完整机制见[代掷与代操作](./dm-proxy.md)。

## 命令总表

下表按「基础 → 进阶 → DM → 查询 → 群管理 → 帮助」分组列出全部命令；「场景」列写明可用范围与权限，没有标注权限的命令所有成员都能用。检定点命令（`.力量检定` 等）按消息模式触发，写作规则见[检定与豁免](./checks.md)。

### 基础

| 命令 | 说明 | 场景 |
| --- | --- | --- |
| `.r [N#][hs][表达式] [原因]` | 掷骰表达式（`#` 连掷 1~10、`h` 暗骰、`s` 只显数值） | 群聊 / 私聊 |
| `.rh [表达式] [原因]` | 暗骰：群内只播一句提示，结果私聊掷骰者 | 群聊 / 私聊 |
| `.dnd [次数] [原因]` | 4D6K3 掷点生成六项属性（降序列表，自行分配） | 群聊 / 私聊 |
| `.dndx [次数] [原因]` | 同上，并按固定顺序绑定属性名（不排序，可直接抄入角色卡） | 群聊 / 私聊 |

### 进阶

| 命令 | 说明 | 场景 |
| --- | --- | --- |
| `.角色卡模板` | 查看示例卡与填写提示 | 仅群聊 |
| `.角色卡记录` + 卡面 | 记录 / 覆盖角色卡（卡面照模板写） | 仅群聊 |
| `.角色卡` / `.角色卡清除` | 查看 / 删除角色卡（记录与清除仅限本人） | 仅群聊 |
| `.角色卡 @玩家` / `.角色卡 角色名` | 查看他人整卡（查看对任何人开放） | 仅群聊 |
| `.状态` / `.状态 @玩家` | 查看自己 / 他人的 HP 与生命骰摘要 | 仅群聊 |
| `.xx检定`（属性/技能/先攻） | 如 `.力量检定`、`.2#察觉检定+1` | 仅群聊 |
| `.xx豁免` | 属性豁免检定点命令，如 `.体质豁免+d4`、`.感知豁免优势` | 仅群聊 |
| `.xx检定/豁免 … @玩家` | 表达式右侧加 @ 代掷（用目标角色的属性/熟练/加值） | 仅群聊 |
| `.武器名攻击` / `.武器名命中` | 用卡上该武器的命中加值掷攻击检定（如 `.刺剑攻击优势`、`.2#刺剑攻击+2`、`.刺剑攻击 @玩家`） | 仅群聊 |
| `.武器名伤害` | 掷该武器伤害并报出类型；后缀 `副手`/`重击`/`偷袭` 可组合（如 `.刺剑重击偷袭伤害`），尾部可加 `±` 临时加值（如 `.火球术伤害+1d6`） | 仅群聊 |
| `.设置武器` / `.删除武器` | 维护卡上武器（同名覆盖 / 删除，多个用 `/` 分隔；`.设置武器` 无参数列出） | 仅群聊 |
| `.先攻检定` / `.先攻检定 @玩家` | 掷先攻并自动写入本群先攻列表（@ 形式以该玩家为归属入表） | 仅群聊 |
| `.hp [对象] 20/30 (5)` | 设置自己 / 队友 / NPC 的 HP（含临时 HP） | 仅群聊 |
| `.hp [对象] -10` / `+2d6` | 伤害 / 治疗（支持掷骰表达式与临时 HP；伤害位置可直接写 `-X伤害` 用卡上武器项，括号可指定来源代发） | 仅群聊 |
| `.hp @玩家 …` / `.hp @玩家` | 对 @ 的玩家角色卡结算 / 查看（@ 与名称可混写） | 仅群聊 |
| `.hp` / `.hp list` | 查看自己 / 本群列表（PC 在前、NPC 在后） | 仅群聊 |
| `.hp del 名称` / `.hp clr` | 删除单个 / 清空全部 NPC 血量记录（玩家角色卡请用 `.角色卡清除`） | 仅群聊 |
| `.npc 持久/临时 名称` | NPC 血量跨战斗保持 / 恢复默认（同名 NPC 新入先攻表默认自动回满） | 仅群聊 |
| `.长休` / `.长休 @玩家` | 长休结算（回满 HP、清临时 HP、回复一半生命骰） | 仅群聊 |

| 命令 | 说明 | 场景 |
| --- | --- | --- |
| `.查询法术 <名称>` | 按名称查法术（速查索引；中文名 / 英文名均可，候选带环阶、学派与出处） | 群聊 / 私聊 |
| `.查询怪物 <名称>` | 按名称查怪物（候选带体型、类型与 CR） | 群聊 / 私聊 |
| `.查询物品 <名称>` | 按名称查魔法物品（候选带稀有度与类别） | 群聊 / 私聊 |
| `.查询专长 <名称>` | 按名称查专长（候选带分类与书目） | 群聊 / 私聊 |
| `.查询职业 <名称>` | 按名称查职业与子职 | 群聊 / 私聊 |
| `.查询起源 <名称>` | 按名称查种族与背景 | 群聊 / 私聊 |
| `.查询术语 <名称>` | 按名称查规则术语与状态 | 群聊 / 私聊 |
| `.查询单位 <名称>` | 查单位换算小节（长度 / 重量 / 温度 / 体积 / 货币） | 群聊 / 私聊 |

| `.搜索 <关键词>` | 全文检索（`.s` / `.检索`），适合记不清名称时；关键词写法与 `.查询` 相同 | 群聊 / 私聊 |
| `.查询图片 [on/off]` | 查看 / 切换**本处**的词条图片显示（群聊按群、私聊按本人）；需骰主先开启图片模式，否则报错并仍以文字显示 | 群聊 / 私聊 |
| `.查询范围 [缩写…]` | 查看 / 收窄**本处**可查询的书目范围（如 `.查询范围 PHB24,MM25`；`.查询范围 全部` 恢复）；不设置即全部开放 | 群聊 / 私聊 |
| `.规则书` | 列出可设置的书目缩写与中文名对照（`.qbooks`；骰主开启图片模式时默认出图） | 群聊 / 私聊 |

> **查规则推荐优先用速查子命令**（`.查询法术` 等 8 条）：它们在站点整理好的速查索引里按名称精确查找，结果最可靠；`.查询` / `.搜索` 是通用检索，覆盖面广但结果不保证、排版可能有解析问题。
>
> 查询类命令**无需管理权限**（图片开关与范围都是按处设置、持久保存），但需规则查询功能已开启（未开启时会提示联系骰主）；详细用法与常见问题见[规则查询](./query.md)，书目范围的设置与缩写对照见[查询范围](./query-scope.md)。骰主开启与调优见[快速开始 - 规则查询](./quickstart.md#规则查询)，自建查询服务（可选）见[自建查询服务](./self-host.md)。
