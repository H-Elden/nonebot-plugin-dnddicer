# 群管理与 FAQ

本页供 DM 与骰主查阅：群级配置（默认骰面、群聊服务开关）、与宿主机器人的协同排查，以及跑团过程中的常见问题。

安装步骤与插件配置项见[快速开始](./quickstart.md)。

## 群默认骰面

`.dset` 设置本群的默认骰面：掷骰（`.r`）中**省略面数的裸 `d` / `2d`** 会使用本群默认骰面（未设置时用全局默认 D20）。可设置任意掷骰表达式（`100`、`2d6+3` 均可）。

设置只能由群主或管理员做，查询任何成员都可以：

::: chat
白鸦 | .dset 100
屠龙骰 | 本群默认掷骰表达式已改为D100。
阿茶 | .dset
屠龙骰 | 当前默认掷骰表达式为D100。使用 .dset [表达式] 进行修改。
:::

改完即生效，此后本群的裸 `d` 都按 D100 掷：

::: chat
老猫 | .rd+2
屠龙骰 | 塔莉 的掷骰结果为 1D100+2=[67]+2=69
:::

三种不生效的情形（普通成员修改、表达式无效、在私聊里发出）：

::: chat
阿茶 | .dset 20
屠龙骰 | 仅群主或管理员可以设置群默认骰面。
白鸦 | .dset 1
屠龙骰 | 默认掷骰表达式无效：默认骰面数至少为2

注：以下内容发生在私聊对话框

阿茶 | .dset 6
屠龙骰（私聊） | 该指令仅在群聊中可用。
:::

角色卡与检定里的骰子（如 `.敏捷检定` 的 D20）不受默认骰面影响，详见[掷骰基础 - 默认骰面](./roll-basics.md#默认骰面)。

## 群聊服务开关

群聊服务**默认关闭**：未开启的群只有 `.bot` 可用，其余命令静默不响应（消息会继续交给宿主其他插件处理，不会刷屏报错）。

- `.bot on` / `.bot off` 只在群聊、只认**群主 / 管理员**，且必须 **@ 本机器人**（@ 在开头或结尾均可）；
- **私聊不受开关限制**，但可用命令更少：掷骰、属性生成等可用，角色卡、检定、HP、先攻等仅限群聊（差异见[快速开始 - 群聊 / 私聊差异速查](./quickstart.md#群聊-私聊差异速查)）；
- 想知道当前开没开：群里 @ 机器人发一句 `.bot`，回复里带本群服务状态。

一条命令开启：

::: chat
白鸦 | @屠龙骰 .bot on
屠龙骰 | 本群服务已开启。
:::

关掉同样一条；`.bot` 命令本身不受开关影响，关掉后仍能重新开启：

::: chat
白鸦 | @屠龙骰 .bot off
屠龙骰 | 本群服务已关闭，本群将不再响应本插件的其他命令（.bot 不受影响）。
:::

完整说明见[快速开始 - 开启本群服务](./quickstart.md#开启本群服务)。

## 规则查询（内容来源与群级设置）

规则查询（`.查询` / `.搜索`）**默认关闭**，需骰主在 `.env` 中开启后才能使用；玩法与书单见[规则查询](./query.md)。本节补骰主与群管理关心的三点。

**内容来源**：查询来自《5e不全书》的检索服务（默认用公开在线服务，也可由骰主自建实例，见[自建查询服务](./self-host.md)）；内容只用于当次回复与短时内存缓存，**不落盘、不随插件分发**，输出统一标注来源。

**两个按处设置**（群聊对该群全员生效、私聊仅影响本人；无需管理权限、设置持久保存）：

- `.查询图片 on` / `off`：本处的词条正文用图片还是文字（需骰主先开启图片模式，未开启时开启会被拒绝并继续用文字）；
- `.查询范围 <缩写>`：把本处可查的书目收窄到指定几本（中文名与缩写对照见 `.规则书`），默认全部开放、`.查询范围 全部` 恢复。

**收不到结果时分两种**：提示里带「查询范围为 …」= 被范围挡住，用 `.查询范围 全部` 放开；否则换个关键词、或改用 `.搜索` 全文检索。发送 `.查询` 收到「规则查询功能未开启，请联系骰主解决」= 骰主尚未开启该功能（群聊里即使已开启查询，也仍受本群服务开关管辖）。

## 与宿主机器人协同

### 命令起始符（骰主可改）

本插件命令默认以 `.` / `。` 开头，**不**使用宿主 `COMMAND_START`（NoneBot 默认含 `/`）。

原因：`/help`、`/bot` 等常见单词命令会与本插件同时命中，造成行为不可控。

- 需要斜杠触发时：设置 `dnddicer_use_host_command_starts=true`（此后 `/.help` 同样有效）；
- 开启后若仍出现命令被“抢答”，调小 `dnddicer_command_priority`（默认 10，越小越优先）。

### 响应不到时的排查顺序

1. **群聊**：本群服务是否开启？（`.bot` 查询；未开启只会得到无响应或 `.bot` 的回复）
2. `.bot` 系列：是否 @ 了机器人？@ 位于开头或结尾均可。
3. 命令是否以 `.`/`。` 开头？（斜杠需配置开启）
4. 私聊直连测试：如果私聊正常而群聊无响应，基本是白名单开关问题。

## 数据存储与隐私

| 项目 | 说明 |
| --- | --- |
| 存储位置 | NoneBot localstore 数据目录下的 `nonebot_plugin_dnddicer/`（可用 `LOCALSTORE_DATA_DIR` 调整） |
| 内容 | 角色卡（群+QQ 键）、HP、先攻表、群配置、服务开关名单、查询设置（图片开关与查询范围）<br>全部本地 JSON，**不上传任何服务器** |
| 清理 | 删除对应 JSON 文件或发送 `.角色卡清除` / `.hp del` / `.init clr` |

## 常见问题 FAQ

**Q：支持 COC 或 D100 体系吗？**

不支持。屠龙骰专精 DND5e/5r：不做 COC 属性生成/理智、不做 `.mode` 规则切换。因此大成功/大失败只围绕 D20，`.rd100` 也不会播报。

**Q：`.r` 与检定点命令（`.力量检定`）的区别？**

从使用权限来看：

- `.r` 任何人在私聊/群聊中均可使用，适用性强，覆盖面广。
- 检定点命令（`.力量检定`）仅限群聊，且必须绑定角色卡。

从易用性来看：

- `.r` 手动写完整表达式；
- 检定点命令自动代入角色卡上的调整值/熟练/额外加值（先攻检定还会自动入先攻表）。

因此，**跑团过程更推荐先绑定角色卡**，使用检定点命令来进行检定。条目与写法见[检定与豁免](./checks.md)。

**Q：检定的“成功 / 失败”怎么算？**

检定点命令只掷出裸数值（D20+加值），**不判定 DC**，由 DM 或玩家自行比较。大成功/大失败只是 20/1 的演出播报（检定与豁免用这套文案）；武器攻击检定另有专门的提示：天然 20 引导重击伤害、天然 1 提示必失，符合 5e 规则。

**Q：写了 `.rexp`、`.ra` 为什么提示未实现？**

期望值计算与特殊判定模式不在本插件范围内，遇到时显式提示而非静默：

::: chat
小满 | .rexp3d6
屠龙骰 | 「期望值计算」(.r exp) 尚未实现，敬请期待。
小满 | .ra3d6
屠龙骰 | 该掷骰模式（a）尚未实现，敬请期待。
:::

**Q：`.dset` 改了默认骰面，会影响谁？**

**只影响本群**。默认骰面是群级配置，本群所有人的裸 `d` 都按它掷，其他群各自独立；想改回来发 `.dset 20` 即可。

**Q：同一条消息能命中多个插件命令怎么办？**

如果你不是骰主，请联系骰主进行修复。

**请骰主（部署者）阅读**：本插件通过事件优先级协同，插件默认优先级 10（高于 NoneBot 默认 1000），同一消息上先于普通监听器处理；需要让位时把 `dnddicer_command_priority` 调大。

**Q：怪物 / NPC 血量与多目标列表有吗？**

有。先 `.ri 名称` 把 NPC 加入先攻表，再用 `.hp 名称 10/10` 记录血量（先攻列表与 `.hp list` 都会展示）；同名 NPC 在新战斗中入表时自动回满，需要跨战斗延续血量用 `.npc 持久 名称`。详见 [HP 与长休 - NPC / 怪物血量](./hp-rest.md#npc-怪物血量)。

**Q：玩家不在场，DM 怎么代操作他的角色卡？**

把 **@该成员** 写在目标位置即可：`@` 直连他本群的角色卡，不受同名 NPC 与角色卡改名影响；`.hp`、`.长休`、检定点命令、`.ri`、`.init 子指令` 都支持。清单见[命令总览 - @ 提及目标](./overview.md#提及目标-dm-代操作)，DM 视角的完整流程见 [DM 实战指南](./dm-guide.md)。
