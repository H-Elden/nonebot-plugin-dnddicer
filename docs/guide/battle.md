# 战斗轮（.br / .回合 / .轮次 / .ed）

战斗轮不是独立的系统，而是**先攻表的「进行中状态机」**：`.br` 开局后，先攻表变成回合队列，`.ed`（结束回合）自动推到下一位，一轮走完自动进位。所有命令**仅限群聊**、作用于**本群先攻表**。

先认识三个概念：

| 概念 | 含义 |
| --- | --- |
| 先攻表 | [先攻列表](./initiative.md)：按先攻值降序的条目队列 |
| 回合指针 | 表里当前行动的那一条（「当前回合」） |
| 轮次 | 队列从头走到尾算一轮，走满一圈进位一次 |

三者都存在同一张先攻表里，所以 `.init` 的列表头就能看到「当前是第几轮、谁的回合」。

## 开局：先 .br，再掷先攻

`.br` / `。战斗轮` 会**清空**本群先攻表与回合指针（无论旧的还是刚掷的），所以顺序必须是**先开局、后入表**：

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
:::

> `.br` 与 `.init clr` 的清空作用**完全等价**，区别只在播报文案。
> 
> `.br` 播「已创建新战斗轮」面向开局，`.init clr` 播「已清除先攻列表」面向清表。
> 
> 战斗结束后不必专门收尾命令——不再推进即可，下次 `.br` 重新开局。

开局后全员掷先攻（`.ri` / `.先攻检定`），就绪的列表形如：

::: chat
白鸦 | .init
屠龙骰 | 先攻列表如下: 
当前是第1轮,塔莉的回合
1.塔莉 先攻:17 HP:43/43
2.熊地精 先攻:17 
3.布鲁姆 先攻:15 HP:48/48
4.向导 先攻:12 
5.洛恩 先攻:9 HP:37/37
6.狼 先攻:7 
7.薇拉 先攻:6 HP:54/54
:::

## 查看当前回合（.回合 / .轮次）

`.回合` 播报「第几轮第几回合、轮到谁」；`.轮次` 同理只管轮次：

::: chat
白鸦 | .回合
屠龙骰 | 现在是第1轮第1回合，塔莉的回合。
:::

## 推进回合（.ed）

行动者用 `.ed` / `。结束` 结束自己的回合，骰娘播报并自动推进到下一位；一轮走完自动进位。**轮到绑定 QQ 的玩家时，末尾会 @ 提醒他**（@ 的是群昵称）：

::: chat
老猫 | .ed
屠龙骰 | 塔莉的回合结束了。
现在是熊地精的回合。

白鸦 | .ed
屠龙骰 | 熊地精的回合结束了。
现在是布鲁姆的回合。请玩家@阿岩开始行动。

注：怪物与 NPC 的回合由 DM 发 .ed 推进。

小满 | .ed
屠龙骰 | 洛恩的回合结束了。
现在是狼的回合。

阿茶 | .ed
屠龙骰 | 薇拉的回合结束了。
新的一轮，现在是第2轮。
现在是塔莉的回合。请玩家@老猫开始行动。

注：一轮走完自动进位——先播「新的一轮」，再播下一位行动者。
:::

> 回合流转只需记住三条：
> 
> - 玩家结束自己的回合用 `.ed`；
> - DM 要连续推进多位用 `.回合+2`；
> - 想直接跳到某人发 `.回合 名字`。

## DM 手动调整（.回合 / .轮次）

回合指针可以前跳、后跳、直接设值，也可以按名字或 @ 玩家定位：

::: chat
白鸦 | .回合-1
屠龙骰 | 现在是骷髅的回合。
白鸦 | .回合 熊地精
屠龙骰 | 现在是熊地精的回合。
白鸦 | .回合 @小满
屠龙骰 | 现在是洛恩的回合。请玩家@小满开始行动。
白鸦 | .回合+2
屠龙骰 | 现在是薇拉的回合。请玩家@阿茶开始行动。
白鸦 | .轮次+1
屠龙骰 | 现在变成第3轮了。
现在是薇拉的回合。
:::

| 写法 | 含义 |
| --- | --- |
| `.回合` / `.轮次` | 查看当前回合 / 轮次 |
| `.回合+2` / `.回合-1` | 前进 / 后退若干位（越界自动进位、退位轮次） |
| `.回合=3` | 直接跳到本轮第 3 位（越界报错） |
| `.回合 名字` | 按名称跳转（精确优先、其次部分匹配） |
| `.回合 @玩家` | 按归属跳转——不受改名与同名歧义影响 |
| `.轮次+1` / `.轮次=3` | 调整轮次（只动轮次，回合指针按越界规则修正） |

## 常见提示

| 场景 | 回复 |
| --- | --- |
| 数字越界（`.回合=99` / `.回合=0`） | `这个数字太大了。` / `这个数字太小了。` |
| 参数不是数字（`.回合+abc`） | `这不是数字。` |
| 名称无匹配 / 匹配到多位 | `没有找到这个回合。` / `找到复数回合，请换一个关键词。` |
| `.回合 @玩家` 但该玩家没有条目 | `@玩家 不在先攻列表中` |
| 先攻表为空时查看或推进 | `目前先攻列表为空，故不存在回合与轮次。` |

::: chat
白鸦 | .回合=99
屠龙骰 | 这个数字太大了。
白鸦 | .回合=0
屠龙骰 | 这个数字太小了。
白鸦 | .回合+abc
屠龙骰 | 这不是数字。
白鸦 | .回合 不存在的东西
屠龙骰 | 没有找到这个回合。
白鸦 | .回合 哥布林
屠龙骰 | 找到复数回合，请换一个关键词。
:::

清表之后再查看/推进，会明确提示「先攻列表为空」：

::: chat
白鸦 | .init clr
屠龙骰 | 已清除先攻列表
白鸦 | .回合
屠龙骰 | 目前先攻列表为空，故不存在回合与轮次。
白鸦 | .ed
屠龙骰 | 目前先攻列表为空，故不存在回合与轮次。
:::

## 范围说明

- **没有 BUFF 计时表**：本轮中自动到期的效果（祝福术、持续时间…）由 DM 手动记、手动撤；
- 条目显示的是**入表时快照的名称**；玩家改名不影响已入表的条目（`.回合 @玩家` 按归属定位，改名照常生效）；
- `.init clr` / `.br` 会一并清理 NPC 的临时血量（详见[HP 与长休](./hp-rest.md#查看与清理)）。

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `.br` / `.战斗轮` | `.br` | 新建战斗轮：清空先攻表与回合指针 |
| `.回合` / `.轮次` | `.回合`、`.回合+2`、`.回合=2`、`.回合 名字`、`.回合 @玩家` | 查看 / 调整回合（`+`/`-`/`=`/名字/@ 四种写法） |
| `.轮次` | `.轮次`、`.轮次+1`、`.轮次=3` | 查看 / 调整轮次 |
| `.ed` / `.结束` | `.ed` | 结束当前回合并自动推进；一处清表用 `.init clr` |
