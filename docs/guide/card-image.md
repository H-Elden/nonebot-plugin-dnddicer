# 角色卡图与立绘

`.角色卡图` 把本群角色卡渲染成一张单页角色卡图片，`.立绘` 给当前卡设置头像图。完整的卡面段语法见[角色卡与属性](./character-card.md#段落一览)。

## 角色卡图

群聊发送 `.角色卡图` 查看本群绑定的图片卡，`.角色卡图 @玩家` 或 `.角色卡图 角色名` 查看他人的本群绑定卡；私聊发送 `.角色卡图 [卡名]` 查看本人卡，卡库多张时需带卡名。

图片需要骰主安装渲染依赖并开启角色卡图开关；未开启或渲染失败时，骰娘会回退为文字卡，并在末尾提示联系骰主解决。

![角色卡图示例](./images/card-sample.png)

> 示例图由真实渲染器使用模板示例卡生成，仅用于展示版式；实际卡面以骰娘输出为准。

卡面按单页角色卡排版：页眉是立绘、身份、经验与 HP 表；左栏是六属性卡（调整值、豁免、技能与专精标记均按卡上的属性与熟练现算）、熟练与语言与战斗记录；右栏顶部是武器与伤害表，其下左列是限定资源、装备（两列清单）、魔法物品、钱币与背景与个性（两列键值），右列是专长、种族特性与职业特性（按等级升序带徽标），两列之下整行是背景故事；再往下是法术区。故事每段首行自动缩进两字；魔法物品单独显示名称、标签与说明段落。没有填写的可选段不会显示。

### 用法

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
小满 | .角色卡图
屠龙骰 | [图片]
小满 | .角色卡图 @阿茶
屠龙骰 | [图片]
:::

`[图片]` 表示骰娘发送的图片消息；正文里看不到图片内容时，说明当前客户端没有加载出来。

## 立绘

发送一张图片并附上 `.立绘 [卡名]`，即可把这张图设为当前卡的立绘；群聊设置本群绑定卡，私聊按卡名设置（卡库仅一张时可省略卡名）。插件按原图保存，不压缩、不缩放、不裁切；建议使用方形图片，卡面立绘框是 1:1。不想自己算比例时，可以用[网页建卡器](./card-builder.md#立绘)里的裁切工具裁成 512×512 再发送。

支持 PNG / JPG / WebP，单张不超过 4 MB。一次发多张时只保留第一张。没有立绘的角色卡会显示姓名首字占位。

立绘属于当前卡；`.角色卡清除 <卡名> 确认` 会连同立绘一起删除，`.角色卡修改` 改段不会丢失已设置的立绘。

没有附带图片时，骰娘只回用法提示：

::: chat
小满 | .立绘
屠龙骰 | 用法：发送一张图片并附带 .立绘 [卡名]（私聊多张卡需带卡名）
:::

## 卡面字段从哪来

卡图的六属性调整值、豁免与技能加值由骰娘按 `$属性$`、`$等级$`、`$熟练$` 与 `$额外加值$` 自动计算，不需要手填；AC 与速度以 `$战斗$` 的值为准，先攻与被动察觉由骰娘按属性、熟练与额外加值自动计算（被动察觉 = 10 + 察觉检定加值，优势/劣势 ±5）。填法见[角色卡与属性](./character-card.md#段落一览)；只想补一个段时，用 `.角色卡修改 <卡名> <段条目>`：

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
:::

卡面图与立绘在私聊按卡名选中，群聊看本群绑定卡；卡库、多卡与绑定命令见[角色卡与属性](./character-card.md)。
