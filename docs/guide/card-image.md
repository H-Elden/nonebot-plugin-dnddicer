# 角色卡图与立绘

`.角色卡图` 把本群角色卡渲染成一张单页角色卡图片，`.立绘` 给当前卡设置头像图。完整的卡面段语法见[角色卡与属性](./character-card.md#段落一览)。

## 角色卡图

发送 `.角色卡图` 查看自己的图片卡；`.角色卡图 @玩家` 或 `.角色卡图 角色名` 查看他人，与 `.角色卡` 的查看范围一致。

图片需要骰主安装渲染依赖并开启角色卡图开关；未开启或渲染失败时，骰娘会回退为文字卡，并在末尾提示联系骰主解决。

![角色卡图示例](./images/card-sample.png)

> 示例图由真实渲染器使用模板示例卡生成，仅用于展示版式；实际卡面以骰娘输出为准。

卡面按单页角色卡排版：页眉是立绘、身份、经验与 HP 表；左边是六属性卡（豁免、技能与专精标记）、熟练与语言、战斗记录；右边是武器表、种族特性 / 专长 / 职业特性、装备与钱币、背景与故事；底部是施法属性、豁免 DC、法术攻击、法术位格子与法术表。没有填写的可选段不会显示。

### 用法

::: chat
小满 | .角色卡记录 $战斗$ AC:15; 先攻:+2; 速度:30; 被动察觉:13
屠龙骰 | 角色卡已设置
小满 | .角色卡图
屠龙骰 | [图片]
小满 | .角色卡图 @阿茶
屠龙骰 | [图片]
:::

`[图片]` 表示骰娘发送的图片消息；正文里看不到图片内容时，说明当前客户端没有加载出来。

## 立绘

发送一张图片并附上 `.立绘`，即可把这张图设为当前卡的立绘。插件按原图保存，不压缩、不缩放、不裁切；建议使用方形图片。

支持 PNG / JPG / WebP，单张不超过 4 MB。一次发多张时只保留第一张。没有立绘的角色卡会显示姓名首字占位。

立绘属于当前角色卡；`.角色卡清除` 会连同立绘一起删除，重新发送整卡（`.角色卡记录`）不会丢失已设置的立绘。

没有附带图片时，骰娘只回用法提示：

::: chat
小满 | .立绘
屠龙骰 | 用法：发送一张图片并附带 .立绘
:::

## 卡面字段从哪来

卡图只展示卡面上已经填写的值，不会按规则自动推算 AC、先攻、豁免、技能加值或被动察觉。填法见[角色卡与属性](./character-card.md#段落一览)；只想补一个段时，`.角色卡记录` 支持单段修改：

::: chat
小满 | .角色卡记录 $战斗$ AC:15; 先攻:+2; 速度:30; 被动察觉:13
屠龙骰 | 角色卡已设置
:::

卡面图片与立绘目前**仅限群聊**；私聊建卡与跨群绑定留待后续的卡库功能。
