# 角色卡图与立绘

`.角色卡` 查看当前角色卡：骰主开启角色卡图后输出一张单页角色卡图片，否则输出文字卡。`.角色卡导出` 始终输出可复制的文字卡，`.立绘` 给当前卡设置头像图。完整的卡面段语法见[角色卡与属性](./character-card.md#段落一览)。

## 角色卡图

群聊发送 `.角色卡` 查看本群绑定的图片卡，`.角色卡 @玩家` 或 `.角色卡 角色名` 查看他人的本群绑定卡；私聊发送 `.角色卡 [卡名]` 查看本人卡，卡库多张时需带卡名。

图片需要骰主安装渲染依赖并开启角色卡图开关；未开启时 `.角色卡` 直接输出文字卡，开启但渲染依赖缺失或渲染失败时回退文字卡，并在末尾提示联系骰主解决。

![角色卡图示例](./images/card-sample.png)

> 示例图由真实渲染器使用模板示例卡生成，仅用于展示版式；实际卡面以骰娘输出为准。示例图是 2024 / 5r 群的称呼。

卡面按单页角色卡排版：页眉是立绘、身份、经验与 HP 表；左栏是六属性卡（调整值、豁免与技能加值均按卡上的属性与熟练现算，专精用 ✦、半熟练在加值后标「半」）、熟练与语言与战斗记录；右栏顶部是武器与伤害表，其下左列是限定资源、装备（两列清单）、魔法物品、钱币与背景与个性（两列键值），右列是专长、种族特性与职业特性（按等级升序带徽标），两列之下整行是背景故事；再往下是法术区。故事每段首行自动缩进两字；魔法物品单独显示名称、标签与说明段落。没有填写的可选段不会显示。

HP 表最后一行的激励框有三态：`$进度$` 里没写 `激励` 时显示 `—`，写 `激励:无` 是空框，写 `激励:有` 是勾选框。标题随[群级规则版本](./rules-version.md)变化：2024 / 5r 为「英雄激励」，2014 / 5e 为「激励」，用 [`.激励`](./character-card.md) 命令记录与转赠时也按同一称呼播报。

::: details 2014 / 5e 群的称呼（同一张示例卡）
![2014 群的角色卡图示例](./images/card-sample-5e.png)
:::

### 用法

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
小满 | .角色卡
屠龙骰 | [图片]
小满 | .角色卡 @阿茶
屠龙骰 | [图片]
:::

`[图片]` 表示骰娘发送的图片消息；正文里看不到图片内容时，说明当前客户端没有加载出来。

## 文字卡导出

需要一份能直接复制、粘回网页建卡器的文字卡时，用 `.角色卡导出`：群聊发送 `.角色卡导出` 看本群绑定的卡，`.角色卡导出 @玩家` 或 `.角色卡导出 角色名` 看他人；私聊发送 `.角色卡导出 [卡名]` 看本人卡，卡库仅一张时可省略卡名。无论角色卡图是否开启，它都只输出文字卡。

::: chat
小满 | .角色卡导出
屠龙骰 | $姓名$ 洛恩
$种族$ 精灵
$职业$ 法师
$子职$ 塑能师
$生命值$ 24/37
$生命骰$ 4/5 D6
$战斗$ AC:15; 速度:30
$等级$ 5
$属性$ 8/15/16/18/10/8
$熟练$ 2*奥秘/历史/调查/宗教/察觉/智力豁免/感知豁免
$武器$ 火焰箭+7,2d10火焰/匕首+5,1d4+2穿刺
$限定资源$ 奥术回想:1/1短休
$法术$ 施法属性:智力; 火球术:3; 闪电束:3*; 护盾术:1*; 火焰箭:0
$法术位$ 1:4/4; 2:0/3; 3:0/2
:::

## 立绘

发送一张图片并附上 `.立绘 [卡名]`，即可把这张图设为当前卡的立绘；群聊设置本群绑定卡，私聊按卡名设置（卡库仅一张时可省略卡名）。插件按原图保存，不压缩、不缩放、不裁切；建议使用方形图片，卡面立绘框是 1:1。不想自己算比例时，可以用[网页建卡器](./card-builder.md#立绘)里的裁切工具裁成 512×512 再发送。

支持 PNG / JPG / WebP，单张不超过 4 MB。一次发多张时只保留第一张。没有立绘的角色卡会显示姓名首字占位。

立绘属于当前卡；`.角色卡清除 <卡名> 确认` 会连同立绘一起删除，`.角色卡修改` 改段不会丢失已设置的立绘。

没有附带图片时，骰娘只回用法提示：

::: chat
小满 | .立绘
屠龙骰 | 用法：发送一张图片并附带 .立绘 [卡名]（私聊多张卡需带卡名）
:::

## 卡面字段从哪来

卡图的六属性调整值、豁免与技能加值由骰娘按 `$属性$`、`$等级$`、`$熟练$`、`$半熟练$` 与 `$额外加值$` 自动计算，不需要手填；AC 与速度以 `$战斗$` 的值为准，先攻与被动察觉由骰娘按属性、熟练、半熟练与额外加值自动计算（被动察觉 = 10 + 察觉检定加值，优势/劣势 ±5）。填法见[角色卡与属性](./character-card.md#段落一览)；只想补一个段时，用 `.角色卡修改 <卡名> <段条目>`：

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
:::

卡面图与立绘在私聊按卡名选中，群聊看本群绑定卡；卡库、多卡与绑定命令见[角色卡与属性](./character-card.md)。
