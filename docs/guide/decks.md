# 牌堆与随机表

牌堆是一组有名字的条目，骰娘从里面随机抽一条；条目可以是文本，也可以带图片。DND 团里的随机表、事件表、战利品表，都可以用同一套命令抽取。

**本插件不内置任何牌堆**，所有牌堆都由骰主放入插件数据目录后使用；插件不附带规则书或其他站点的译文。

本页命令群聊与私聊都能用，不需要绑定角色卡。群聊仍受 `.bot on/off` 的群服务开关限制。

## 基本用法

`.draw` 不带参数时列出当前可用的自定义牌堆。

- `.draw 示例牌堆`：抽 1 条；
- `.draw 示例牌堆 3`：抽 3 条，默认不放回，抽到的条目不会在本次命令里重复；
- `.draw 3#示例牌堆`：与上一条等价，兼容 `N#` 写法；
- `.draw 示例牌堆 3 放回`：抽 3 条，每次独立随机，允许重复；
- `.draw 搜索 示例`：按名称搜索牌堆；
- `.draw 详情 示例牌堆`：查看牌堆的条目数、作者、版本、许可与简介。

`.抽牌` 和 `.牌堆` 是 `.draw` 的中文别名，三个名字等价。牌堆名精确优先，未命中再按子串匹配；匹配到多个时骰娘会列出候选，不会猜。

一次最多抽 10 条。默认不放回，牌堆抽完就停止，并在结果末尾提示实际抽到几条。需要独立随机时写 `放回`。

不带参数先看当前有哪些牌堆。下面的“示例牌堆”是测试环境里的自定义牌堆：

::: chat
白鸦 | .draw
屠龙骰 | 自定义牌堆（1）：
- 示例牌堆（3 条）
用 .draw 名称 [次数] 抽取；.draw 搜索 关键词 搜索。
:::

单抽与多抽：

::: chat
白鸦 | .draw 示例牌堆
屠龙骰 | 从【示例牌堆】抽到：
01｜篝火旁传来的旧传闻
白鸦 | .draw 示例牌堆 3
屠龙骰 | 从【示例牌堆】抽了 3 条：
1. 01｜篝火旁传来的旧传闻
2. 02｜林间小径上的一串脚印
3. 03｜酒馆角落里的陌生人
:::

搜索与详情：

::: chat
白鸦 | .draw 搜索 示例
屠龙骰 | 搜索「示例」（1 个）：
- 示例牌堆（3 条）
白鸦 | .draw 详情 示例牌堆

## 添加牌堆

本插件不内置牌堆。骰主把 Dice! 格式的 JSON 文件放进插件数据目录的 `decks` 文件夹，再由骰主私聊执行 `.draw 重载`。也可以使用社区制作的 Dice! JSON 牌堆，使用前请自行确认文本与图片的授权。条目语法、图片条目与排错见[自定义牌堆](./deck-custom.md)。

## 常见问题

**为什么没有内置牌堆？**

本插件不分发规则书或第三方站点的译文。牌堆内容由骰主自行准备，或使用你有权使用的牌堆文件；插件只负责读取和抽取。

**抽到的牌会从牌堆里消失吗？**

不会跨命令保存。每次 `.draw` 都从完整牌堆开始，只有同一次命令里的多次抽取默认不放回。
