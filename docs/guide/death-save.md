# 死亡豁免

本页讲 HP 归 0 之后的流程：**濒死与死亡豁免**。只作用于玩家（绑定角色卡或无卡 HP 记录），NPC 血量不受影响（怪物 0 HP 就是昏迷倒下）。

命令**仅限群聊**。示例取自示例团在碎星隘口遭遇战中的结算（队伍信息见[示例团与人物](./cast.md)）。

## 濒死与死亡豁免

骰娘不做「濒死判定」这一步：`.hp` 的伤害让 HP 归 0 时，自动进入濒死并提示掷豁免；之后轮到该角色时，本人发送 `.ds`（`.死亡豁免` 的简写）即可。判定与属性无关，只掷一颗 D20。没有绑定角色卡、但用 `.hp` 记过 HP 的玩家同样适用，`.ds` 读写那份群级 HP 记录。

`.ds` 需要先有一条记过当前/最大值的生命值信息：卡面 `$生命值$` 或无卡 HP 记录都行；完全没有记录时先发 `.hp 当前/最大`（没有角色卡也可以）。只想过一次 d20、不需要骰娘记次数与联动的话，直接发 `.rd20` 即可。

- **出目 ≥ 10** → 成功 +1；**出目 ≤ 9** → 失败 +1；
- **累计 3 次成功** → 伤势稳定，不再需要掷；**累计 3 次失败** → 死亡；
- **自然 20** → 立刻回复 1 点 HP、脱离濒死；**自然 1** → 记两次失败。

::: chat
白鸦 | .hp 薇拉 -51
屠龙骰 | 薇拉: 当前HP减少51
HP:35/54 -> HP:0/54 昏迷 濒死(成功0 失败0)
已进入濒死，请在自己回合开始时掷 .死亡豁免（3 次成功稳定、3 次失败死亡）。
:::

注：进入濒死的那一击本身**不记失败**，计数从 0/0 开始；只要 `HP` 回到 1 点以上（治疗、自然 20），计数与稳定状态一并清除。

濒死者再挨打会**自动记失败**（伤害重击时记两次），`.hp` 的结算行会显示记完之后的计数，再跟上这一句：

::: chat
白鸦 | .hp 薇拉 20/54
屠龙骰 | 薇拉: HP=20/54
当前HP:20/54
白鸦 | .hp 薇拉 -20
屠龙骰 | 薇拉: 当前HP减少20
HP:20/54 -> HP:0/54 昏迷 濒死(成功0 失败0)
已进入濒死，请在自己回合开始时掷 .死亡豁免（3 次成功稳定、3 次失败死亡）。
白鸦 | .hp 薇拉 -9
屠龙骰 | 薇拉: 当前HP减少9
HP:0/54 昏迷 濒死(成功0 失败0) -> HP:0/54 昏迷 濒死(成功0 失败1)
正在濒死中受到伤害：死亡豁免失败+1（成功0 失败1）
:::

掷豁免的过程与成功累计如下，第三次成功即转为稳定：

::: chat
阿茶 | .ds
屠龙骰 | 薇拉的死亡豁免：
1D20=[15]=15
死亡豁免成功 +1（成功1 失败1）
HP:0/54 昏迷 濒死(成功1 失败1)
阿茶 | .ds
屠龙骰 | 薇拉的死亡豁免：
1D20=[12]=12
死亡豁免成功 +1（成功2 失败1）
HP:0/54 昏迷 濒死(成功2 失败1)
阿茶 | .ds
屠龙骰 | 薇拉的死亡豁免：
1D20=[11]=11
死亡豁免成功：伤势稳定，不再需要掷死亡豁免（再受伤则重新开始死亡豁免）。
HP:0/54 昏迷 伤势稳定
阿茶 | .ds
屠龙骰 | 伤势已稳定，无需再掷死亡豁免（再受伤将重新开始）。
阿茶 | .ds 状态
屠龙骰 | 薇拉：HP:0/54 昏迷 伤势稳定
:::

稳定之后：

- 不必再掷（再发 `.ds` 只回一句「伤势已稳定」）；
- **再受伤**则稳定被打破、重新开始死亡豁免，计数清零；
- 稳定不等于醒来，`HP` 仍是 0、仍然昏迷，需要治疗把 HP 拉回正数。

桌面上的房规加值（如「这次豁免 +2」）与优劣势都能直接写：`.ds 优势`、`.ds +2`、`.ds 劣势-1`。

## 即死：伤害 ≥ HP 上限

**单次伤害 ≥ HP 上限**直接判死，不进入濒死、也不看计数（示例团薇拉的 HP 上限是 54，所以 51 点只算打成濒死）：

::: chat
白鸦 | .hp 塔莉 43/43
屠龙骰 | 塔莉: HP=43/43
当前HP:43/43
白鸦 | .hp 塔莉 -43
屠龙骰 | 塔莉: 当前HP减少43
HP:43/43 -> HP:0/43 昏迷 已死亡
受到43点伤害（≥生命值上限 43）——死亡。
:::

## 手动裁决

`.ds` 还有三个子命令，方便 DM 处理桌面上的特殊情形：

- `.ds 状态` 查看当前 HP 与死亡豁免摘要；
- `.ds 成功+1` / `.ds 失败+1`（数量可写 `+2`）手动记账，例如「医药检定成功、直接稳定」就发三次成功；
- `.ds 重置` 清空计数、稳定与死亡标记（**由本人发送**）。死亡的卡不会因为普通治疗而复活；复活有两条路：用 `.ds 重置` 裁决后把 HP 拉回正数，或直接走一次 `.长休`（回满 HP 并一并清除死亡标记）。

「自然 1 记两次失败 + 一次失败」就是三次失败、直接死亡；死亡后骰娘不再接受掷豁免（只提示用 `.ds 重置` 裁决）：

::: chat
阿茶 | .ds
屠龙骰 | 薇拉的死亡豁免：
1D20=[1]=1
死亡豁免·自然1：失败 +2（成功0 失败2）
HP:0/54 昏迷 濒死(成功0 失败2)
阿茶 | .ds
屠龙骰 | 薇拉的死亡豁免：
1D20=[5]=5
死亡豁免失败 +1，累计 3 次——死亡。
HP:0/54 昏迷 已死亡
:::

裁决复活由本人重置，**别忘了把 HP 拉回正数**（`HP` 仍是 0 的话依然昏迷）：

::: chat
阿茶 | .ds 重置
屠龙骰 | 已重置薇拉的死亡豁免状态（HP:0/54 昏迷 濒死(成功0 失败0)）。
白鸦 | .hp 薇拉 +1
屠龙骰 | 薇拉: 当前HP增加1
HP:0/54 昏迷 濒死(成功0 失败0) -> HP:1/54
:::

**明确不做**（避免骰娘替 DM 拿主意）：1d4 小时后自动回 1 HP（需要定时器）、医药检定自动稳定、死亡后的自动复活。

## 相关命令

- `.hp`：生命值记录、伤害与治疗，见[生命值管理](./hp.md)与[HP 进阶](./hp-advanced.md)；`.长休`：休息结算见[休息与资源](./resources.md)；
- `.hp [目标] -伤害 击晕`：留活口（5e 归 0 且伤势稳定、5r 改为降到 1 HP 并昏迷，都不进濒死），见[规则版本与击晕](./rules-version.md)；
- `.角色卡`：`$生命值$` 里写 `当前/最大`；死亡豁免状态不入卡面（是战斗中的临时状态）。
