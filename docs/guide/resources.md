# 休息与资源

跑团里最费神的是资源计数：生命骰还剩几颗、限定资源用掉几次、法术位空了没有。骰娘把这些记在角色卡上，休息时按卡面恢复，施法时按卡面扣除。

> 本页命令**仅限群聊**，且需要先在本群绑定角色卡（见[角色卡与属性](./character-card.md)）。骰娘只按卡面记账，不按职业、等级或规则表自动推算次数与环位；两版规则的差异由[群级规则版本](./rules-version.md)决定。

## 生命骰（.生命骰）

生命骰来自卡面 `$生命骰$` 段，写成 `当前/总数 D骰面`，例如 `$生命骰$ 5/5 D10`。`.生命骰 [数量] [@玩家]` 花费 N 颗生命骰（缺省 1 颗）恢复生命值，骰面与总数都读卡面：

- **5e（2014）**：每粒掷 `1D骰面 + 体质调整值`，每粒最低 0，逐粒累加；
- **5r（2024）**：掷 N 颗骰子取骰点总和（至少 1），再加 `投掷枚数 × 体质调整值`（最终治疗最低 0）。

示例团洛恩体质 16（+3）、生命骰 D6，花 1 颗：

::: chat
白鸦 | .hp 洛恩 17/37
屠龙骰 | 洛恩: HP=17/37
当前HP:17/37
小满 | .生命骰 1
屠龙骰 | 洛恩使用了生命骰：
使用1颗D6生命骰, 体质调整值为3, 骰点1D6=[4]=4, 调整1×3=+3, 回复7点生命值
HP:17/37 -> HP:24/37
:::

- 数量写在命令后，如 `.生命骰 3`；DM 可代操作：`.生命骰 2 @玩家`；
- 生命骰不足、未记录生命骰、角色已死亡或 HP 为 0 时会拒绝执行；
- 本命令只结算生命骰，不检查短休本身；两版口径的差异见[规则版本与击晕](./rules-version.md)。

## 短休（.短休）

`.短休 [@玩家]` 结算一次短休能自动恢复的部分：

- 恢复 `$限定资源$` 中恢复档含 `短休` 或 `两者` 的条目；
- 恢复**契约魔法**法术位（魔契师）；
- **不自动花费生命骰、不改 HP**，只在末尾提示可用生命骰，需要回血请另发 `.生命骰 N`。

::: chat
小满 | .能力 奥术回想 -1
屠龙骰 | 奥术回想：1/1 → 0/1（已用尽）
小满 | .短休
屠龙骰 | 洛恩进行了一次短休
恢复能力：奥术回想 0/1 → 1/1
可用生命骰5颗，需要回血请用 .生命骰 N
:::

恢复量由 `$限定资源$` 的恢复档决定：`短休` 回满、`短休+1` 恢复 1 次、`两者` 短休与长休都回满、`手动` 不随休息恢复。没有可恢复内容时只提示生命骰；生命骰已用尽或未记录时也会说明。

## 长休（.长休）

`.长休 [@玩家]` 一次结算完整的长休：**HP 回复至上限**、**临时 HP 清零**（有剩余时提示失效）、**清空死亡豁免状态**（已死亡的角色也会借此复活）、按规则版本恢复生命骰，并恢复卡上资源：

- 恢复 `$限定资源$` 中恢复档含 `长休` 或 `两者` 的条目；
- 恢复全部普通法术位与契约魔法法术位；
- 准备型施法职业（2024 的 8 个施法职业、2014 的牧师/德鲁伊/圣武士/法师）卡上有法术时，末尾提醒「可重新准备法术」，但**不会自动改动 `*` 标记**。

::: chat
白鸦 | .hp 薇拉 20/54
屠龙骰 | 薇拉: HP=20/54
当前HP:20/54
阿茶 | .能力 圣疗 -5
屠龙骰 | 圣疗：25/25 → 20/25
阿茶 | .能力 引导神力 -1
屠龙骰 | 引导神力：2/2 → 1/2
阿茶 | .法术位 1 -1
屠龙骰 | 1环：2/2 → 1/2
阿茶 | .长休
屠龙骰 | 薇拉进行了一次长休
生命值回复至上限(54)
回复0个生命骰, 当前拥有5/5个D10生命骰
恢复能力：圣疗 20/25 → 25/25；引导神力 1/2 → 2/2
恢复法术位：1环 1/2 → 2/2
可重新准备法术（.法术 准备 <名称>）。
:::

生命骰的回复量按群级规则版本：5e 回复总枚数的一半（至少 1 枚），5r 恢复全部已消耗，见[规则版本与击晕](./rules-version.md)。死亡与复活口径见[死亡豁免](./death-save.md)。

## 限定资源（.能力）

`$限定资源$` 每项写成 `名称:当前/上限恢复档`，多项用 `;` 分隔。恢复档写 `短休` / `长休` / `两者` / `手动`，默认回满；要恢复固定次数就加 `+N`（如 `短休+1`），也可以显式写 `满`：

| 恢复档 | 含义 |
| --- | --- |
| `短休` | 短休时回满 |
| `短休+1` | 短休时恢复 1 次 |
| `长休` | 长休时回满 |
| `两者` | 短休与长休都回满 |
| `手动` | 不随休息恢复，只能手动加 |

清单与详情会把「回满」明确写出来，如 `短休+1，长休回满`；`两者` 显示为 `短休回满，长休回满`。

示例团布鲁姆的卡上记了引导神力，查看与试用：

::: chat
阿岩 | .能力
屠龙骰 | 当前限定资源（1 项）：
1. 引导神力 2/2（短休+1，长休回满）
用法：.能力 名称 查看详情；.能力 名称 -N 消耗、+N 恢复
阿岩 | .能力 引导神力
屠龙骰 | 引导神力：2/2（短休+1，长休回满）
阿岩 | .能力 引导神力 -1
屠龙骰 | 引导神力：2/2 → 1/2
阿岩 | .能力 引导神力 +1
屠龙骰 | 引导神力：1/2 → 2/2（已满）
:::

- `.能力`：列出卡上全部限定资源；
- `.能力 名称`：查看单项详情；
- `.能力 名称 -N` / `+N`：消耗 / 恢复 N 次（缺省 1 次），不会越过 0 与上限；已经为 0 时再消耗会提示「已经用尽」，不会只回 `0/上限 → 0/上限`；
- `.设置能力 名称:当前/上限恢复档`：录入或覆盖（多项用 `;` 分隔，同名覆盖）；
- `.删除能力 名称`：删除（支持模糊匹配，多个用 `/` 分隔）。

名称匹配是「精确优先、其次子串」，同时命中多条时会列出候选、不会替你选。

::: chat
阿岩 | .设置能力 神圣干预:1/1长休
屠龙骰 | 已设置限定资源：神圣干预（当前共 2 项）
1. 引导神力 2/2（短休+1，长休回满）
2. 神圣干预 1/1（长休回满）
阿岩 | .删除能力 神圣干预
屠龙骰 | 已删除限定资源: 神圣干预
:::

## 代操作目标（@玩家 / 角色名）

DM 可以替不在场的玩家查看与调整资源，写法与 `.hp` 一致：目标写在命令最前面，可以是 `@玩家`，也可以是本群角色名。名称匹配精确优先、其次子串，多候选只列清单不猜。

- `.能力 @玩家` / `.能力 角色名`：查看对方的限定资源清单；
- `.能力 <目标> 名称 -N`：消耗或恢复对方的限定资源；
- `.法术位 @玩家` / `.法术位 角色名`：查看对方的法术位；
- `.法术位 <目标> set 1:4,2:3` / `reset` / `1 -1`：设置、恢复或手动增减（自身子语法写在目标之后）。

目标只从本群已绑定角色卡里找，不走 NPC 或先攻表；目标无卡、名称多候选会直接提示。`.能力` 会先尝试把开头文字当角色名，匹配不到时整段按本人限定资源名解析：若你的能力名恰好与某位玩家的角色名相同，想操作自己请改用 `@自己`。目前只有 `.能力` 与 `.法术位` 支持目标代操作，`.设置能力` / `.删除能力` / `.法术` / `.设置法术` / `.删除法术` / `.施法` 仍只作用于本人。

::: chat
白鸦 | .能力 @阿茶
屠龙骰 | 薇拉的限定资源（2 项）：
1. 圣疗 25/25（长休回满）
2. 引导神力 2/2（短休+1，长休回满）
用法：.能力 名称 查看详情；.能力 名称 -N 消耗、+N 恢复
白鸦 | .能力 薇拉 圣疗 -1
屠龙骰 | 薇拉的圣疗：25/25 → 24/25
白鸦 | .法术位 @小满
屠龙骰 | 洛恩的法术位：
1环：4/4
2环：0/3
3环：0/2
白鸦 | .法术位 洛恩 1 -1
屠龙骰 | 洛恩的1环：4/4 → 3/4
:::

## 魔法物品（$魔法物品$）

`$魔法物品$` 每件写成 `名称|标签|说明`，多项用 `;` 分隔。标签写类型、稀有度与同调要求；说明里的 `//` 表示分段：

```
$魔法物品$ 防护斗篷|奇物，非普通（需同调）|着装期间 AC 和豁免 +1。//银线织成，边缘绣着守护符文。
```

魔法物品不放进 `$物品$`，也不记数量与装备标记。卡面会单独显示名称、标签与说明段落；网页建卡器的说明框用空行分段，不需要手写 `//`。

## 法术清单与准备（.法术）

`$法术$` 每项写成 `法术名:环阶`，`0` 表示戏法；尾部加 `*` 表示**今日已准备**。可以先用 `施法属性:属性` 记下施法属性，再用 `豁免DC` / `法术攻击` 记下施法数值；卡面图还会读 `|` 后的详情（`时间=…,距离=…,专注=是,材料=是,备注=…`，只用于展示）：

```
$法术$ 施法属性:智力; 火球术:3*; 闪电束:3; 火焰箭:0
```

洛恩的卡上录了五个法术，`.法术` 会标出环阶与准备状态：

::: chat
小满 | .法术
屠龙骰 | 当前法术（5 项，施法属性：智力）：
1. 火球术 3环（已准备）
2. 闪电束 3环
3. 魔法飞弹 1环（已准备）
4. 护盾术 1环（已准备）
5. 火焰箭 戏法
用法：.法术 准备/取消 名称；记录用 .设置法术 名称:环阶
:::

准备标记随时可以切换，戏法不参加准备：

::: chat
小满 | .法术 准备 闪电束
屠龙骰 | 已将「闪电束」标记为今日已准备（3环）。
小满 | .法术 取消 火球术
屠龙骰 | 已取消「火球术」的准备标记（3环）。
:::

`.设置法术` 与 `.删除法术` 负责改卡，`.法术 准备/取消` 只切换当日的准备标记：

::: chat
小满 | .设置法术 魔法飞弹:2
屠龙骰 | 已设置法术：魔法飞弹（当前共 5 项）
1. 火球术 3环
2. 闪电束 3环（已准备）
3. 魔法飞弹 2环（已准备）
4. 护盾术 1环（已准备）
5. 火焰箭 戏法
小满 | .删除法术 魔法飞弹
屠龙骰 | 已删除法术: 魔法飞弹
:::

- `.法术`：查看法术清单；
- `.法术 准备 名称` / `.法术 取消 名称`：切换 `*` 标记（名称支持模糊匹配；戏法无需准备）；
- `.法术 提醒 on|off`：记录本群的**施法未准备提醒**开关，默认开（按群保存，供 `.施法` 判定）；
- `.设置法术 名称:环阶[*][|详情]`：录入或覆盖（多项用 `;` 分隔；可写 `施法属性:智力`、`豁免DC:15`、`法术攻击:+7`；`|` 之后可写卡面详情）；
- `.删除法术 名称`：删除（支持模糊匹配，多个用 `/` 分隔）。

普通 `.设置法术` 只改环阶，不会抹掉已有的准备标记与卡面详情（写了 `|详情` 才整组覆盖）；要取消准备请用 `.法术 取消`。

::: chat
小满 | .法术
屠龙骰 | 当前法术（4 项，施法属性：智力）：
1. 火球术 3环
2. 闪电束 3环（已准备）
3. 护盾术 1环（已准备）
4. 火焰箭 戏法
用法：.法术 准备/取消 名称；记录用 .设置法术 名称:环阶
小满 | .法术 提醒
屠龙骰 | 本处的施法未准备提醒：开启。发送 .法术 提醒 off 关闭。
小满 | .法术 提醒 off
屠龙骰 | 已关闭本处的施法未准备提醒。
小满 | .法术 提醒 on
屠龙骰 | 已开启本处的施法未准备提醒。
:::

## 法术位（.法术位 / .ss）

`$法术位$` 每项写成 `环阶:当前/上限`，契约魔法写 `契约N:当前/上限`：

```
$法术位$ 1:4/4; 2:3/3; 3:2/2; 契约3:2/2
```

洛恩的查看、设置、手动消耗与恢复：

::: chat
小满 | .法术位
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 set 1:4, 2:3, 3:2/2
屠龙骰 | 已设置法术位：1环 4/4、2环 3/3、3环 2/2
当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 3 -1
屠龙骰 | 3环：2/2 → 1/2
小满 | .ss
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：1/2
小满 | .法术位 reset
屠龙骰 | 已恢复全部法术位：
1环：4/4
2环：3/3
3环：2/2
:::

- `.法术位` / `.ss`：查看当前法术位；写 `@玩家` 或角色名可查看他人（见上文「代操作目标」）；
- `.法术位 set 1:4,2:3`：设置（只写一个数表示当前与上限都设为它；写 `3:2/2` 可分别指定）；
- `.法术位 3 -1` / `.法术位 契约 -1`：手动消耗（`+1` 为恢复，缺省 1 次，不会越过 0 与上限）；
- `.法术位 reset`：全部恢复到上限（长休口径）。

## 施法（.施法 / .cast）

`.施法 <法术名>[环阶修饰]` 按卡面 `$法术$` 与 `$法术位$` 结算，**环阶一律来自卡面，不查索引、不发网络请求**：

- `.施法 火球术`：用录入环阶（3 环）；
- `.施法 护盾术2` / `.施法 护盾术2环`：**绝对升环**，用 2 环位施展 1 环法术；
- `.施法 护盾术+1` / `.施法 护盾术+1环`：**相对升环**，录入环阶 +1；
- `.施法 2` / `.施法 2环`：只指定环阶，直接消耗 1 个 2 环位；
- 戏法（0 环）不消耗法术位，也不需要准备。

洛恩在短休前的一轮施法：

::: chat
小满 | .施法 火球术
屠龙骰 | 洛恩施展了「火球术」（3环）
消耗3环法术位：2/2 → 1/2
（未标记为已准备，如需标记：.法术 准备 火球术）
小满 | .施法 闪电束
屠龙骰 | 洛恩施展了「闪电束」（3环）
消耗3环法术位：1/2 → 0/2
小满 | .施法 护盾术2
屠龙骰 | 洛恩施展了「护盾术」（2环）
消耗2环法术位：3/3 → 2/3
小满 | .施法 护盾术+1
屠龙骰 | 洛恩施展了「护盾术」（2环）
消耗2环法术位：2/3 → 1/3
小满 | .施法 2
屠龙骰 | 洛恩消耗了1个2环法术位：1/3 → 0/3
小满 | .施法 火焰箭
屠龙骰 | 洛恩施展了「火焰箭」（戏法）
戏法不消耗法术位。
可用 .火焰箭伤害 掷伤害。
小满 | .施法 3
屠龙骰 | 没有可用的3环法术位（当前可用：1环 4/4）。
:::

判定细节：

- **未准备提醒**：法术已录入但没有 `*` 标记时照常消耗环位，只在末尾附一句提醒；是否提醒由群级规则版本与职业决定，并可用 `.法术 提醒 off` 关闭：

  | 群级规则版本 | 职业 | 提醒 |
  | --- | --- | --- |
  | 2024（5r） | 吟游诗人 / 牧师 / 德鲁伊 / 术士 / 魔契师 / 法师 / 圣武士 / 游侠 | 提醒 |
  | 2014（5e） | 牧师 / 德鲁伊 / 圣武士 / 法师（准备型） | 提醒 |
  | 2014（5e） | 吟游诗人 / 游侠 / 术士 / 魔契师 / 战士 / 游荡者 / 其他 | 不提醒 |

- 环位不足会列出当前可用环阶；绝对升环低于法术本身环阶时直接报错，并提示最低环阶；
- 魔契师只有契约位时，低环法术会自动使用契约位（按契约位环阶施放），回复里会写明「契约魔法」；
- 卡上 `$武器$` 有同名条目时，末尾提示可用 `.法术名伤害` 掷伤害；
- 戏法写 `0` 或直接写名字都不耗位；写 `火焰箭2` 这类升环写法会被拒绝。

## 与武器段的分工

`$武器$` 记「伤害怎么掷」，`$法术$` 记「几环、准备了没」，两者同名共存是正常用法。洛恩的卡同时有：

```
$武器$ 火焰箭+7,2d10火焰/匕首+5,1d4+2穿刺
$法术$ 施法属性:智力; 火球术:3*; 闪电束:3; 魔法飞弹:1*; 护盾术:1*; 火焰箭:0
```

- `.火焰箭伤害`：掷武器段的伤害表达式；
- `.法术 准备 火焰箭`：会提示戏法无需准备；
- `.火球术伤害`：掷武器段登记的火球术伤害（若录了同名武器项）。
