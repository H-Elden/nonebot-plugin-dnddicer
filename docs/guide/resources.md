# 能力、法术与法术位

角色卡除了数值与武器，还能记三类「有限资源」：有使用次数的能力（`$能力$`）、法术清单（`$法术$`）与法术位（`$法术位$`）。骰娘只按卡面记账，不按职业、等级或规则表自动推算次数与环位。

> 三段都**仅限群聊**，且需要先记录角色卡（见[角色卡与属性](./character-card.md)）。新增段一律用 `;` 分条、`:` 分字段，半角与全角都接受。

## 能力次数（.能力）

`$能力$` 每项写成 `名称:当前/上限恢复档`，多项用 `;` 分隔。恢复档写 `短休` / `长休` / `两者` / `手动`，默认回满；要恢复固定次数就加 `+N`（如 `短休+1`），也可以显式写 `满`：

| 恢复档 | 含义 |
| --- | --- |
| `短休` | 短休时回满 |
| `短休+1` | 短休时恢复 1 次 |
| `长休` | 长休时回满 |
| `两者` | 短休与长休都回满 |
| `手动` | 不随休息恢复，只能手动加 |

示例团布鲁姆的卡上记了引导神力，查看与试用：

::: chat
阿岩 | .能力
屠龙骰 | 当前能力（1 项）：
1. 引导神力 2/2（短休+1，长休）
用法：.能力 名称 查看详情；.能力 名称 -N 消耗、+N 恢复
阿岩 | .能力 引导神力
屠龙骰 | 引导神力：2/2（短休+1，长休）
阿岩 | .能力 引导神力 -1
屠龙骰 | 引导神力：2/2 → 1/2
阿岩 | .能力 引导神力 +1
屠龙骰 | 引导神力：1/2 → 2/2（已满）
:::

- `.能力`：列出卡上全部能力；
- `.能力 名称`：查看单项详情；
- `.能力 名称 -N` / `+N`：消耗 / 恢复 N 次（缺省 1 次），不会越过 0 与上限；
- `.设置能力 名称:当前/上限恢复档`：录入或覆盖（多项用 `;` 分隔，同名覆盖）；
- `.删除能力 名称`：删除（支持模糊匹配，多个用 `/` 分隔）。

名称匹配是「精确优先、其次子串」，同时命中多条时会列出候选、不会替你选。

::: chat
阿岩 | .设置能力 神圣干预:1/1长休
屠龙骰 | 已设置能力：神圣干预（当前共 2 项）
1. 引导神力 2/2（短休+1，长休）
2. 神圣干预 1/1（长休）
阿岩 | .删除能力 神圣干预
屠龙骰 | 已删除能力: 神圣干预
:::

> 恢复档目前只作记录与展示；`.短休` / `.长休` 的自动恢复会随休息功能接入，当前请用 `.能力 名称 +N` 手动恢复。

## 法术清单与准备（.法术）

`$法术$` 每项写成 `法术名:环阶`，`0` 表示戏法；尾部加 `*` 表示**今日已准备**。可以先用 `施法属性:属性` 记下施法属性：

```
$法术$ 施法属性:智力; 火球术:3*; 闪电束:3; 火焰箭:0
```

洛恩的卡上录了五个法术，`.法术` 会标出环阶与准备状态：

::: chat
小满 | .法术
屠龙骰 | 当前法术（5 项，施法属性：智力）：
1. 火球术 3环（已准备）
2. 闪电束 3环
3. 魔法飞弹 1环（已准备）
4. 护盾术 1环（已准备）
5. 火焰箭 戏法
用法：.法术 准备/取消 名称；记录用 .设置法术 名称:环阶
:::

准备标记随时可以切换，戏法不参加准备：

::: chat
小满 | .法术 准备 闪电束
屠龙骰 | 已将「闪电束」标记为今日已准备（3环）。
小满 | .法术 取消 火球术
屠龙骰 | 已取消「火球术」的准备标记（3环）。
:::

`.设置法术` 与 `.删除法术` 负责改卡，`.法术 准备/取消` 只切换当日的准备标记：

::: chat
小满 | .设置法术 魔法飞弹:2
屠龙骰 | 已设置法术：魔法飞弹（当前共 5 项）
1. 火球术 3环
2. 闪电束 3环（已准备）
3. 魔法飞弹 2环（已准备）
4. 护盾术 1环（已准备）
5. 火焰箭 戏法
小满 | .删除法术 魔法飞弹
屠龙骰 | 已删除法术: 魔法飞弹
:::

- `.法术`：查看法术清单；
- `.法术 准备 名称` / `.法术 取消 名称`：切换 `*` 标记（名称支持模糊匹配；戏法无需准备）；
- `.法术 提醒 on|off`：记录本群的**施法未准备提醒**开关，默认开（按群保存，供施法功能使用）；
- `.设置法术 名称:环阶`：录入或覆盖（多项用 `;` 分隔；可写 `施法属性:智力`；尾部 `*` 表示已准备）；
- `.删除法术 名称`：删除（支持模糊匹配，多个用 `/` 分隔）。

普通 `.设置法术` 只改环阶，不会抹掉已有的准备标记；要取消准备请用 `.法术 取消`。

::: chat
小满 | .法术
屠龙骰 | 当前法术（4 项，施法属性：智力）：
1. 火球术 3环
2. 闪电束 3环（已准备）
3. 护盾术 1环（已准备）
4. 火焰箭 戏法
用法：.法术 准备/取消 名称；记录用 .设置法术 名称:环阶
小满 | .法术 提醒
屠龙骰 | 本处的施法未准备提醒：开启。发送 .法术 提醒 off 关闭。
小满 | .法术 提醒 off
屠龙骰 | 已关闭本处的施法未准备提醒。
小满 | .法术 提醒 on
屠龙骰 | 已开启本处的施法未准备提醒。
:::

## 法术位（.法术位 / .ss）

`$法术位$` 每项写成 `环阶:当前/上限`，契约魔法写 `契约N:当前/上限`：

```
$法术位$ 1:4/4; 2:3/3; 3:2/2; 契约3:2/2
```

洛恩的查看、设置、手动消耗与恢复：

::: chat
小满 | .法术位
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 set 1:4, 2:3, 3:2/2
屠龙骰 | 已设置法术位：1环 4/4、2环 3/3、3环 2/2
当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 3 -1
屠龙骰 | 3环：2/2 → 1/2
小满 | .ss
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：1/2
小满 | .法术位 reset
屠龙骰 | 已恢复全部法术位：
1环：4/4
2环：3/3
3环：2/2
:::

- `.法术位` / `.ss`：查看当前法术位；
- `.法术位 set 1:4,2:3`：设置（只写一个数表示当前与上限都设为它；写 `3:2/2` 可分别指定）；
- `.法术位 3 -1` / `.法术位 契约 -1`：手动消耗（`+1` 为恢复，缺省 1 次，不会越过 0 与上限）；
- `.法术位 reset`：全部恢复到上限（长休口径）。

## 与武器段的分工

`$武器$` 记「伤害怎么掷」，`$法术$` 记「几环、准备了没」，两者同名共存是正常用法。洛恩的卡同时有：

```
$武器$ 火焰箭+7,2d10火焰/匕首+5,1d4+2穿刺
$法术$ 施法属性:智力; 火球术:3*; 闪电束:3; 魔法飞弹:1*; 护盾术:1*; 火焰箭:0
```

- `.火焰箭伤害`：掷武器段的伤害表达式；
- `.法术 准备 火焰箭`：会提示戏法无需准备；
- `.火球术伤害`：掷武器段登记的火球术伤害（若录了同名武器项）。

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `.能力` | `.能力`、`.能力 名称` | 能力清单 / 单项详情 |
| `.能力 名称 ±N` | `.能力 引导神力 -1` | 消耗 / 恢复次数 |
| `.设置能力` / `.删除能力` | `.设置能力 引导神力:2/2短休+1,长休` | 维护卡上能力 |
| `.法术` | `.法术`、`.法术 准备 名称`、`.法术 取消 名称` | 法术清单与准备标记 |
| `.法术 提醒` | `.法术 提醒 on` / `off` | 施法未准备提醒开关 |
| `.设置法术` / `.删除法术` | `.设置法术 火球术:3*` | 维护卡上法术 |
| `.法术位` / `.ss` | `.法术位 set 1:4,2:3`、`.法术位 1 -1`、`.法术位 reset` | 查看与调整法术位 |

接下来：把这些资源写进角色卡的方法见[角色卡与属性](./character-card.md)，武器伤害掷骰见[武器与攻击](./weapons.md)。
