# 武器与攻击

跑团里的攻击结算往往「一把武器一条公式」：长剑 +8 打 1D8+5、火焰箭 +7 打 2D10……

本插件把这些公式交给你**自己写进角色卡**。骰娘只负责忠实执行，**不判 AC、不判是否熟练、不自动补属性**，写多少加值就掷多少；法术攻击同样适用，把法术的命中与伤害写成一件「武器」即可。

攻击检定与伤害**统一从卡上的武器项发起**（没有武器项就掷不了攻击；徒手、临时武器之类的临时攻击直接用 `.r1d20+加值` 手掷即可）。

## 录入武器与武器管理

在角色卡里写入 `$武器$` 条目，格式为 `名称+命中加值,伤害表达式+类型`，多个武器用 `/` 分隔（命中加值与伤害类型都可省略）。

名称尾部加 `x` 表示「不可进行攻击检定」（纯伤害法术，见[下文](#纯伤害法术-x-标记)）：

> 逗号前后空格、中英文逗号、表达式内部空白都按等价处理，写法不必逐字精确。

```text
$武器$ 长剑+8,1d8+5挥砍/匕首+7,1d4+4穿刺/火球术x,8d6火焰
```

四张示例团角色卡的武器都写在卡上，可直接参考（[示例团与人物](./cast.md)）。

不改整张卡也能增量维护：

- `.设置武器`：无参数，列出当前武器；
- `.设置武器 名称+命中加值,伤害骰+类型`：新增或覆盖同名武器（多项用 `/` 分隔）；
- `.删除武器 名称`：删除（多个用 `/` 分隔）。

::: chat
老猫 | .设置武器
屠龙骰 | 当前武器（2 件）：
1. 刺剑+7,1d8+4穿刺
2. 匕首+7,1d4+4穿刺
用法：.设置武器 短剑+6,1d4+4穿刺（多项用 / 分隔）；删除用 .删除武器 名称
老猫 | .设置武器 手弩+7,1d6+4穿刺
屠龙骰 | 已设置武器：手弩（当前共 3 件）
1. 刺剑+7,1d8+4穿刺
2. 匕首+7,1d4+4穿刺
3. 手弩+7,1d6+4穿刺
老猫 | .手弩攻击
屠龙骰 | 塔莉进行【手弩攻击检定】：
武器命中加值:+7
1D20+7=[12]+7=19
老猫 | .删除武器 手弩
屠龙骰 | 已删除武器: 手弩

注：塔莉的卡上原有两件武器（刺剑、匕首）；命令新增手弩后立刻可用于攻击，用完再删掉。
:::

## 攻击检定

**命令格式：**

```
.[次数#]X攻击[后缀][±临时加值]
```

`.刺剑攻击` 与 `.刺剑命中` 同义：以卡上该武器的命中加值掷 `1D20+加值`。**是否命中由你与 DM 自行比较 AC**，骰娘不做判定。

::: chat
老猫 | .刺剑攻击
屠龙骰 | 塔莉进行【刺剑攻击检定】：
武器命中加值:+7
1D20+7=[15]+7=22
小满 | .火焰箭命中
屠龙骰 | 洛恩进行【火焰箭攻击检定】：
武器命中加值:+7
1D20+7=[18]+7=25
:::

支持：

- 前缀：`N#` 多次攻击，如双持或额外攻击；
- 攻击后缀：`优势` / `劣势`；
- 临时加值：鼓舞、吟游诗人激励等临时修正；
- DM 代掷：`.刺剑攻击 @玩家`（完整机制见[代掷与代操作](./dm-proxy.md)）。

::: chat
老猫 | .刺剑攻击优势
屠龙骰 | 塔莉进行【刺剑攻击检定】：
武器命中加值:+7 优势
2D20K1+7=MAX{[6], [17]}+7=24
老猫 | .2#刺剑攻击
屠龙骰 | 塔莉进行【2次刺剑攻击检定】：
武器命中加值:+7
1D20+7=[9]+7=16
1D20+7=[14]+7=21
:::

攻击检定掷出**天然 20** 时，骰娘会提示改用重击后缀结算伤害（掷出天然 1 则提示必失）：

::: chat
老猫 | .刺剑攻击
屠龙骰 | 塔莉进行【刺剑攻击检定】：
武器命中加值:+7
1D20+7=[20]+7=27
天然20：重击！伤害用 .刺剑重击伤害 结算

注：掷骰结果不受影响，提示只负责把你引向正确的下一步。
:::

## 伤害掷骰

**命令格式：**

```
.X[后缀]伤害[±临时加值]
```

`.刺剑伤害` 掷卡上的伤害表达式，并报出造成的伤害与类型（伤害类型照卡上记录；没写类型则省去类型词）：

::: chat
老猫 | .刺剑伤害
屠龙骰 | 塔莉用【刺剑】造成了 10 点穿刺伤害：
1D8+4=[6]+4=10
小满 | .火焰箭伤害
屠龙骰 | 洛恩用【火焰箭】造成了 13 点火焰伤害：
2D10=[9+4]=13
:::

伤害后缀写在「伤害」之前、可任意组合：

| 后缀 | 例 | 效果 |
| --- | --- | --- |
| `重击` | `.刺剑重击伤害` | 所有骰子掷两次（固定加值只加一次） |
| `偷袭` | `.刺剑偷袭伤害` | 按职业与等级自动附加偷袭骰（见下） |
| `副手` | `.匕首副手伤害` | 剔除全部加值、只保留骰子 |

「伤害」之后还可以跟 `±` **临时加值**（如 `.火球术伤害+1d6`，见[升环写法](#升环法术-两种写法)），会并入伤害表达式一起掷，同样参与重击翻倍等后缀变换。

这套伤害写法在 `.hp` 的伤害位置同样可用：`.hp 骷髅a易伤 -刺剑重击伤害+1d4` 一条命令完成掷伤与扣血；武器项默认取**发送者本人**的角色卡，DM 代发时可在尾部括号指定来源（`.hp 骷髅a易伤 -刺剑伤害（塔莉）` 或 `（@老猫）`）。伤害位置写「攻击 / 命中」会被拦下并引导改用「伤害」，见 [HP 进阶与长休](./hp-advanced.md)。

::: chat
老猫 | .刺剑重击伤害
屠龙骰 | 塔莉用【刺剑】造成了 12 点穿刺伤害（重击）：
2D8+4=[5+3]+4=12
老猫 | .刺剑偷袭伤害
屠龙骰 | 塔莉用【刺剑】造成了 18 点穿刺伤害（含偷袭3D6）：
1D8+4+3D6=[6]+4+[2+5+1]=18
老猫 | .匕首副手伤害
屠龙骰 | 塔莉用【匕首】造成了 3 点穿刺伤害（副手：不加任何加值）：
1D4=[3]=3
老猫 | .刺剑重击偷袭伤害
屠龙骰 | 塔莉用【刺剑】造成了 31 点穿刺伤害（重击，含偷袭6D6）：
2D8+4+6D6=[4+4]+4+[1+3+2+6+5+2]=31

注：塔莉是 5 级游荡者，偷袭骰 3d6；重击时与武器伤害骰一起翻倍（3d6 → 6d6）。
:::

### 偷袭骰

角色卡填好 `$职业$` 与 `$等级$` 后，`偷袭` 后缀会按游荡者特性表自动附加 N 颗 D6（1 级 1D6 起、19~20 级封顶 10D6）。

> **当前版本不支持兼职**（多职业等级不拆分），兼职角色请只填写主职业；非游荡者使用偷袭后缀会得到提示：

::: chat
阿岩 | .战锤偷袭伤害
屠龙骰 | 当前职业「牧师」没有偷袭特性，偷袭后缀不适用

注：`$职业$` 填 12 职业规范名之一（如 游荡者/法师）；没填职业时，偷袭后缀会引导你先去设置职业。
:::

### 纯伤害法术：x 标记

有些法术只有伤害、没有攻击检定，比如火球术。

名称尾部加 `x` 表示「**不可进行攻击检定**」，设置后发送 `.火球术命中` 会被明确拒绝；

不写 `x` 时按默认语义执行（掷 `1D20`、无命中加值），由你自行判断是否符合该法术的用法。

::: chat
小满 | .设置武器 火球术x,8d6火焰/四环火球术x,9d6火焰
屠龙骰 | 已设置武器：火球术/四环火球术（当前共 4 件）
1. 火焰箭+7,2d10火焰
2. 匕首+5,1d4+2穿刺
3. 火球术x,8d6火焰
4. 四环火球术x,9d6火焰
小满 | .火球术命中
屠龙骰 | 【火球术】不可进行攻击检定！
:::

### 升环法术：两种写法

骰娘不识别升环规则（各法术的升环效果不同），需要你自行处理；常用两种写法：

- **预设多条**：把常用环阶各写成一件（如 `四环火球术x,9d6火焰`），施放时直接 `.四环火球术伤害`；
- **临时加值**：只保留基础条目，施放时用 `±` 补齐升环骰（`.火球术伤害+1d6`）。

::: chat
小满 | .四环火球术伤害
屠龙骰 | 洛恩用【四环火球术】造成了 38 点火焰伤害：
9D6=[6+5+4+3+2+1+6+6+5]=38
小满 | .火球术伤害+1d6
屠龙骰 | 洛恩用【火球术】造成了 38 点火焰伤害：
8D6+1D6=[6+5+4+3+2+1+6+6]+[5]=38

注：两种写法掷出的都是 9 颗 d6（四环火球术），选顺手的那种即可。
:::

## 规则小注

- **重击**（攻击检定天然 20）：该次攻击的所有伤害骰掷两次、固定加值只加一次，偷袭等额外伤害骰同样翻倍；对应后缀 `.X重击伤害`；
- **副手**（两武器战斗）：命中照常计算，伤害不加属性调整值；本插件按「剔除全部加值、只掷骰子」的口径执行，纯定值伤害（如吹箭筒 1 点）会提示该后缀不适用；
- **偷袭**：规则上每回合一次、需优势或同伴有敌对目标近身等条件；骰娘不判断条件，由你决定这次攻击是否加 `偷袭` 后缀。

## 相关命令

| 命令 | 别名 | 一句话说明 |
| --- | --- | --- |
| `.X攻击` | `.X命中` | 用卡上该武器的命中加值掷攻击检定<br>（支持：`优势`/`劣势`/`N#`/`±`/`@`；`x` 标记的武器会被拒绝） |
| `.X伤害` | — | 掷该武器的伤害并报出类型（`副手`/`重击`/`偷袭` 后缀与 `±` 临时加值） |
| `.hp [对象] -X伤害` | — | 在 `.hp` 的伤害位置直接写武器伤害项，掷伤与扣血一条命令；尾部括号可指定来源（DM 代发用，见 [HP 进阶与长休](./hp-advanced.md) 与 [血量与伤害结算](./dm-settlement.md)） |
| `.设置武器` | — | 新增/覆盖武器（同名覆盖；多项用 `/` 分隔）；无参数列出 |
| `.删除武器` | — | 删除武器（多个用 `/` 分隔） |

武器写在角色卡的 `$武器$` 段，职业与等级也在同一张卡上（见[角色卡与属性](./character-card.md)）；属性/技能/豁免的检定点命令见[检定与豁免](./checks.md)。接下来：[HP 进阶与长休](./hp-advanced.md)：把伤害直接接到血量结算。
