# 示例团与人物

从本页面起，本站所有示例**均来自同一支固定小队**：示例群的群主是 DM，另有四名玩家各带一张规则完整的角色卡，以及一位没有建卡的编外成员。

示例沿一条**时间线**推进：开群建卡 → 旅店试骰 → 探路检定 → 遭遇战 → 休整 → 石桥桥头（第二场遭遇，DM 视角）→ 散场，各功能页的示例都取自这条线，不同页面里出现的角色、数值与骰值可相互印证。

## 示例怎么读

- 气泡**左侧是骰娘**（屠龙骰）；**DM 与所有玩家都在右侧**，头像为昵称某字与固定配色，用于区分是谁在发言；
- 气泡上方的名字是 QQ **群昵称**；骰娘回复里的名字是玩家的**角色名**，显示名按「角色名 → 群名片 → QQ 昵称」回退，建过卡的玩家在骰娘文案里显示角色名（见[名称显示规则](./overview.md#名称显示规则)）；
- 蓝紫色的「注：」条是本站讲解，不是骰娘输出；其余每一行都来自真实运行。

::: chat
阿茶 | .r2d6+3
屠龙骰 | 薇拉 的掷骰结果为 2D6+3=[5+2]+3=10

注：发送者是群昵称「阿茶」，而骰娘文案里用的是她的角色名「薇拉」。
:::

## 四张角色卡

四张卡按 **2024 版核心规则**建（玩家手册 / 城主指南 / 怪物图鉴，无扩展）：

- **27 点购点**定基础属性 → 叠加**背景属性加值**（2024 起物种不再给属性加值）→ 再叠加 **4 级属性提升**；熟练项只登记该角色拥有的属性相关条目；
- 额外加值只写**与属性检定相关**的部分；武器类加值（含魔法武器的 +1）须计入 `$武器$` 条目。

| 购点 | 15/10/13/8/10/15 | 8/15/14/15/10/8 | 8/15/14/10/14/10 | 14/8/15/8/15/10 |
| 背景属性加值 | 力量 +2、体质 +1 | 智力 +2、体质 +1 | 敏捷 +2、体质 +1 | 感知 +2、魅力 +1 |
| 4 级属性提升 | 力量 +1、魅力 +1 | 智力 +1、体质 +1 | 敏捷 +1、体质 +1 | 感知 +1、体质 +1 |
| 最终属性 | 18/10/14/8/10/16（+4/0/+2/−1/0/+3） | 8/15/16/18/10/8（−1/+2/+3/+4/0/−1） | 8/18/16/10/14/10（−1/+4/+3/0/+2/0） | 14/8/16/8/18/11（+2/−1/+3/−1/+4/0） |
| 生命值 | 10+2＋4×(6+2)＋10(健壮)＝**54** | 6+3＋4×(4+3)＝**37** | 8+3＋4×(5+3)＝**43** | 8+3＋4×(5+3)＋5(矮人刚毅)＝**48** |
| 生命骰 | 5×D10 | 5×D6 | 5×D8 | 5×D8 |
| 豁免熟练 | 感知、魅力 | 智力、感知 | 敏捷、智力 | 感知、魅力 |
| 技能熟练 | 士兵：运动、威吓；<br>职业：洞悉、游说；<br>物种：察觉 | 学者：奥秘、历史；<br>职业：调查、宗教；<br>物种：察觉 | 罪犯：巧手、隐匿；<br>职业：欺瞒、察觉、游说、洞悉 | 侍僧：洞悉、宗教；<br>职业：医药、游说 |
| 专精 | — | 奥秘（职业） | 隐匿、巧手（职业） | — |
| 武器熟练 | 长剑、标枪 | 匕首、轻弩 | 刺剑、匕首、短弓 | 战锤 |
| 武器精通 | 长剑（削弱）、标枪（缓速） | —（法师无此特性） | 刺剑（侵扰）、匕首（迅击） | —（牧师无此特性） |
| 额外加值 | —<br>（长剑 +1，非普通；加值计入武器项） | — | 隐匿:优势<br>（精灵之靴，非普通） | 隐匿:劣势（链甲）；<br>豁免:+1（防护斗篷，非普通） |
| 武器 | 长剑+8,1d8+5挥砍 | 火焰箭+7,2d10火焰；<br>匕首+5,1d4+2穿刺 | 刺剑+7,1d8+4穿刺；<br>匕首+7,1d4+4穿刺 | 战锤+5,1d8+2钝击 |

要点：
- **属性加值来自背景**（2024 起物种不再给属性加值，改为给特性）；
- **生命值**按「1 级取生命骰最大值 + 体质调整值，其后每级取职业固定值 + 体质调整值」计算（圣武士 6、牧师与游荡者 5、法师 4），再加上物种与专长的固定加值（矮人刚毅每级 +1、健壮每级 +2）；
- **熟练加值**（5 级）为 +3；
- **调整值**为 (属性 − 10) ÷ 2 向下取整；
- **额外加值**只登记算得进属性检定的部分，来源为 2024 城主指南的魔法物品（5–10 级开卡时给 1 件普通 + 1 件非普通）；
- **武器项**（`$武器$` 段）的数值：
    - 命中加值 = 攻击属性调整 + 熟练加值（+ 魔法加值）；
    - 伤害加值 = 攻击属性调整（+ 魔法加值）；
    - 伤害类型照武器实际记录（供伤害提示与后续特性使用），详见[武器与攻击](./weapons.md)。

## 群里的第一幕

开团前，群主把本群的服务打开（白名单机制下，未开启的群只有 `.bot` 可用）：

::: chat
白鸦 | @屠龙骰 .bot on
屠龙骰 | 本群服务已开启。
:::

随后四名玩家依次登记角色卡（记录时逐段解析，任何无效项都会整体拒收）：

::: chat

$子职$ 奉献之誓

## 示例时间线

| 阶段 | 内容 |
| --- | --- |
| ① 开群与建卡 | 群主开启本群服务；四名玩家登记角色卡 |
| ② 旅店试骰 | 出发前的掷骰（基本表达式、优势/劣势、暗骰、连掷） |
| ③ 探路检定 | 属性 / 技能 / 豁免检定点命令，含 DM 代掷 |
| ④ 碎星隘口遭遇战 | 批量先攻、战斗轮推进、HP / AOE / 抗性易伤结算（含 NPC 与亡灵） |
| ⑤ 战利与长休 | 战后恢复：长休、生命骰回复 |
| ⑥ 收尾与清场 | 清空先攻表与 NPC 血量记录 |
| ⑦ 石桥桥头遭遇战 | 第二场遭遇：DM 的整装备战、隐藏血量、三种伤害结算、暗骰与回合推进（见 [DM 实战指南](./dm-guide.md)） |
| ⑧ 散场前 | 散客小鹿入表并按名称结算、群默认骰面的设置与拒绝提示（见[命令总览](./overview.md)与[群管理与 FAQ](./faq.md)） |
| ⑨ 散场 | 群主关闭本群服务（`.bot off`） |

之后各功能页的示例，都取自这条时间线上对应的片段；出场人物、角色卡数值与本页一致。
