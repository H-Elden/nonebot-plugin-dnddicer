# 属性生成（.dnd / .dndx）

两者都按 DND5e 标准掷点法 **4D6K3** 生成六项属性：每项掷 4 个 D6、去掉最低的一个、剩余 3 个求和。区别只在**结果是否绑定属性名**：

| 命令 | 输出 | 适用场景 |
| --- | --- | --- |
| `.dnd` | 六项数值的**降序**列表（只出数值，不绑定） | 你想自行把数值分配给六属性 |
| `.dndx` | 数值按固定顺序**直接绑定属性名**（不降序排列） | 掷出即定，直接抄进角色卡 |

## 用法

```
.dnd [次数] [原因]
.dndx [次数] [原因]
```

| 参数 | 说明 |
| --- | --- |
| 次数 | 可选，默认 1、上限 10（越界回退 1）。`.` 与命令名后可直接接数字（`.dnd2` / `.dndx2` 与带空格写法等价） |
| 原因 | 可选（截断 50 字符），显示在结果标题中；给次数时跟在次数之后，省略次数时直接给出（`.dnd 开卡`） |

群聊与私聊均可使用；两个命令的次数/原因规则完全一致。

## `.dnd`：只出数值（自行分配）

::: chat
阿岚 | .dnd
屠龙骰 | 艾琳 DND人物作成:
83 : [18, 17, 14, 13, 12, 9]
:::

输出读法：`83` 是六项合计；`[18, 17, …]` 是六项数值的**降序**列表。示例中第一项 18 来自掷出 `6,6,6,1`（去掉 1 后 6+6+6）；每项属性都是这样独立掷出。

多组与原因：

::: chat
阿岚 | .dnd 2 为了勇者
屠龙骰 | 艾琳 DND人物作成——为了勇者:
108 : [18, 18, 18, 18, 18, 18]
108 : [18, 18, 18, 18, 18, 18]
:::

原因也可以省略次数直接给出：

::: chat
阿岚 | .dnd 为了勇者
屠龙骰 | 艾琳 DND人物作成——为了勇者:
108 : [18, 18, 18, 18, 18, 18]
:::

## `.dndx`：绑定属性名（不排序）

::: chat
阿岚 | .dndx
屠龙骰 | 艾琳 DND人物作成(属性绑定):
83 : 力量 18、敏捷 17、体质 14、智力 12、感知 9、魅力 13
:::

六项数值按 **力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力** 的固定顺序一一对应，**不降序排列**——上面这组 18 直接归力量、17 归敏捷、…、13 归魅力，掷出即定、无需再分配。

多组与原因写法同 `.dnd`：

::: chat
阿岚 | .dndx 2 为了勇者
屠龙骰 | 艾琳 DND人物作成(属性绑定)——为了勇者:
108 : 力量 18、敏捷 18、体质 18、智力 18、感知 18、魅力 18
108 : 力量 18、敏捷 18、体质 18、智力 18、感知 18、魅力 18
:::

> 注：标准购点（27 点）暂无先例（DicePP/海豹骰均无），本期未提供；如需购点建卡，可直接用 `.角色卡记录` 填写你购点得到的数值。

## 建卡衔接

`.dnd` 需先自行分配，再按 `力量/敏捷/体质/智力/感知/魅力` 的顺序写进 `$属性$`：

::: chat
阿岚 | .角色卡记录
$姓名$ 艾琳
$等级$ 1
$属性$ 18/14/13/12/9/17

注：自行分配：依次为 力量/敏捷/体质/智力/感知/魅力
屠龙骰 | 角色卡已设置
:::

`.dndx` 的结果顺序与角色卡 `$属性$` 行完全一致，**数值按序抄写即可**：

::: chat
阿岚 | .dndx
屠龙骰 | 艾琳 DND人物作成(属性绑定):
83 : 力量 18、敏捷 17、体质 14、智力 12、感知 9、魅力 13

阿岚 | .角色卡记录
$姓名$ 艾琳
$等级$ 1
$属性$ 18/17/14/12/9/13
屠龙骰 | 角色卡已设置
:::

角色卡与检定点命令见 [角色卡与检定](./character-card.md)。
