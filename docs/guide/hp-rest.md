# HP 管理（.hp 与 .长休）

`.hp` 管理 PC 与 NPC/怪物（见下文「NPC / 怪物血量」）的生命值（当前 HP / 最大 HP / 临时 HP），`.长休` 一键执行长休结算。命令**仅限群聊**；PC 数据挂在角色卡上（无卡时 `.hp 20/30` 会为发送者就地建立一条 HP 记录）。

## 查看与基础设置

```text
你发送：.hp 20/30
骰娘回复：艾琳: HP=20/30
当前HP:20/30
```

| 写法 | 含义 |
| --- | --- |
| `.hp 20/30` | 设置自己：当前 20 / 最大 30 |
| `.hp 20` | 只设置当前 HP |
| `.hp (10)` | 只设置临时 HP 10（括号为临时 HP） |
| `.hp 20/30 (10)` | 同时设置当前/最大/临时 |
| `.hp` | 查看自己的 HP 摘要 |
| `.hp 队友A 30/30` | 设置**队友**的 HP（目标见下节） |

临时 HP 是 5e 的额外血条——受伤时**临时 HP 先吸收伤害**，溢出部分才扣当前 HP：

```text
你发送：.hp 20/30 (10)
骰娘回复：艾琳: 临时HP=10
当前HP:20/30 (10)

你发送：.hp -15
骰娘回复：艾琳: 当前HP减少15
HP:20/30 (10) -> HP:15/30
```

## 伤害与治疗（+ / -）

```text
你发送：.hp -10
骰娘回复：艾琳: 当前HP减少10
HP:25/30 -> HP:15/30

你发送：.hp +15
骰娘回复：艾琳: 当前HP增加15
HP:15/30 -> HP:30/30        ← 治疗不超过最大 HP
```

调整值支持**掷骰表达式**（由引擎掷骰后结算）：

```text
你发送：.hp +2d6
骰娘回复：艾琳: 当前HP增加[3+4]=7
HP:20/30 -> HP:27/30

你发送：.hp 队友A -4d6     ← 对队友造成 4d6 伤害
```

HP 降至 0 → 昏迷（`昏迷` 标注）；随后治疗可唤醒：

```text
你发送：.hp -30
骰娘回复：艾琳: 当前HP减少30
HP:20/30 -> HP:0/30 昏迷

你发送：.hp +15
骰娘回复：艾琳: 当前HP增加15
HP:0/30 昏迷 -> HP:15/30
```

> 用 `-` 时若带目标前缀（`/` 或 `(` 开头的情况除外）会被识别为表达式而非目标——
> 例如 `.hp 爱丽丝 15/30` 中 `爱丽丝` 是目标、`15/30` 是设置值。

## 指定目标（队友 / NPC）

可指定的目标按 **PC 角色卡 → NPC 血量记录 → 先攻表** 三层查找（精确匹配优先
于部分匹配），用名称中**独一无二的一部分**即可匹配：

```text
你发送：.hp 爱丽丝 15/30
骰娘回复：爱丽丝: HP=15/30
当前HP:15/30
```

| 情况 | 提示 |
| --- | --- |
| 多个目标匹配同一关键字 | `存在多个匹配目标：['爱丽丝a', '爱丽丝b']`（换更精确的关键字） |
| 目标不存在 | `找不到XXX的生命值信息` + 新NPC提示（需先加入先攻表） |
| 一次调整多个目标 | 目标用 `;` 分隔（如 `.hp 爱丽丝;小刚 -5`） |

> 名称匹配为**精确优先的两级匹配**（与 `.init` 子指令一致）：先攻表/记录里同时
> 有「地精」与「熊地精」时，`.hp 地精 ...` 直接命中地精、`.hp 熊 ...` 命中熊地精；
> 没有完全匹配时才做子串匹配，命中多个则提示歧义。

### @ 指定玩家（DM 代操作）

用 **@群成员** 可直连该成员在本群的角色卡——不走名称搜索，因此不怕重名 NPC，
角色卡改名也不影响；@ 与名称可用 `;`（半角/全角）或空白混写：

```text
你发送：.hp @布兰克 -4d6           ← 对 @ 的玩家角色卡造成伤害
骰娘回复：布兰克: 当前HP减少[3+2+4]=9
HP:20/30 -> HP:11/30

你发送：.hp @布兰克 20/30 (5)      ← 设置 / 治疗（+10）/ 抗性·易伤后缀同理
你发送：.hp @布兰克易伤 -d8        ← 易伤后缀紧贴标记照常生效
你发送：.hp @布兰克;地精 -d8       ← 与 NPC 条目混写：AOE 一发结算
你发送：.hp @布兰克                ← 查看该玩家的 HP（可多个：.hp @布兰克 @莎白）
```

- @ 的目标需**已在本群建立角色卡**，否则回复 `@玩家 还没有在本群建立角色卡（可用 .角色卡记录 建卡后再试）`；
- **游离 @**（@ 没写在目标位置，如 `.hp -4d6 @布兰克`、`.hp 20/30 @布兰克`、`@布兰克 .hp -4d6`）
  **不执行**并回纠正示例——这些写法此前会静默按发送者自己结算，属易误伤写法；
- `@机器人自身` 不作为目标（`@骰娘 .hp -4d6` 仍按发送者自己结算）。

**无角色卡的队友**只要已用 `.ri` 加入先攻表（条目绑定其 QQ），DM 也能直接用其
名称结算；反馈落款走全插件统一的名称回退链（见[名称显示规则](../index.md#名称显示规则)）：

```text
你发送：.ri20            ← 队友在群里自己发（无卡：条目名取群名片）
骰娘回复：陈莉莉的先攻值是 20

你发送：.hp 陈莉莉-9     ← DM 结算
骰娘回复：陈莉莉: 当前HP减少9
损失HP:0 -> 损失HP:9
```

> 无最大 HP 的记录按「损失HP」累计受创（`损失HP:N` 表示已损失 N 点），
> 治疗先以「损失」回补至 0。要让其拥有正常的 `HP:x/y` 记录，先 `.hp 名称 当前/最大`，
> 或让该玩家用 `.角色卡记录` 建卡。

## DM 掷怪物伤害（推荐用法）

DM 可以把"掷怪物攻击伤害 + 扣血"一步完成：**目标写在前面，伤害表达式跟在 `-`
后面**。`-`（或 `+`）是 HP 命令的**操作符**，它之后的整段是一个掷骰表达式，
会**整体求值一次**作为本次伤害/治疗——表达式内部的 `+`/`-` 只是骰子算式
（先乘除与括号、加减从左到右），与 `.r` 的表达式规则一致。

```text
你发送：.hp 爱丽丝 -d8+3+d6
骰娘回复：爱丽丝: 当前HP减少[5]+3+[2]=10
HP:20/30 -> HP:10/30
```

> 上例掷出 d8=5、d6=2，总伤害 5+3+2=10。"伤害值再减 2"则写作 `-d12-2`
> （掷 d12 后整体减 2，即伤害 −2）。

### AOE：多个目标同时结算

目标用 `;` 分隔，伤害表达式**只掷一次**、对每个目标分别扣减：

```text
你发送：.hp 爱丽丝；莎白 -d12-2
骰娘回复：爱丽丝: 当前HP减少[7]-2=5; HP:20/30 -> HP:15/30
莎白: 当前HP减少[7]-2=5; HP:18/30 -> HP:13/30
```

### 目标的抗性与易伤

目标名后直接跟 **`抗性`**（伤害减半，向下取整、最少 1）或 **`易伤`**（伤害
加倍），即可在同一发 AOE 里对每个 PC 按各自承伤特性结算——不加后缀的按全额：

```text
你发送：.hp 爱丽丝抗性；莎白易伤；布莱克 -d12-2
骰娘回复：爱丽丝: 当前HP减少[7]-2=5（抗性减半→2）; HP:20/30 -> HP:18/30
莎白: 当前HP减少[7]-2=5（易伤加倍→10）; HP:18/30 -> HP:8/30
布莱克: 当前HP减少[7]-2=5; HP:15/30 -> HP:10/30
```

> `抗性`/`易伤` 后缀只对伤害（`-`）生效；用于设置/治疗会提示错误。
> 结算顺序：临时 HP 先吸收，溢出再扣当前 HP；降至 0 昏迷。
> **伤害与治疗的最低值为 0**：表达式算出负值时（如 `.hp 向导 -d12-2` 掷出 1）
> 不会反向加血或掉血，按 0 计并在结果中标注「伤害最低为0」（`.r` 表达式里
> 自带的 `抗性`/`易伤` 后缀同样受限）。

## NPC / 怪物血量

NPC 血量支持**自动回满**（同名 NPC 视为新个体）与**跨战斗保持**（`.npc 持久`），
记录独立于角色卡，**先 `.ri` 入先攻表、再 `.hp` 记录**：

```text
你发送：.ri20 哥布林
骰娘回复：哥布林的先攻值是 20

你发送：.hp 哥布林 20/20
骰娘回复：哥布林: HP=20/20
当前HP:20/20
```

记录会随先攻列表与 `.hp list` 一起展示（PC 在前、NPC 在后），`.hp del 哥布林`
可单独删除；DM 可以用与 PC 相同的语法替 NPC 结算伤害（含 `抗性`/`易伤` 后缀与
AOE 多目标）。

### 自动回满：同名 NPC 视为新个体

新一场战斗中再次把 NPC 加入先攻表时，**设过上限的血量记录会自动回满**，并在
先攻结果后附上提示——同名 NPC（如多只「地精」）通常不是同一只：

```text
你发送：.ri15 哥布林
骰娘回复：哥布林的先攻值是 15
注：哥布林 已自动回满 20/20（上次 16/20）
如需沿用上次血量:
.hp 哥布林 16/20
如需跨战斗保持血量:
.npc 持久 哥布林
```

- 提示里的 `.hp 哥布林 16/20` 可直接复制发送，沿用上次战斗结束时的血量；
- 同名条目在**同一场战斗中重掷先攻**不会触发回满（不会误清已受的伤害）；
- 未设上限、只记录受损（`损失HP:N`）的记录不参与回满。

### 跨战斗保持血量（.npc 持久）

需要跨战斗延续血量的 NPC（长期随队的向导、反复登场的对手等），用
`.npc 持久 名称` 一次性标记：之后每次入先攻表都保持原血量、不再自动回满；
`.npc 临时 名称` 恢复默认。目标可用名称中独一无二的一部分，血量记录需已存在：

```text
你发送：.npc 持久 向导
骰娘回复：已将NPC「向导」设为跨战斗保持血量（.ri 再次入表时不再自动回满）
```

### 清空与清理

三种清理各管一段，按需选用：

| 方式 | 清理范围 |
| --- | --- |
| `.init clr` / `.br` | 清空先攻表，并清理 NPC 的**临时血量**（未设上限、只记受损的条目） |
| `.init del 名称` | 删除单个先攻条目，一并删除其血量记录 |
| `.hp del 名称` / `.hp clr` | 删除单个 / 清空全部 NPC 血量记录（不动先攻表，见下节） |

设过上限的记录与 `.npc 持久` 标记的记录在前两者中保留；`.hp clr` 则包含它们
（属显式清理）。

## 查看列表与删除

```text
你发送：.hp list
骰娘回复：战士小明 HP:20/30
阿强 HP:15/25
```

- `.hp list` 列出**本群全部 PC 与 NPC** 的 HP（PC 在前、NPC 在后）；无记录时提示「本群没有任何生命值信息」；
- 列表与目标结算反馈的名称回退链与全插件一致：**角色卡名 → 群名片 → QQ 昵称 → 「未知玩家（QQ号）」**（见[名称显示规则](../index.md#名称显示规则)）；
- **删除只作用于 NPC 血量记录**（与 `.init` 的 `del`/`clr` 同形）：

| 命令 | 作用 |
| --- | --- |
| `.hp del 名称` | 删除单个 NPC 血量记录（多个用 `/` 分隔，如 `.hp del 哥布林a/哥布林b`） |
| `.hp clr` | 清空**本群全部** NPC 血量记录（含跨战斗保持的），回「已清空N条NPC血量记录」 |

```text
你发送：.hp del 哥布林
骰娘回复：已删除哥布林的生命值信息

你发送：.hp clr
骰娘回复：已清空3条NPC血量记录
```

- `.hp del`（无对象）不会删除任何东西，只提示用法；
- 目标解析为**玩家角色卡**时不会被删除，而是提示改用 `.角色卡清除`；用 `@玩家`
  指定时会附带「移除玩家先攻条目请用 `.init del` 该玩家」的引导；
- PC 的血量无需删除——直接 `.hp 20/30` 覆盖设置即可；`.hp` 无记录时提示 `找不到艾琳的生命值信息`。

## 长休（.长休）

```text
你发送：.长休
骰娘回复：艾琳进行了一次长休
生命值回复至上限(30) 5点临时生命值失效
回复2个生命骰, 当前拥有4/4个D8生命骰
```

DM 可代不在场的玩家收尾：`.长休 @玩家` 用该玩家的角色卡结算（回复落款取其角色名；
无卡时给出真 @ 引导建卡）：

```text
你发送：.长休 @艾琳
骰娘回复：艾琳进行了一次长休
生命值回复至上限(30) 5点临时生命值失效
回复2个生命骰, 当前拥有4/4个D8生命骰
```

规则：HP 回复至上限、临时 HP 清零、生命骰回复一半（不足 1 按 1）。需要角色卡上记录了 `$生命值$`（含当前值）与 `$生命骰$`（如 `2/4 D8`）。未记录生命骰时只结算 HP 与临时 HP；无角色卡提示 `找不到艾琳的角色卡信息`。
