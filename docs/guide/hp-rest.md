# HP 与长休

`.hp` 管理全场的生命值（当前 / 最大 / 临时），`.长休` 一键做长休结算。玩家的 HP 挂在角色卡上（改的就是卡里的 `$生命值$`），NPC 与怪物则是**独立于角色卡**的血量记录。

命令**仅限群聊**。示例取自示例团在碎星隘口遭遇战中的结算。

## 记录与查看（.hp）

没建卡也能记录，小鹿给自己的角色记了一条：

::: chat
小鹿 | .hp 20/30
屠龙骰 | 小鹿: HP=20/30
当前HP:20/30
小鹿 | .hp
屠龙骰 | 小鹿: HP:20/30
:::

| 写法 | 含义 |
| --- | --- |
| `.hp 20/30` | 设置自己：当前 20 / 最大 30 |
| `.hp 12` | 只改当前 HP（最大与临时保留） |
| `.hp (5)` | 只设临时 HP 5（括号内为临时 HP） |
| `.hp 20/30 (5)` | 一次设全：当前 / 最大 / 临时 |
| `.hp` | 查看自己的摘要 |
| `.hp @玩家` | 查看该玩家的摘要（多名用空格或 `;` 分隔） |
| `.hp 队友 30/30` | 设置**他人**（目标写法见[下节](#目标怎么找)） |
| `.hp list` | 列出本群全部 PC 与 NPC 的血量 |

## 伤害与治疗（+ / -）

`-` 扣血、`+` 回血，冒号后既可以是数字，也可以是一段**掷骰表达式**（由骰娘掷出后结算），更推荐是 `X伤害` 的形式。DM 掷怪伤害、扣血一步到位：

::: chat
白鸦 | .hp 薇拉 -d8+3+d6
屠龙骰 | 薇拉: 当前HP减少[7]+3+[4]=14
HP:54/54 -> HP:40/54
:::

第一个 `-`（或 `+`）是 HP 命令的**操作符**，它之后的整段 `d8+3+d6` 是一个掷骰表达式，整体求值一次。

`X伤害` 的形式更省事：伤害位置直接写角色卡上的武器名（默认**发送者本人**，也可用尾部括号指定来源），与[武器与攻击](./weapons.md)的 `.X伤害` 完全同款，`副手` / `重击` / `偷袭` 后缀与 `±` 临时加值都支持（如 `-战锤重击伤害+1d4`），不必每次手写算式；回复先报「谁用哪件武器造成了多少伤害」，再列出每个目标的扣血读数：

::: chat
阿岩 | .hp 骷髅a易伤 -战锤伤害
屠龙骰 | 布鲁姆用【战锤】造成了 10 点钝击伤害：
骷髅a: 当前HP减少[3]+2=5（易伤加倍→10）
HP:13/13 -> HP:3/13
:::

注：表头报的是**实际结算值**：单目标时按抗性/易伤折算（本例掷出 5 → 造成 10）；一发多目标时报掷出的原始值，折算逐目标在各自行里体现。

DM 代不在场的玩家结算时，把**武器来源**写在尾部括号里（角色名支持模糊匹配、中英文括号皆可，也可以直接 @玩家）：

::: chat
白鸦 | .hp 骷髅b易伤 -火焰箭伤害（洛恩）
屠龙骰 | 洛恩用【火焰箭】造成了 4 点火焰伤害：
骷髅b: 当前HP减少[1+1]=2（易伤加倍→4）
HP:13/13 -> HP:9/13
白鸦 | .hp 骷髅b -匕首伤害（@小满）
屠龙骰 | 洛恩用【匕首】造成了 3 点穿刺伤害：
骷髅b: 当前HP减少[1]+2=3
HP:9/13 -> HP:6/13
:::

伤害位置只认「伤害」，写成「攻击 / 命中」会被拦下并引导：

::: chat
阿岩 | .hp 骷髅a易伤 -战锤攻击
屠龙骰 | 「战锤攻击」是攻击检定而非伤害掷骰，请用「战锤伤害」！
:::

表达式内部的 `+`/`-` 只是骰子算式（先乘除与括号、加减从左到右），与 `.r` 完全一致。治疗不会超过最大 HP，超出部分截断：

::: chat
阿岩 | .hp 薇拉 +2d8+4
屠龙骰 | 薇拉: 当前HP增加[3+4]+4=11
HP:40/54 -> HP:51/54
:::

「多段伤害一次结算」时有个语义坑：操作符后的整段是**一个算式**，不是逐笔扣减。想让「8 和 5 都算伤害」，写法是 `-8+5`（`-` 已代表扣血）：

::: chat
白鸦 | .hp 薇拉 -8-5
屠龙骰 | 薇拉: 当前HP减少8-5=3
HP:51/54 -> HP:48/54

注：错误：不是「先扣 8 再扣 5」，`8-5` 先算出 3，实际只扣 3。

白鸦 | .hp 薇拉 -(8+5)
屠龙骰 | 薇拉: 临时HP减少8+5=13
HP:48/54 -> HP:48/54

注：错误：也别用括号求稳，`.hp` 里**末尾的括号是临时 HP 的位置**（`.hp (10)`），这一发被当成「减少临时 HP」，HP 纹丝不动。

白鸦 | .hp 薇拉 -8+5
屠龙骰 | 薇拉: 当前HP减少8+5=13
HP:48/54 -> HP:35/54

注：正确：`-8+5` = 扣 13（操作符之后接整段伤害算式）。
:::

## 临时 HP

临时 HP 是 5e 的「额外血条」：受伤时**先扣临时 HP**，溢出部分才扣当前 HP。洛恩 用虚假生命给自己挂了 10 点，随后挨了狼一口：

::: chat
小满 | .hp (10)
屠龙骰 | 洛恩: 临时HP=10
当前HP:37/37 (10)
白鸦 | .hp 洛恩 -13
屠龙骰 | 洛恩: 当前HP减少13
HP:37/37 (10) -> HP:34/37
:::

10 点临时 HP 全部吸收，超出的 3 点才扣到当前 HP（37 → 34）。

## 归零与倒地

HP 降至 0 会被标上 `昏迷`；治疗可当场唤醒：

::: chat
白鸦 | .hp 薇拉 -51
屠龙骰 | 薇拉: 当前HP减少51
HP:35/54 -> HP:0/54 昏迷
阿岩 | .hp 薇拉 +15
屠龙骰 | 薇拉: 当前HP增加15
HP:0/54 昏迷 -> HP:15/54
:::

> 上例是 DM 直接结算的伤害数值：`.hp 目标 -数值` 里的数字由 DM 按桌面裁定输入（怪物暴击、坠落、陷阱…都走同一条路）。

## 目标怎么找

不带目标时默认是自己；写了目标则在**PC 角色卡 → NPC 血量记录 → 先攻表**三层里按名称查找，**精确优先、其次部分匹配**，写名称中**最独一无二的一部分**即可：

::: chat
白鸦 | .hp 熊 -8
屠龙骰 | 熊地精: 当前HP减少8
HP:17/27 -> HP:9/27
:::

命中多个时报歧义、列出候选；三层都找不到时给出新 NPC 的引导（怪物要先入先攻表）：

::: chat
白鸦 | .hp 大魔头 -8
屠龙骰 | 找不到大魔头的生命值信息
新NPC需要先加入先攻表才可设置HP
白鸦 | .hp 哥布林 -8
屠龙骰 | 存在多个匹配目标：['哥布林a', '哥布林b']
:::

### @ 指定玩家（DM 代结算）

用 **@群成员** 可直连该成员在本群的角色卡，不走名称搜索，不怕重名 NPC、角色卡改名也不影响：

::: chat
白鸦 | .hp @小满 -2d6
屠龙骰 | 洛恩: 当前HP减少[4+3]=7
HP:34/37 -> HP:27/37
:::

**游离 @ 会被拦下**：@ 必须写在目标位置（命令后、表达式前），写在别处不执行、并回纠正示例，避免静默按发送者自己结算：

::: chat
白鸦 | .hp -d6 @小满
屠龙骰 | 未执行：目标请写在目标位置，例如 .hp @小明 -d4
:::

@ 与名称可以混写、用 `;` 或空格分隔（一发 AOE 同时结算玩家与怪物）；@ 的目标需已建卡，否则回复真 @ 引导。

> 没有角色卡的队友若已经用 `.ri` 入过先攻表（条目绑定了他的 QQ），DM 也能直接用其名称结算；只是他的名字不在角色卡层，名称匹配会落到先攻表层。

## AOE：一发多目标

目标之间用 `;`（半角/全角皆可）分隔，伤害表达式**只掷一次**、对每个目标分别扣减，洛恩的火球术笼罩了两只怪物：

::: chat
白鸦 | .hp 哥布林a;狼 -8d6
屠龙骰 | 哥布林a: 当前HP减少[3+5+2+6+4+1+5+3]=29; HP:7/7 -> HP:0/7 昏迷
狼: 当前HP减少[3+5+2+6+4+1+5+3]=29; 损失HP:0 -> 损失HP:29
:::

两个目标的读数不同：`哥布林a` 记录过最大 HP，显示 `HP:当前/上限`；`狼` 只记过受损，显示 `损失HP:累计`（见[关底 Boss 或初见之敌](#关底-boss-或初见之敌-只记损失)）。

## 抗性与易伤

目标名后直接跟 **`抗性`**（伤害减半，向下取整、最少 1）或 **`易伤`**（伤害加倍），即可按各自的承伤特性结算：

::: chat
白鸦 | .hp 布鲁姆抗性 -2d6
屠龙骰 | 布鲁姆: 当前HP减少[5+3]=8（抗性减半→4）
HP:48/48 -> HP:44/48
阿岩 | .战锤攻击
屠龙骰 | 布鲁姆进行【战锤攻击检定】：
武器命中加值:+5
1D20+5=[14]+5=19
白鸦 | .hp 骷髅易伤 -d8+2
屠龙骰 | 骷髅: 当前HP减少[6]+2=8（易伤加倍→16）
损失HP:9 -> 损失HP:25
:::

上例两种承伤特性都来自规则本身：布鲁姆是矮人（毒素伤害有抗性），骷髅对钝击伤害易伤，DM 把结论写进目标名后即可。

**一发多目标时逐目标声明**，每个目标各挂各的后缀（`;` 半角 / 全角皆可），一发里可以既有抗性也有易伤：

::: chat
白鸦 | .hp 布鲁姆抗性；洛恩 -2d6
屠龙骰 | 布鲁姆: 当前HP减少[5+3]=8（抗性减半→4）; HP:44/48 -> HP:40/48
洛恩: 当前HP减少[5+3]=8; HP:27/37 -> HP:19/37
白鸦 | .hp 布鲁姆抗性;洛恩易伤 -2d6
屠龙骰 | 布鲁姆: 当前HP减少[5+3]=8（抗性减半→4）; HP:40/48 -> HP:36/48
洛恩: 当前HP减少[5+3]=8（易伤加倍→16）; HP:19/37 -> HP:3/37
:::

后缀也可以写在**伤害表达式里**（引擎级别的别名，`.r` 里同样可用）：

::: chat
白鸦 | .hp 布鲁姆 -2d6抗性
屠龙骰 | 布鲁姆: 当前HP减少[5+3]/2=4
HP:36/48 -> HP:32/48
:::

两种写法都成立，**推荐写在目标名后**，读数里会标注「（抗性减半→N）」，AOE 时还能逐目标区分：

| 写法 | 读数 | 减半的取整 | 一发多目标 |
| --- | --- | --- | --- |
| 目标名后缀（推荐） | `[5+3]=8（抗性减半→4）` | 向下取整、**最少 1** | 可逐目标声明不同的后缀 |
| 表达式内后缀 | `[5+3]/2=4` | 纯向下取整，没有「最少 1」的保底 | 对整段算式生效，所有目标一视同仁 |

> 后缀不能连写（`.hp 布鲁姆 -2d6抗性易伤` 不会被识别）；按 5e 规则，同一目标若两者兼有则相互抵消、按正常伤害结算，此时不带后缀写即可。

- `抗性` / `易伤` 后缀**只对伤害（`-`）生效**，用于设置或治疗会提示错误；
- 结算顺序固定：临时 HP 先吸收 → 溢出扣当前 HP → 降至 0 昏迷；
- 伤害与治疗**最低按 0 计**：表达式算出负值时不会反向回血，并按 0 结算。

## NPC / 怪物血量

NPC 与怪物的血量记录**独立于角色卡**（PC 的挂在卡上），并且要**先入先攻表**才能按名称记录、结算。按「想让玩家看到多少」，DM 一般有三种处理方式：

### 寻常小怪：公开血量

杂兵、已经交过手的怪物不必保密，入表后记一记「当前 / 上限」，之后就能与 PC 一样结算（`.hp 哥布林a -d8+4`），`.init` 与 `.hp list` 里也都带着读数：

::: chat
白鸦 | .hp 熊地精 27/27
屠龙骰 | 熊地精: HP=27/27
当前HP:27/27
:::

同名小怪还有一条省事的规则：**新一场战斗中入表即自动回满**（同名视为新个体）：

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
白鸦 | .ri-1 哥布林b
屠龙骰 | 哥布林b的先攻值是 1D20-1=[4]-1=3
注：哥布林b 已自动回满 7/7（上次 1/7）
如需沿用上次血量:
.hp 哥布林b 1/7
如需跨战斗保持血量:
.npc 持久 哥布林b
:::

提示里的 `.hp … 当前/上限` 可直接复制发送，沿用上次战斗结束时的血量；**同一场战斗中重掷先攻不会触发回满**（不会误清已受的伤害）；未设上限、只记受损的记录也不参与回满。

### 关底 Boss 或初见之敌：只记损失

不想公布具体血量时**不设上限、直接扣血**，读数变成「累计损失」（`损失HP:n`），玩家只能推断它掉了多少：

::: chat
白鸦 | .hp 骷髅 -d8+4
屠龙骰 | 骷髅: 当前HP减少[5]+4=9
损失HP:0 -> 损失HP:9
:::

治疗会先把「损失」补回 0；想让某个怪物改用公开读数，补一次 `.hp 名称 当前/上限` 即可。

### 友军 NPC：跨战斗保持

随队 NPC（向导、保镖、长期雇佣兵）同样要入先攻表、同样会挨打，但血量应当延续到下一场，而不是每战回满：

::: chat
白鸦 | .hp 向导 22/22
屠龙骰 | 向导: HP=22/22
当前HP:22/22
白鸦 | .hp 向导 -8
屠龙骰 | 向导: 当前HP减少8
HP:22/22 -> HP:14/22
:::

用 `.npc 持久 名称` 标记一次即可，此后每次入表都保持原血量、不再自动回满（`.npc 临时 名称` 恢复默认）：

::: chat
白鸦 | .npc 持久 向导
屠龙骰 | 已将NPC「向导」设为跨战斗保持血量（.ri 再次入表时不再自动回满）
:::

目标可用名称中独一无二的一部分，**血量记录需已存在**。标记后再入表，血量原样保留。同一场遭遇里，哥布林b 回了满、向导 保持 14/22：

::: chat
白鸦 | .ri+1 向导
屠龙骰 | 向导的先攻值是 1D20+1=[9]+1=10
白鸦 | .init
屠龙骰 | 先攻列表如下: 
当前是第1轮,向导的回合
1.向导 先攻:10 HP:14/22
2.哥布林b 先攻:3 HP:7/7
:::

### 查看与清理

::: chat
白鸦 | .hp list
屠龙骰 | 薇拉 HP:54/54
洛恩 HP:37/37
塔莉 HP:43/43
布鲁姆 HP:32/48
熊地精 HP:9/27
向导 HP:14/22
哥布林a HP:0/7 昏迷
哥布林b HP:7/7
白鸦 | .hp del 哥布林a
屠龙骰 | 已删除哥布林a的生命值信息
白鸦 | .hp clr
屠龙骰 | 已清空3条NPC血量记录
白鸦 | .hp list
屠龙骰 | 薇拉 HP:54/54
洛恩 HP:37/37
塔莉 HP:43/43
布鲁姆 HP:32/48
:::

`.hp list` 里 **PC 在前、NPC 在后**，名称走全插件统一的回退链（角色名 → 群名片 → QQ 昵称，见[名称显示规则](./overview.md#名称显示规则)）。

| 命令 | 作用 |
| --- | --- |
| `.hp del 名称` | 删除单个 NPC 血量记录（多个用 `/` 分隔） |
| `.hp clr` | 清空本群全部 NPC 血量记录 |
| `.init del 名称` / `.init clr` / `.br` | 先攻条目的删除 / 清表会**一并清理**对应的 NPC 临时血量（未设上限、只记受损的记录）；设过上限与 `.npc 持久` 的记录保留 |

- `.hp del` / `.hp clr` **只作用于 NPC**：目标是玩家角色卡时会提示改用 `.角色卡清除`；PC 的血量不需要删，直接 `.hp 20/30` 覆盖即可。

## 长休（.长休）

::: chat
阿茶 | .长休
屠龙骰 | 薇拉进行了一次长休
生命值回复至上限(54)
回复0个生命骰, 当前拥有5/5个D10生命骰
白鸦 | .长休 @小满
屠龙骰 | 洛恩进行了一次长休
生命值回复至上限(37) 10点临时生命值失效
回复0个生命骰, 当前拥有5/5个D6生命骰
:::

结算三件事：**HP 回复至上限**、**临时 HP 清零**（有剩余时会提示失效）、**回复一半生命骰**（回复量为总数的一半向下取整、至少 1，且不超过总数）。生命骰信息来自卡上的 `$生命骰$`，格式为 `当前/总数 D骰面`：示例团刚建卡、生命骰还是满的（`5/5`），所以显示回复 0 个；若已消耗 3 颗（`2/5 D8`），长休回复 2 颗、变成 `4/5`。

DM 可代不在场的玩家收尾：`.长休 @玩家` 用该玩家的角色卡结算；无卡时给出真 @ 引导建卡。

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `.hp` | `.hp [目标] [±数值/表达式] [(临时)]` | 记录 / 伤害 / 治疗；目标支持名称、`;` 多目标与 `@玩家` |
