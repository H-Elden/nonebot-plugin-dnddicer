# HP 管理（.hp 与 .长休）

`.hp` 管理 PC 的生命值（当前 HP / 最大 HP / 临时 HP），`.长休` 一键执行长休结算。
命令**仅限群聊**；数据挂在角色卡上（无卡时 `.hp 20/30` 会为发送者就地建立一条 HP 记录）。

## 查看与基础设置

```text
你发送：.hp 20/30
骰娘回复：艾琳: HP=20/30
当前HP:20/30
```

| 写法 | 含义 |
| --- | --- |
| `.hp 20/30` | 设置自己：当前 20 / 最大 30 |
| `.hp 20` | 只设置当前 HP |
| `.hp (10)` | 只设置临时 HP 10（括号为临时 HP） |
| `.hp 20/30 (10)` | 同时设置当前/最大/临时 |
| `.hp` | 查看自己的 HP 摘要 |
| `.hp 队友A 30/30` | 设置**队友**的 HP（目标见下节） |

临时 HP 是 5e 的额外血条——受伤时**临时 HP 先吸收伤害**，溢出部分才扣当前 HP：

```text
你发送：.hp 20/30 (10)
骰娘回复：艾琳: 临时HP=10
当前HP:20/30 (10)

你发送：.hp -15
骰娘回复：艾琳: 当前HP减少15
HP:20/30 (10) -> HP:15/30
```

## 伤害与治疗（+ / -）

```text
你发送：.hp -10
骰娘回复：艾琳: 当前HP减少10
HP:25/30 -> HP:15/30

你发送：.hp +15
骰娘回复：艾琳: 当前HP增加15
HP:15/30 -> HP:30/30        ← 治疗不超过最大 HP
```

调整值支持**掷骰表达式**（由引擎掷骰后结算）：

```text
你发送：.hp +2d6
骰娘回复：艾琳: 当前HP增加[3+4]=7
HP:20/30 -> HP:27/30

你发送：.hp 队友A -4d6     ← 对队友造成 4d6 伤害
```

HP 降至 0 → 昏迷（`昏迷` 标注）；随后治疗可唤醒：

```text
你发送：.hp -30
骰娘回复：艾琳: 当前HP减少30
HP:20/30 -> HP:0/30 昏迷

你发送：.hp +15
骰娘回复：艾琳: 当前HP增加15
HP:0/30 昏迷 -> HP:15/30
```

> 用 `-` 时若带目标前缀（`/` 或 `(` 开头的情况除外）会被识别为表达式而非目标——
> 例如 `.hp 爱丽丝 15/30` 中 `爱丽丝` 是目标、`15/30` 是设置值。

## 指定目标（队友 / NPC 占位）

目标是**群内已有角色卡（或 HP 记录）的玩家**，可用名称中**独一无二的一部分**匹配：

```text
你发送：.hp 爱丽丝 15/30
骰娘回复：爱丽丝: HP=15/30
当前HP:15/30
```

| 情况 | 提示 |
| --- | --- |
| 多个目标匹配同一关键字 | `存在多个匹配目标：['爱丽丝a', '爱丽丝b']`（换更精确的关键字） |
| 目标不存在 | `找不到XXX的生命值信息` |
| 一次调整多个目标 | 目标用 `;` 分隔（如 `.hp 爱丽丝;小刚 -5`） |

## 查看列表与删除

```text
你发送：.hp list
骰娘回复：战士小明 HP:20/30
阿强 HP:15/25
```

- `.hp list` 列出**本群全部 PC** 的 HP；无记录时提示「本群没有任何生命值信息」；
- 列表名称回退链：**角色卡名 → 群名片 → QQ 昵称 → 「未知玩家」**（API 查询失败也不显示 QQ 号）；
- `.hp del` 删除自己的 HP 记录；`.hp` 无记录时提示 `找不到艾琳的生命值信息`。

## 长休（.长休）

```text
你发送：.长休
骰娘回复：艾琳进行了一次长休
生命值回复至上限(30) 5点临时生命值失效
回复2个生命骰, 当前拥有4/4个D8生命骰
```

规则：HP 回复至上限、临时 HP 清零、生命骰回复一半（不足 1 按 1）。
需要角色卡上记录了 `$生命值$`（含当前值）与 `$生命骰$`（如 `2/4 D8`）。
未记录生命骰时只结算 HP 与临时 HP；无角色卡提示 `找不到艾琳的角色卡信息`。

## 相关
