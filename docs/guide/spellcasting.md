# 法术与施法

法术清单、法术位与 `.施法` 的完整用法。角色的 `$法术$` 与 `$法术位$` 两段都记在角色卡上，骰娘按卡面记账，不内置法术数值库、不查规则索引。休息时如何恢复法术位与准备提醒见[休息与资源](./resources.md)。

> 本页命令**仅限群聊**，且需要先在本群绑定角色卡（见[角色卡录入](./character-card.md)）。环阶、伤害、治疗量与升环效应全部来自卡面；两版规则的差异由[群级规则版本](./rules-version.md)决定。

## 法术清单与准备

`$法术$` 每项写成 `法术名:环阶`，`0` 表示戏法；尾部加 `*` 表示**今日已准备**。先用 `施法属性:属性` 记下施法属性，再用 `豁免DC` / `法术攻击` 记下全局施法数值。战斗数据写在同一条目的 `|` 之后：`类型` 是施法方式，`伤害` 写表达式加类型，`治疗` 写完整治疗表达式，`多发` 写逐发次数，`豁免` / `成功` / `升环` 按需填写；`时间` / `距离` / `专注` / `仪式` / `材料` / `备注` 只用于卡面展示：

```
$法术$ 施法属性:智力; 豁免DC:15; 法术攻击:+7;
火球术:3*|类型:豁免|豁免:敏捷|成功:半伤|伤害:8d6火焰|升环:+1d6|时间:1动作|距离:150尺;
火焰箭:0|类型:攻击|伤害:2d10火焰|时间:1动作|距离:120尺;
魔法飞弹:1*|类型:自动|伤害:1d4+1力场|多发:3|升环:+1发
```

`类型` 可选 `攻击` / `豁免` / `自动` / `辅助` / `治疗` / `特殊`；攻击型的攻击加值默认继承头键 `法术攻击`，豁免型的 DC 默认继承头键 `豁免DC`，条目里写 `攻击:` / `DC:` 可以单独覆盖。伤害支持多段多类型，用 `+` 连接（如 `2d10钝击+4d6寒冷`）；豁免型写了伤害就必须写 `成功:半伤` 或 `成功:无伤`。`多发:N` 只用于攻击型与自动型：攻击型逐发掷攻击，自动型在 `.施法` 时逐发掷伤害；伤害命令默认只掷一次。

`治疗` 只用于治疗型，写完整表达式（如 `2d4+3`、`70`），骰娘不自动加施法属性调整值；治疗型必须写 `治疗`，不能写 `伤害` / `多发` / `攻击` / `豁免` / `DC` / `成功`。升环加骰（`+2d4`）与固定值（`+10`）都会按环差自动叠加。

洛恩的卡上录了五个法术，清单按环阶从低到高排列，同环内保持卡面录入顺序（卡面 `$法术$` 仍按录入顺序保存）；`.法术` 会标出环阶与准备状态：

1. 火焰箭 戏法
2. 魔法飞弹 1环（已准备）
3. 护盾术 1环（已准备）
4. 火球术 3环（已准备）
5. 闪电束 3环
用法：.法术 准备/取消 名称；记录用 .设置法术 名称:环阶
:::

:::

`.设置法术` 与 `.删除法术` 负责改卡，`.法术 准备/取消` 只切换当日的准备标记：

::: chat

1. 火焰箭 戏法
2. 护盾术 1环（已准备）

屠龙骰 | 已删除法术: 魔法飞弹
:::

- `.法术`：查看法术清单；
- `.法术 准备 名称` / `.法术 取消 名称`：切换 `*` 标记（名称支持模糊匹配；戏法无需准备）；
- `.法术 提醒 on|off`：记录本群的**施法未准备提醒**开关，默认开（按群保存，供 `.施法` 判定）；
- `.设置法术 名称:环阶[*][|类型:…|伤害:…|治疗:…|豁免:…|升环:…]`：录入或覆盖（多项用 `;` 分隔；可写 `施法属性:智力`、`豁免DC:15`、`法术攻击:+7`；`|` 之后写战斗字段与卡面详情）；
- `.删除法术 名称`：删除（支持模糊匹配，多个用 `/` 分隔）。

普通 `.设置法术` 只改环阶，不会抹掉已有的准备标记与卡面详情（写了 `|详情` 才整组覆盖）；要取消准备请用 `.法术 取消`。

## 法术位

`$法术位$` 每项写成 `环阶:当前/上限`，契约魔法写 `契约N:当前/上限`：

```
$法术位$ 1:4/4; 2:3/3; 3:2/2; 契约3:2/2
```

洛恩的查看、设置、手动消耗与恢复：

::: chat
小满 | .法术位
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 set 1:4; 2:3; 3:2/2
屠龙骰 | 已设置法术位：1环 4/4、2环 3/3、3环 2/2
当前法术位：
1环：4/4
2环：3/3
3环：2/2
小满 | .法术位 3 -1
屠龙骰 | 3环：2/2 → 1/2
小满 | .ss
屠龙骰 | 当前法术位：
1环：4/4
2环：3/3
3环：1/2
小满 | .法术位 reset
屠龙骰 | 已恢复全部法术位：
1环：4/4
2环：3/3
3环：2/2
:::

- `.法术位` / `.ss`：查看当前法术位；写 `@玩家` 或角色名可查看他人；
- `.法术位 set 1:4; 2:3`：设置（只写一个数表示当前与上限都设为它；写 `3:2/2` 可分别指定；多项用 `;` 分隔）；
- `.法术位 3 -1` / `.法术位 契约 -1`：手动消耗（`+1` 为恢复，缺省 1 次，不会越过 0 与上限）；
- `.法术位 reset`：全部恢复到上限（长休规则）。

## 代操作法术位

DM 可以替不在场的玩家查看与调整法术位，目标写法与 `.能力` 相同：目标写在命令最前面，可以是 `@玩家`，也可以是本群角色名；名称匹配精确优先、其次子串，多候选只列清单不猜。目标只从本群已绑定角色卡里找，不走 NPC 或先攻表。

::: chat
白鸦 | .法术位 @小满
屠龙骰 | 洛恩的法术位：
1环：2/4
2环：2/3
3环：0/2
白鸦 | .法术位 洛恩 1 -1
屠龙骰 | 洛恩的1环：2/4 → 1/4
:::

`.法术` / `.设置法术` / `.删除法术` / `.施法` 仍只作用于本人。通用目标规则见[休息与资源](./resources.md#代操作目标)。

## 施法

`.施法 法术名[环阶修饰]` 按卡面 `$法术$` 与 `$法术位$` 结算，**环阶一律来自卡面，不查索引、不发网络请求**：

- `.施法 火球术`：用录入环阶（3 环）；
- `.施法 火球术4` / `.施法 火球术4环`：**绝对升环**，用 4 环位施展 3 环法术；
- `.施法 火球术+1` / `.施法 火球术+1环`：**相对升环**，录入环阶 +1；
- `.施法 2` / `.施法 2环`：只指定环阶，直接消耗 1 个 2 环位；
- `.施法 火焰箭 优势` / `.施法 火焰箭 劣势`：攻击型法术的攻击检定取优/劣势；
- 戏法（0 环）不消耗法术位，也不需要准备。

`.施法` 按条目的 `类型` 自动结算：

| 类型 | 自动掷什么 | 说明 |
| --- | --- | --- |
| `攻击` | D20 + 法术攻击加值 | 只掷攻击；命中后用 `.法术名伤害` 掷伤害；`多发:N` 时逐发攻击 |
| `豁免` | 伤害 | 回复里报「目标属性豁免 DC N，成功半伤/无伤」，不替目标掷豁免 |
| `自动` | 伤害 | 不需要攻击或豁免，直接结算；`多发:N` 时逐发掷伤害 |
| `治疗` | 治疗量 | 用条目的 `治疗` 表达式掷骰，只报结果，不自动加到 HP；升环加骰与固定值自动叠加 |
| `辅助` / `特殊` | 不掷骰 | 只扣环位并展示条目的 `效果` |

攻击加值默认继承头键 `法术攻击`，豁免 DC 默认继承头键 `豁免DC`；条目里写 `攻击:` / `DC:` 可单独覆盖。伤害型豁免必须写 `成功:半伤` 或 `成功:无伤`。

治疗型同样只扣法术位，不选择目标、不自动回血。群体治疗掷一次，所有目标恢复同一数值，目标数写在 `效果` 里（如 `效果:至多 6 个目标`）。布鲁姆的治疗真言与升环：

::: chat
阿岩 | .施法 治疗真言
屠龙骰 | 布鲁姆施展了「治疗真言」（1环）
消耗1环法术位：4/4 → 3/4
布鲁姆的「治疗真言」恢复了 9 点生命值：
2D4+4=[2+3]+4=9
阿岩 | .施法 治疗真言2环
屠龙骰 | 布鲁姆施展了「治疗真言」（2环）
消耗2环法术位：3/3 → 2/3
布鲁姆的「治疗真言」恢复了 14 点生命值：
4D4+4=[1+2+3+4]+4=14
:::

> **仪式施法**：带有仪式标签的法术按仪式施展时，施法时间多 10 分钟，不消耗法术位，也不能升环，因此不需要使用 `.施法`，否则会被当作普通施法扣掉环位。骰娘不判断角色是否具备仪式施法特性，卡面 `|仪式:是` 只用于展示。

判定细节：

- **未准备提醒**：法术已录入但没有 `*` 标记时照常消耗环位，只在末尾附一句提醒；是否提醒由群级规则版本与职业决定，并可用 `.法术 提醒 off` 关闭：

  | 群级规则版本 | 职业 | 提醒 |
  | --- | --- | --- |
  | 2024（5r） | 吟游诗人 / 牧师 / 德鲁伊 / 术士 / 魔契师 / 法师 / 圣武士 / 游侠 | 提醒 |
  | 2014（5e） | 牧师 / 德鲁伊 / 圣武士 / 法师（准备型） | 提醒 |
  | 2014（5e） | 吟游诗人 / 游侠 / 术士 / 魔契师 / 战士 / 游荡者 / 其他 | 不提醒 |

- 环位不足会列出当前可用环阶；绝对升环低于法术本身环阶时直接报错，并提示最低环阶；
- 魔契师只有契约位时，低环法术会自动使用契约位（按契约位环阶施放），回复里会写明「契约魔法」；
- 攻击型只掷攻击，伤害用 `.法术名伤害` 另发；豁免型与自动型在 `.施法` 时已经掷过伤害；治疗型只掷治疗量，不自动加到 HP；辅助型只展示 `效果`；
- **多发**：`多发:N` 的攻击型法术在 `.施法` 时逐发掷攻击，自动型逐发掷伤害；升环 `+N发` 按环差自动增加发数。伤害命令默认只掷一次，多道命中后用 `.3#灼热射线伤害` 逐次补掷，骰娘不会按 `多发` 自动连掷伤害；
- 升环加骰（`升环:+1d6`）与固定值（`升环:+10`）按实际施法环阶自动叠加；加束 / 加枚 / 加目标等其他形态只提示「本期需手动处理」；
- 戏法写 `0` 或直接写名字都不耗位；写 `火焰箭2` 这类升环写法会被拒绝；
- 旧卡没有战斗字段时，`.施法` 只扣环位并提示补录。

## 与武器段的分工

`$武器$` 只写**物理武器**；法术的攻击、伤害、豁免与升环全部写在 `$法术$`。洛恩的卡：

```
$武器$ 匕首+5|1d4+2穿刺
$法术$ 施法属性:智力; 豁免DC:15; 法术攻击:+7; 火焰箭:0|类型:攻击|伤害:2d10火焰|时间:1动作|距离:120尺; 火球术:3*|类型:豁免|豁免:敏捷|成功:半伤|伤害:8d6火焰|升环:+1d6|时间:1动作|距离:150尺|材料:是; 闪电束:3|类型:豁免|豁免:敏捷|成功:半伤|伤害:8d6闪电|升环:+1d6|时间:1动作|距离:自身|材料:是; 魔法飞弹:1*|类型:自动|伤害:1d4+1力场|多发:3|升环:+1发|时间:1动作|距离:120尺; 护盾术:1*|类型:辅助|效果:AC+5，持续到你的下回合开始|时间:1反应|距离:自身
```

- `.施法 火焰箭`：扣环位并掷法术攻击；
- `.火焰箭伤害`：武器段找不到同名项时回退读法术段的 `伤害`；
- `.火焰箭攻击`：同样回退读法术段的攻击加值；
- `.火球术4伤害`：豁免型法术也可以直接用 `.X伤害` 补掷，环阶修饰会应用升环加骰；
- `.法术 准备 火焰箭`：会提示戏法无需准备。
