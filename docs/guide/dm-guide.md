# DM 实战指南

本页假设你是 DM：骰娘负责记账，你负责世界。

全文按一支新队伍的真实流程走——**开团前**把队伍带进骰娘，**开团中**用点命令给检定提速，**一次战斗**从开表一路跑到推进。示例全部取自示例团时间线里的真实记录（第二场遭遇：石桥桥头）。

示例中的命令**仅限群聊**。玩家视角的操作见[掷骰基础](./roll-basics.md)与[角色卡与属性](./character-card.md)。

## 开团前：把队伍带进骰娘

开团前要办三件事：把骰娘请进群，让玩家把卡**开出来**，再把卡**记进骰娘**。

### 开群服务：先把骰娘请进群（.bot on）

骰娘被拉进群后**默认不响应**——群主或管理员先 **@它** 发一句 `.bot on` 开启本群服务，之后其余命令才会生效：

::: chat
白鸦 | @屠龙骰 .bot on
屠龙骰 | 本群服务已开启。
:::

开启状态随时可以用 `.bot` 查询（会顺带返回插件信息）；权限细节见页末的[权限与协同](#权限与协同)。

### 开卡：让骰娘替玩家掷点（.dnd / .dndx）

当 DM 希望玩家使用掷点的方式来确定角色的属性值时，骰娘提供了两种方式：

- `.dndx` 按固定顺序**直接绑定属性名**（掷出即定，抄进角色卡即可）；
- `.dnd` 只出一组降序数值（玩家可自行分配）。

这两个命令后均支持跟数字，可多掷几组挑一组（例如 `.dnd5`，上限 10）。小鹿试掷了一组：

::: chat
小鹿 | .dndx
屠龙骰 | 小鹿 DND人物作成(属性绑定):
75 : 力量 9、敏捷 15、体质 15、智力 15、感知 12、魅力 9
:::

想让玩家按 27 点购点自己算也可以，两种开卡方式的细节见[角色卡与属性 - 属性怎么来](./character-card.md#属性怎么来)。

### 记卡：把角色卡记进骰娘（.角色卡记录）

卡开出来别停在纸面上：让每个玩家把卡**记录进骰娘**（一条命令，卡面照 `$…$` 模板写；格式记不清就用 `.角色卡模板` 现取一份）：

::: chat
小满 | .角色卡记录
$姓名$ 洛恩
$种族$ 精灵
$职业$ 法师
$子职$ 塑能师
$等级$ 5
$生命值$ 37/37
$生命骰$ 5/5 D6
$属性$ 8/15/16/18/10/8
$熟练$ 智力豁免/感知豁免/2*奥秘/历史/调查/宗教/察觉
$武器$ 火焰箭+7,2d10火焰/匕首+5,1d4+2穿刺
屠龙骰 | 角色卡已设置
:::

把四张卡都记完，收益是全场的：

- **玩家更省事**：检定、豁免等点命令自动代入调整值、熟练与卡上加值；攻击与伤害直接调卡上的武器项（`.刺剑攻击`、`.刺剑伤害`），不用每次翻卡；
- **推进更快**：伤害、加血、掷先攻都变成一条命令，文字团不用等谁报数值；
- **血量更好管**：PC 的血挂在卡上，`.hp`、`.长休` 直接读卡结算，DM 还能用 `@` 代操作；
- **先攻表更好读**：条目显示**角色名**（薇拉、塔莉……）而不是群昵称，扫一眼就知道轮到谁。

## 开团中：检定交给点命令

跑团过程中最频繁的交互是检定。让玩家养成用**点命令**的习惯——不写表达式、不查卡，骰娘把该加的加完：

::: chat
阿岩 | .感知检定
屠龙骰 | 布鲁姆进行【感知检定】：
无熟练加值 感知调整值:4
1D20+4=[12]+4=16
阿岩 | .感知豁免
屠龙骰 | 布鲁姆进行【感知豁免】：
熟练加值:3 感知调整值:4 额外加值:+1
1D20+4+3+1=[11]+4+3+1=19
:::

属性检定、技能检定与豁免是同一套写法（`.力量检定`、`.隐匿检定`、`.敏捷豁免`），条目与同义词见[检定与豁免](./checks.md)；

攻击与伤害走角色卡 `$武器$` 项（如 `.刺剑攻击`、`.刺剑重击伤害`），见[武器与攻击](./weapons.md)。

玩家不在场时你用 `@` 代掷（如 `.感知豁免 @玩家`、`.刺剑攻击 @玩家`），播报里会 @ 着他。

## 一次战斗

### 战斗前：开表、入表、定血

一场战斗的准备按这个顺序走，**先开局、后入表**：

1. `.br` 清空并新建战斗轮；
2. 让玩家掷先攻——**推荐 `.先攻检定`**：直接读角色卡，玩家不用报调整值；
3. 你同时把怪物、友军 NPC 入表（代控的未到场 PC 用 `.ri+2 @玩家`）；
4. 给能公开血量的怪记上「当前/上限」；可能持续出场的友军 NPC 记完血再挂 `.npc 持久`；Boss 留白；
5. 有同先攻值就用 `.init first 名称` 定先后，最后 `.init` 发一份终表。

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
白鸦 | 请大家开始投掷先攻
阿茶 | .先攻检定
屠龙骰 | 薇拉进行【先攻检定】：
无熟练加值 敏捷调整值:0
薇拉的先攻值是 1D20=[15]=15
小满 | .先攻检定
屠龙骰 | 洛恩进行【先攻检定】：
无熟练加值 敏捷调整值:2
洛恩的先攻值是 1D20+2=[12]+2=14
老猫 | .先攻检定
屠龙骰 | 塔莉进行【先攻检定】：
熟练加值:3 敏捷调整值:4
塔莉的先攻值是 1D20+4+3=[11]+4+3=18
阿岩 | .先攻检定
屠龙骰 | 布鲁姆进行【先攻检定】：
无熟练加值 敏捷调整值:-1
布鲁姆的先攻值是 1D20-1=[13]-1=12

注：可以推荐玩家用 .先攻检定 掷先攻——自动读卡，不用手动查卡算加值。
白鸦 | .ri18 木乃伊
屠龙骰 | 木乃伊的先攻值是 18
出现相同先攻值，请DM来决定由谁先行动，若不决定将保持默认顺序：
回复.init first 名称 将该对象提前（同先攻值: 木乃伊 / 塔莉）
白鸦 | .ri+2 2#骷髅
屠龙骰 | 骷髅a的先攻值是 1D20+2=[11]+2=13
骷髅b的先攻值是 1D20+2=[4]+2=6
白鸦 | .ri+1 向导
屠龙骰 | 向导的先攻值是 1D20+1=[8]+1=9
:::

DM 侧常用四种入表写法：

| 写法 | 场景 |
| --- | --- |
| `.ri18 木乃伊` | 固定值：想让它先手（Boss、伏击者），直接写数字 |
| `.ri+2 2#骷髅` | 批量派生：`N#` 一次生成 骷髅a、骷髅b，各自独立掷 |
| `.ri+2 向导/狼` | 斜杠多项：多个不同名的怪各自掷一次 |
| `.ri+2 @玩家` | 代掷：玩家不在场时替他入表，条目取他的角色卡名并与该玩家绑定 |

入完表就轮到定血。记血的前提是**怪物已在先攻表里**——没入表会被直接挡下：

::: chat
白鸦 | .hp 木乃伊 58/58
屠龙骰 | 找不到木乃伊的生命值信息
新NPC需要先加入先攻表才可设置HP
:::

按「想让玩家看到什么」挑记法：能公开的记「当前/上限」，Boss 留白（第一次挨打自动开始记「损失」），友军记完再挂 `.npc 持久` 跨战斗沿用：

::: chat
白鸦 | .hp 骷髅a 13/13
屠龙骰 | 骷髅a: HP=13/13
当前HP:13/13
白鸦 | .hp 骷髅b 13/13
屠龙骰 | 骷髅b: HP=13/13
当前HP:13/13
白鸦 | .hp 向导 22/22
屠龙骰 | 向导: HP=22/22
当前HP:22/22
白鸦 | .npc 持久 向导
屠龙骰 | 已将NPC「向导」设为跨战斗保持血量（.ri 再次入表时不再自动回满）
:::

三种血量策略的完整说明（含自动回满）见 [HP 与长休 - NPC / 怪物血量](./hp-rest.md#npc-怪物血量)。本场里木乃伊与塔莉同为 18——`.init first`（别名 `.先攻 提前`）定先后，`.init` 亮出终表，战斗前准备至此完成。

::: chat
白鸦 | .init first 塔莉
屠龙骰 | 塔莉的先攻已在相同先攻值中被提前
白鸦 | .init
屠龙骰 | 先攻列表如下: 
当前是第1轮,塔莉的回合
1.塔莉 先攻:18 HP:43/43
2.木乃伊 先攻:18 
3.薇拉 先攻:15 HP:54/54
4.洛恩 先攻:14 HP:37/37
5.骷髅a 先攻:13 HP:13/13
6.布鲁姆 先攻:12 HP:32/48
7.向导 先攻:9 HP:22/22
8.骷髅b 先攻:6 HP:13/13
:::

### 战斗中：三种伤害结算

战斗按先攻表推进，玩家依次行动。伤害怎么落账，按你对怪物的熟悉程度分三种打法：

**① 玩家回合·玩家不熟悉特性的怪**：让玩家用 `.X伤害` 掷伤害（读数带伤害类型），你按裁定手动打进 `.hp`——避免玩家直接操作敌人 HP 时漏算抗性/易伤：

::: chat
老猫 | .匕首攻击
屠龙骰 | 塔莉进行【匕首攻击检定】：
武器命中加值:+7
1D20+7=[19]+7=26
白鸦 | 命中！请掷伤害骰！
老猫 | .匕首伤害
屠龙骰 | 塔莉用【匕首】造成了 6 点穿刺伤害：
1D4+4=[2]+4=6
白鸦 | .hp 木乃伊抗性 -6
屠龙骰 | 木乃伊: 当前HP减少6（抗性减半→3）
损失HP:0 -> 损失HP:3
:::

塔莉掷出 6 点穿刺，你在 `.hp` 里把承伤特性当后缀写（`抗性` 折半、`易伤` 加倍），骰娘结算并在读数里标注。

**② 玩家回合·玩家很熟悉的怪**：直接让玩家用 `.hp` 命令，掷骰与扣血一条命令完成：

> 伤害位置直接写 `-战锤伤害`，用玩家自己卡上的武器项；后缀与 `±` 临时加值写法同[武器与攻击](./weapons.md)

::: chat
阿岩 | .战锤攻击
屠龙骰 | 布鲁姆进行【战锤攻击检定】：
武器命中加值:+5
1D20+5=[16]+5=21
阿岩 | .hp 骷髅a易伤 -战锤伤害
屠龙骰 | 布鲁姆用【战锤】造成了 10 点钝击伤害：
骷髅a: 当前HP减少[3]+2=5（易伤加倍→10）
HP:13/13 -> HP:3/13
:::

玩家临时离席时，你可以代他把这一发打出来——括号里写**武器来源**（角色名支持模糊匹配，也可以直接 @玩家）：

::: chat
白鸦 | .hp 骷髅b易伤 -火焰箭伤害（洛恩）
屠龙骰 | 洛恩用【火焰箭】造成了 4 点火焰伤害：
骷髅b: 当前HP减少[1+1]=2（易伤加倍→4）
HP:13/13 -> HP:9/13
白鸦 | .hp 骷髅b -匕首伤害（@小满）
屠龙骰 | 洛恩用【匕首】造成了 3 点穿刺伤害：
骷髅b: 当前HP减少[1]+2=3
HP:9/13 -> HP:6/13
:::

但要留意：伤害位置只认「伤害」——写成 `-战锤攻击` 会被拦下并引导改用「战锤伤害」：

::: chat
阿岩 | .hp 骷髅a易伤 -战锤攻击
屠龙骰 | 「战锤攻击」是攻击检定而非伤害掷骰，请用「战锤伤害」！
:::

**③ 你的回合**（怪物与 NPC 行动）：你知道全场所有数据，直接 `.hp` 一步到位：

::: chat
白鸦 | .hp 向导 -d6+3
屠龙骰 | 向导: 当前HP减少[5]+3=8
HP:22/22 -> HP:14/22
:::

范围伤害用 `;` 分隔目标，**掷一次、逐目标结算**，每个目标各挂各的后缀；玩家临时离席时，代他把这一发打出来：

::: chat
白鸦 | .hp 骷髅a;骷髅b;木乃伊易伤 -8d6
屠龙骰 | 骷髅a: 当前HP减少[2+3+1+4+2+5+1+3]=21; HP:3/13 -> HP:0/13 昏迷
骷髅b: 当前HP减少[2+3+1+4+2+5+1+3]=21; HP:6/13 -> HP:0/13 昏迷
木乃伊: 当前HP减少[2+3+1+4+2+5+1+3]=21（易伤加倍→42）; 损失HP:3 -> 损失HP:45

注：小满去接水了——洛恩的火球术由 DM 代发；三大目标里只有木乃伊对火焰易伤。
:::

回合流转也由你掌舵：**玩家回合结束，你可以代他发 `.ed`**（文字团提速），你自己的回合结束自行发 `.ed`；要跳着走用 `.回合±n` 与 `.回合 名称`：

::: chat
白鸦 | .回合
屠龙骰 | 现在是第1轮第1回合，塔莉的回合。
白鸦 | .ed
屠龙骰 | 塔莉的回合结束了。
现在是木乃伊的回合。
白鸦 | .ed
屠龙骰 | 木乃伊的回合结束了。
现在是薇拉的回合。请玩家@阿茶开始行动。
白鸦 | .回合+3
屠龙骰 | 现在是布鲁姆的回合。请玩家@阿岩开始行动。
白鸦 | .回合 木乃伊
屠龙骰 | 现在是木乃伊的回合。
白鸦 | .轮次+1
屠龙骰 | 现在变成第2轮了。
现在是木乃伊的回合。
:::

### 下一场战斗

一场打完**不需要收尾**，无需任何命令。下一场直接 `.br` 即可；它会顺手清掉上一场「只记损失」的临时记录，其余原样留着：

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
白鸦 | .hp list
屠龙骰 | 薇拉 HP:54/54
洛恩 HP:37/37
塔莉 HP:43/43
布鲁姆 HP:32/48
骷髅a HP:0/13 昏迷
骷髅b HP:0/13 昏迷
向导 HP:14/22
:::

可以看到：

- 木乃伊的 `损失HP` 记录随清表消失（下次遇到同名敌人自动从零记起）。
- 对于记录过血量上限的骷髅，下次战斗如果又为骷髅投掷先攻，会自动回满血，默认视为不同骷髅。
- 对于同样记录过血量上限，但设置了 `.npc 持久 名称` 命令的向导，下次战斗为他投掷先攻时，不会自动回满血，视为同一个NPC。

## 暗骰：藏起来的骰子

不想让玩家看到骰值时用 `.rh`：群内只播一句「进行了一次暗骰」，**结果私聊给掷骰者**。替怪物藏检定：

::: chat
白鸦 | .rhd+3 木乃伊潜行
屠龙骰 | 白鸦 进行了一次暗骰

注：以下内容发生在私聊对话框

屠龙骰（私聊） | 白鸦 为 木乃伊潜行 进行的暗骰结果为 1D20+3=[12]+3=15
:::

- 写法与 `.r` 完全一致（优势、加值、原因都支持）；
- 骰值只有你（掷骰者）看得到。
- 玩家也可以用 `.rh` 藏自己的骰。

运镜与边界见[掷骰进阶 - 暗骰](./roll-advanced.md#暗骰-h-rh)。

> 使用这个功能，意味着你希望玩家知道你进行了一次掷骰但不告诉玩家具体数值。
> 
> 如果你连“进行过暗骰”这一点都不希望玩家知道，毫无疑问你可以直接在骰娘的私聊对话框中发送 `.r` 命令进行掷骰。

## 权限与协同

骰娘进群后**默认不响应**（白名单模式）——先由群主或管理员 @它开启本群服务：

::: chat
白鸦 | @屠龙骰 .bot on
屠龙骰 | 本群服务已开启。
:::

- `.bot on` / `.bot off` 只在群聊、只认群主与管理员，且必须 **@ 骰娘** 触发（@ 在开头或结尾均可）；未开启的群里其余命令静默不响应，不刷屏；
- 除 `.bot` 系列外，其他命令**不需要 @ 骰娘**；
- 命令起始符只能是 `.` 或 `。`；是否额外支持 `/` 等其他起始符，取决于骰主（部署方）的设置。

## DM 速查表

| 场景 | 写法 |
| --- | --- |
| 掷点开卡 | `.dndx`（绑定属性名）、`.dnd`（纯数值）、`.dnd3`（多掷几组） |
| 记录角色卡 | `.角色卡记录` + 卡面（模板用 `.角色卡模板` 取） |
| 检定提速 | `.感知检定`、`.隐匿检定`、`.敏捷豁免`（`@玩家` 可代掷） |
| 攻击提速 | 玩家 `.刺剑攻击`（`@玩家` 可代掷）、`.刺剑伤害`（`重击`/`偷袭`/`副手` 后缀） |
| 开新一场 | `.br` |
| 玩家掷先攻 | `.先攻检定`（读卡，推荐）、`.ri`、`.ri+7` |
| 怪物 / 友军入表 | `.ri18 木乃伊`（固定值）、`.ri+2 2#骷髅`（批量派生）、`.ri+2 向导/狼`（多项）、`.ri+2 @玩家`（代入表） |
| 公开血量 | `.hp 骷髅a 13/13` → 读数 `HP:3/13` |
| 隐藏血量 | 不记上限；第一次受伤自动记 `损失HP:n` |
| 友军跨战斗保持 | `.hp 向导 22/22` + `.npc 持久 向导`（恢复用 `.npc 临时 向导`） |
| 同值定先后 | `.init first 名称`（别名 `.先攻 提前`）；`.init` 看终表 |
| 伤害·玩家不熟悉怪 | 玩家 `.匕首伤害` → 你 `.hp 木乃伊抗性 -6` 手动扣血（伤害类型已随读数给出） |
| 伤害·玩家熟悉怪 | 玩家 `.hp 骷髅a易伤 -战锤伤害`（一条命令掷骰 + 扣血；伤害位置直接写 `-X伤害`） |
| 代发武器伤害 | `.hp 骷髅b易伤 -火焰箭伤害（洛恩）`（括号写角色名或 @玩家，用其卡上武器项） |
| 伤害·你的回合 | `.hp 向导 -d6+3`（掷怪伤害一步到位） |
| 一发多目标 | `.hp 骷髅a;骷髅b;木乃伊易伤 -8d6`（掷一次、逐目标结算） |
| 推进 / 跳转 | `.ed`（可代玩家发）、`.回合`、`.回合+3`、`.回合-1`、`.回合 名称`、`.轮次+1` |
| 暗骰 | `.rhd+3 木乃伊潜行`（结果私聊掷骰者） |
| 查看全场 | `.init`（先攻表）、`.hp list`（PC 在前、NPC 在后） |
| 开群服务 | `.bot on`（群主/管理员，需 @ 骰娘） |
