# 规则查询

规则查询让骰娘直接查《5e不全书》的内容：`.查询` 按名称找词条、`.搜索` 全文找，候选列表里回个数字就能看词条正文；骰主开启图片模式后，词条还能以卡片图返回。

DM 还可以给每个群限定**可查的书目**，只开放本团允许的那几本书。

> **前提与来源**：规则查询默认关闭，需骰主在 `.env` 文件中开启并提供查询服务；未开启时发送 `.查询` 会提示「规则查询功能未开启，请联系骰主解决」。查询内容来自[《5e不全书》](https://5echm.kagangtuya.top/)（在线服务或骰主自建的实例），只用于当次回复与短时内存缓存，**不落盘、不随插件分发**，输出统一标注来源。
>
> **示例说明**：本页骰娘回复里的词条正文是**演示用合成文本**（文档不转录规则原文），命令行为与真实运行逐字一致。

## 两种检索：`.查询` 与 `.搜索`

`.查询`（别名 `.q`）按**名称**检索：标题与词条名优先，适合记得名字时直接查；`.搜索`（别名 `.s` / `.检索`）在**全部正文**里检索，适合记不清名称、只知道某个说法时。

关键词支持三种写法：空格分隔的多个关键词**同时满足**（如 `.查询 火焰 伤害`）、`|` 表示**或**（如 `.查询 火焰|闪电`）、最多 5 组；用引号可以把几个词连成一个短语（如 `"火焰 伤害"`）；关键词里不要带命令起始符。

::: chat
阿茶 | .查询 镜影术
屠龙骰 | 「镜影术」共 1 条候选（第 1/1 页）：
1. 二环（玩家手册2024）
回复数字查看详情，+ / - 翻页（60 秒内有效）
阿茶 | 1
屠龙骰 | 《5e不全书》· 玩家手册2024 · 二环
二环 幻术
施法时间：1 动作
距离：自身
成分：V、S
持续时间：1 分钟
三个镜像出现在你周围，用于迷惑攻击者。

注：词条正文在本文档里为演示用合成文本，真实查询返回《5e不全书》的对应条目。
:::

多个关键词也支持：「`|`」是**或**（任一命中即可），空格是**且**（同一页要同时含这些词）：

::: chat
阿茶 | .查询 火焰|闪电
屠龙骰 | 「火焰|闪电」共 3 条候选（第 1/1 页）：
1. 三环（玩家手册2024）
2. 二环（玩家手册2024）
3. 元素法术速查（速查）
回复数字查看详情，+ / - 翻页（60 秒内有效）
阿茶 | .查询 火焰 伤害
屠龙骰 | 「火焰 伤害」共 2 条候选（第 1/1 页）：
1. 三环（玩家手册2024）
2. 法术速查（速查）
回复数字查看详情，+ / - 翻页（60 秒内有效）

注：`火焰|闪电` 命中的页面各含其中一个词（一页讲火焰、一页讲闪电）；`火焰 伤害` 则要求同一页同时含这两个词，候选更少、更准。
:::

两点值得留意：

- 候选标题是**页面名**——《5e不全书》的法术按环阶成页，所以「镜影术」的候选写的是「二环」；骰娘在你选编号后做**条目级定位**，只把该词条那一段裁出来发给你（上方第 2 条回复的标题行即条目名）；
- 候选列表**只认发起者本人**、默认 **60 秒**有效：别人回数字不会触发，过期后回数字也不再响应（不会和群里的普通聊天抢消息）。

## 图片显示：`.查询图片`

词条正文默认以文字发送，若骰主开启图片模式（并装好可选渲染依赖）后，用户可以自己决定本群或本私聊要不要图片：

| 命令 | 作用 |
| --- | --- |
| `.查询图片` | 查看本处当前的显示形态（群聊按群、私聊按本人） |
| `.查询图片 on` | 本处的词条正文改为卡片图 |
| `.查询图片 off` | 本处改回文字 |

「骰主总开关」与「本处开关」是**两级**关系：

总开关决定**能不能用**图片，本处开关决定**本处用不用**（默认文字）。所以骰主没配置时，用户自己开是开不起来的，会明确报错并继续以文字显示：

::: chat
阿茶 | .查询图片
屠龙骰 | 本群的查询结果当前以文字显示。发送 .查询图片 on 可改为图片。
阿茶 | .查询图片 on
屠龙骰 | 无法开启：骰主未开启图片模式，请联系骰主解决。当前仍以文字显示。

注：报错说明骰主尚未开启图片模式（或未安装渲染依赖）；此时无论怎么设置都会以文字显示。
:::

设置无需管理权限、持久保存；候选列表与各类提示始终是文字，**只有词条正文出图**。

开启图片模式的方法（安装、开关与 Linux 字体要求）见[快速开始](./quickstart.md)的安装说明与骰主向文档。

## 查询范围：`.查询范围` 与 `.规则书`

一个跑团群通常只开放核心书与几本扩展。`.查询范围` 把**本处**可查的书目收窄到指定的几本（群聊设置对该群全员生效，私聊仅影响本人）；**不设置就是全部开放**，与默认行为一致。

| 命令 | 作用 |
| --- | --- |
| `.查询范围` | 查看本处当前的范围（未设置时提示「全部书目」） |
| `.查询范围 PHB24,MM25` | 只用指定书目（**英文缩写**，逗号/顿号/空格分隔，大小写不敏感） |
| `.查询范围 全部` | 恢复为全部书目 |

设置只接受**书目缩写**（不接受中文书名）：写错了会直接报错，并告诉你该怎么改。

::: chat
白鸦 | .查询范围 PHB24,MM25,XGE
屠龙骰 | 已设置：本群的查询范围收窄为 PHB24 玩家手册2024、MM25 怪物图鉴2025、XGE 珊娜萨的万事指南。
白鸦 | .查询范围
屠龙骰 | 本群的查询范围为：PHB24 玩家手册2024、MM25 怪物图鉴2025、XGE 珊娜萨的万事指南。发送 .查询范围 全部 恢复全部书目。
阿茶 | .查询 法术位
屠龙骰 | 没有找到与「法术位」相关的内容。本群的查询范围为 玩家手册2024、怪物图鉴2025、珊娜萨的万事指南，可发送 .查询范围 全部 放开全部书目后再试。
白鸦 | .查询范围 Dk
屠龙骰 | 无法设置：Dk（请用 3PP）。设置只接受书目缩写，发送 .规则书 查看对照（合作内容、模组等以整目录缩写设置）。
白鸦 | .查询范围 全部
屠龙骰 | 已恢复：本群可查询全部书目。

注：收窄后「搜不到」会说明当前范围（避免误以为骰娘坏了）；`Dk`（德拉肯海姆）这类合作内容书目与其它作品共用一个站内目录，需用整目录键 `3PP` 设置。

## 常见问题

**查到一半提示「没有找到」？** 先看提示里有没有「本群的查询范围为 …」——若有，说明是范围挡住了，`.查询范围 全部` 即可放开；若没有，换个关键词或用 `.搜索` 全文检索。

**跨群/私聊设置互不影响吗？** 互不影响：范围与图片开关都是**按处**的——群聊按群（对该群全员生效）、私聊按本人。

**查询内容会被存下来吗？** 不会：只用于当次回复与短时内存缓存（关键词缓存默认 10 分钟），不落盘、不随插件分发；输出统一标注来源。
