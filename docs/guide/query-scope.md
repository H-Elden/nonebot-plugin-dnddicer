# 查询范围（.查询范围 / .规则书）

一个跑团群通常只开放核心书与几本扩展。`.查询范围` 把**本处**可查的书目收窄到指定的几本，玩家查规则时不会翻到本团用不到的扩展与模组；**不设置就是全部开放**，与默认行为一致。

- 设置**按处生效**：群聊设置对该群全员生效，私聊仅影响本人；持久保存；
- 这是**全桌的约定**而非权限管控：群里谁都能调，玩家私聊里查询也按他自己的设置走、不受本群范围影响；
- 前提：骰主已开启规则查询功能（见[快速开始 - 规则查询](./quickstart.md#规则查询)）。

## 设置与查看

DM 开团前按本团在跑的规则收窄，示例取自示例团：

::: chat
白鸦 | .查询范围 PHB24,DMG24,MM25
屠龙骰 | 已设置：本群的查询范围收窄为 PHB24 玩家手册2024、DMG24 城主指南2024、MM25 怪物图鉴2025。
白鸦 | .查询范围
屠龙骰 | 本群的查询范围为：PHB24 玩家手册2024、DMG24 城主指南2024、MM25 怪物图鉴2025。发送 .查询范围 全部 恢复全部书目。
:::

| 命令 | 作用 |
| --- | --- |
| `.查询范围` | 查看本处当前的范围（未设置时提示「全部书目」） |
| `.查询范围 PHB24,MM25` | 只用指定书目（**英文缩写**，逗号/顿号/空格分隔，大小写不敏感） |
| `.查询范围 全部` | 恢复为全部书目 |

设置只接受**书目缩写**（不接受中文书名）：写错了会直接报错，并告诉你该怎么改。

## 整目录键（3PP / FR / ADV / MISC）

查询的筛选单位是《5e不全书》站内的**一级目录**，而目录与书并不总是一一对应：合作内容、冒险模组与部分设定集是多本作品共用一个目录的。

这些目录单独列出，用 `3PP` / `FR` / `ADV` / `MISC` 明确设置；写书名缩写（如 `Dk`）时骰娘会提示改用对应的目录键。
