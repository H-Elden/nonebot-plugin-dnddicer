# 最佳实践：一场完整的跑团

本页以 DM 的视角组织（骰娘负责记账，你负责世界），玩家照做自己那几步即可。假设骰娘已经在群里正常服务、全桌的指令都玩熟了、角色卡也都记好了，我们按**开团前 → 游戏前 → 游戏中 → 游戏后**的顺序把一套最顺手的流程完整走一遍。

示例全部取自示例团时间线里的真实记录（第二场遭遇：石桥桥头）。命令**仅限群聊**；骰娘进群后默认不响应，第一步永远是开群服务。

## 开团前：把队伍带进骰娘

开团前办四件事：把骰娘请进群、让玩家把卡开出来、把卡记进骰娘、按本团规则收窄可查书目。

### 开群服务：先把骰娘请进群（.bot on）

骰娘被拉进群后**默认不响应**，由群主或管理员先 **@它** 发一句 `.bot on` 开启本群服务，之后其余命令才会生效：

::: chat
白鸦 | @屠龙骰 .bot on
屠龙骰 | 本群服务已开启。
:::

开启状态随时可以用 `.bot` 查询（会顺带返回插件信息）。权限、起始符与响应排查见[群管理与 FAQ](./faq.md)。

### 开卡：让骰娘替玩家掷点（.dnd / .dndx）

希望玩家用掷点确定属性值时，骰娘提供了两种方式：`.dndx` 按固定顺序**直接绑定属性名**（掷出即定，抄进角色卡即可）；`.dnd` 只出一组降序数值（玩家自行分配）。两个命令后均可跟数字多掷几组（如 `.dnd5`，上限 10）。小鹿试掷了一组：

::: chat
小鹿 | .dndx
屠龙骰 | 小鹿 DND人物作成(属性绑定):
75 : 力量 9、敏捷 15、体质 15、智力 15、感知 12、魅力 9
:::

想让玩家按 27 点购点自己算也可以，两种开卡方式的细节见[角色卡与属性 - 属性怎么来](./character-card.md#属性怎么来)。

### 记卡：把角色卡记进骰娘（.角色卡记录）

卡开出来别停在纸面上：让每个玩家把卡**记录进骰娘**（一条命令，卡面照 `$…$` 模板写；格式记不清就用 `.角色卡模板` 现取一份）：

::: chat
小满 | .角色卡记录
$姓名$ 洛恩
$种族$ 精灵
$职业$ 法师
$子职$ 塑能师
$等级$ 5
$生命值$ 37/37
$生命骰$ 5/5 D6
$属性$ 8/15/16/18/10/8
$熟练$ 智力豁免/感知豁免/2*奥秘/历史/调查/宗教/察觉
$武器$ 火焰箭+7,2d10火焰/匕首+5,1d4+2穿刺
屠龙骰 | 角色卡已设置
:::

把四张卡都记完，收益是全场的：

- **玩家更省事**：检定、豁免等点命令自动代入调整值、熟练与卡上加值；攻击与伤害直接调卡上的武器项（`.刺剑攻击`、`.刺剑伤害`），不用每次翻卡；
- **推进更快**：伤害、加血、掷先攻都变成一条命令，文字团不用等谁报数值；
- **血量更好管**：PC 的血挂在卡上，`.hp`、`.长休` 直接读卡结算，DM 还能用 `@` 代操作；
- **先攻表更好读**：条目显示**角色名**（薇拉、塔莉……）而不是群昵称，扫一眼就知道轮到谁。

### 定书目：收窄本团可查的规则（.查询范围）

规则查询默认开放全部书目。开团前按本团在跑的规则收窄本群可查的书（需骰主已开启规则查询功能）：

::: chat
白鸦 | .查询范围 PHB24,DMG24,MM25
屠龙骰 | 已设置：本群的查询范围收窄为 PHB24 玩家手册2024、DMG24 城主指南2024、MM25 怪物图鉴2025。
:::

设置只认**英文缩写**（逗号、顿号或空格分隔），缩写对照用 `.规则书` 现查；设置按群生效、持久保存，`.查询范围 全部` 随时恢复全部开放。完整说明见[查询范围](./query-scope.md)。

## 游戏前：开表、入表、定血

每场战斗的准备都按这个顺序走，**先开局、后入表**：

1. `.br` 清空并新建战斗轮；
2. 让玩家掷先攻，**推荐 `.先攻检定`**：直接读角色卡，玩家不用报调整值；
3. 你同时把怪物、友军 NPC 入表（代控的未到场 PC 用 `.ri+2 @玩家`）；
4. 给能公开血量的怪记上「当前/上限」；可能持续出场的友军 NPC 记完血再挂 `.npc 持久`；Boss 留白；
5. 有同先攻值就用 `.init first 名称` 定先后，最后 `.init` 发一份终表。

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
白鸦 | 请大家开始投掷先攻
阿茶 | .先攻检定
屠龙骰 | 薇拉进行【先攻检定】：
无熟练加值 敏捷调整值:0
薇拉的先攻值是 1D20=[15]=15
小满 | .先攻检定
屠龙骰 | 洛恩进行【先攻检定】：
无熟练加值 敏捷调整值:2
洛恩的先攻值是 1D20+2=[12]+2=14
老猫 | .先攻检定
屠龙骰 | 塔莉进行【先攻检定】：
熟练加值:3 敏捷调整值:4
塔莉的先攻值是 1D20+4+3=[11]+4+3=18
阿岩 | .先攻检定
屠龙骰 | 布鲁姆进行【先攻检定】：
无熟练加值 敏捷调整值:-1
布鲁姆的先攻值是 1D20-1=[13]-1=12

注：可以推荐玩家用 .先攻检定 掷先攻：自动读卡，不用手动查卡算加值。
白鸦 | .ri18 木乃伊
屠龙骰 | 木乃伊的先攻值是 18
出现相同先攻值，请DM来决定由谁先行动，若不决定将保持默认顺序：
回复.init first 名称 将该对象提前（同先攻值: 木乃伊 / 塔莉）
白鸦 | .ri+2 2#骷髅
屠龙骰 | 骷髅a的先攻值是 1D20+2=[11]+2=13
骷髅b的先攻值是 1D20+2=[4]+2=6
白鸦 | .ri+1 向导
屠龙骰 | 向导的先攻值是 1D20+1=[8]+1=9
:::

DM 侧常用四种入表写法：

| 写法 | 场景 |
| --- | --- |
| `.ri18 木乃伊` | 固定值：想让它先手（Boss、伏击者），直接写数字 |
| `.ri+2 2#骷髅` | 批量派生：`N#` 一次生成 骷髅a、骷髅b，各自独立掷 |
| `.ri+2 向导/狼` | 斜杠多项：多个不同名的怪各自掷一次 |
| `.ri+2 @玩家` | 代掷：玩家不在场时替他入表，条目取他的角色卡名并与该玩家绑定 |

入完表就轮到定血。记血的前提是**怪物已在先攻表里**，没入表会被直接挡下：

::: chat
白鸦 | .hp 木乃伊 58/58
屠龙骰 | 找不到木乃伊的生命值信息
新NPC需要先加入先攻表才可设置HP
:::

按「想让玩家看到什么」挑记法：能公开的记「当前/上限」，Boss 留白（第一次挨打自动开始记「损失」），友军记完再挂 `.npc 持久` 跨战斗沿用：

::: chat
白鸦 | .hp 骷髅a 13/13
屠龙骰 | 骷髅a: HP=13/13
当前HP:13/13
白鸦 | .hp 骷髅b 13/13
屠龙骰 | 骷髅b: HP=13/13
当前HP:13/13
白鸦 | .hp 向导 22/22
屠龙骰 | 向导: HP=22/22
当前HP:22/22
白鸦 | .npc 持久 向导
屠龙骰 | 已将NPC「向导」设为跨战斗保持血量（.ri 再次入表时不再自动回满）
:::

三种血量策略的完整说明（含自动回满）见[生命值管理 - NPC / 怪物血量](./hp.md)。本场里木乃伊与塔莉同为 18，用 `.init first`（别名 `.先攻 提前`）定先后，`.init` 亮出终表，战斗前准备至此完成：

::: chat
白鸦 | .init first 塔莉
屠龙骰 | 塔莉的先攻已在相同先攻值中被提前
白鸦 | .init
屠龙骰 | 先攻列表如下: 
当前是第1轮,塔莉的回合
1.塔莉 先攻:18 HP:43/43
2.木乃伊 先攻:18 
3.薇拉 先攻:15 HP:54/54
4.洛恩 先攻:14 HP:37/37
5.骷髅a 先攻:13 HP:13/13
6.布鲁姆 先攻:12 HP:32/48
7.向导 先攻:9 HP:22/22
8.骷髅b 先攻:6 HP:13/13
:::

## 游戏中：检定、结算、推进

跑团过程中最频繁的交互是检定。让玩家养成用**点命令**的习惯，不写表达式、不查卡，骰娘把该加的加完：

::: chat
阿岩 | .感知检定
屠龙骰 | 布鲁姆进行【感知检定】：
无熟练加值 感知调整值:4
1D20+4=[12]+4=16
阿岩 | .感知豁免
屠龙骰 | 布鲁姆进行【感知豁免】：
熟练加值:3 感知调整值:4 额外加值:+1
1D20+4+3+1=[11]+4+3+1=19
:::

属性检定、技能检定与豁免是同一套写法（`.力量检定`、`.隐匿检定`、`.敏捷豁免`），条目与同义词见[检定与豁免](./checks.md)；攻击与伤害走角色卡 `$武器$` 项（如 `.刺剑攻击`、`.刺剑重击伤害`），见[武器与攻击](./weapons.md)。

战斗中一次交锋，攻击、天然 20 提示与伤害结算连起来是这样：

::: chat
老猫 | .匕首攻击+1d4
屠龙骰 | 塔莉进行【匕首攻击检定】：
武器命中加值:+7
1D20+7+1D4=[20]+7+[3]=30
天然20：重击！伤害用 .匕首重击伤害 结算
白鸦 | .hp 熊地精 -d8+4
屠龙骰 | 熊地精: 当前HP减少[6]+4=10
HP:27/27 -> HP:17/27
:::

伤害怎么落账（三种打法）、范围伤害与 DM 代发的完整图解见[血量与伤害结算](./dm-settlement.md)；玩家不在场时用 `@` 代掷与代操作见[代掷与代操作](./dm-proxy.md)。

回合流转也由 DM 掌舵：**玩家回合结束，可以代他发 `.ed`**（文字团提速），怪物与 NPC 的回合由你 `.ed`；要跳着走用 `.回合±n` 与 `.回合 名称`：

::: chat
白鸦 | .回合
屠龙骰 | 现在是第1轮第1回合，塔莉的回合。
白鸦 | .ed
屠龙骰 | 塔莉的回合结束了。
现在是木乃伊的回合。
白鸦 | .ed
屠龙骰 | 木乃伊的回合结束了。
现在是薇拉的回合。请玩家@阿茶开始行动。
白鸦 | .回合+3
屠龙骰 | 现在是布鲁姆的回合。请玩家@阿岩开始行动。
白鸦 | .回合 木乃伊
屠龙骰 | 现在是木乃伊的回合。
白鸦 | .轮次+1
屠龙骰 | 现在变成第2轮了。
现在是木乃伊的回合。
:::

### 暗骰：藏起来的骰子

不想让玩家看到骰值时用 `.rh`：群内只播一句「进行了一次暗骰」，**结果私聊给掷骰者**。替怪物藏检定：

::: chat
白鸦 | .rhd+3 木乃伊潜行
屠龙骰 | 白鸦 进行了一次暗骰

注：以下内容发生在私聊对话框

屠龙骰（私聊） | 白鸦 为 木乃伊潜行 进行的暗骰结果为 1D20+3=[12]+3=15
:::

- 写法与 `.r` 完全一致（优势、加值、原因都支持）；
- 骰值只有你（掷骰者）看得到；玩家也可以用 `.rh` 藏自己的骰；
- 连「进行过暗骰」都不想暴露时，直接在私聊里发 `.r` 即可。运镜与边界见[掷骰进阶 - 暗骰](./roll-advanced.md#暗骰-h-rh)。

## 游戏后：长休与下一场

一场打完**不需要收尾**，无需任何命令。回到安全处可以顺手做一次长休（`.长休`；DM 可代不在场的玩家收尾，见[HP 进阶与长休](./hp-advanced.md)）。

下一场战斗直接 `.br` 即可；它会顺手清掉上一场「只记损失」的临时记录，其余原样留着：

::: chat
白鸦 | .br
屠龙骰 | 已创建新战斗轮。清除先攻表、当前回合。
白鸦 | .hp list
屠龙骰 | 薇拉 HP:54/54
洛恩 HP:37/37
塔莉 HP:43/43
布鲁姆 HP:32/48
骷髅a HP:0/13 昏迷
骷髅b HP:0/13 昏迷
向导 HP:14/22
:::

可以看到：

- 木乃伊的 `损失HP` 记录随清表消失（下次遇到同名敌人自动从零记起）；
- 对于记录过血量上限的骷髅，下次战斗如果又为骷髅投掷先攻，会自动回满血，默认视为不同骷髅；
- 对于同样记录过血量上限，但设置了 `.npc 持久 名称` 命令的向导，下次战斗为他投掷先攻时，不会自动回满血，视为同一NPC。

## 全流程速查表

| 阶段 | 场景 | 写法 |
| --- | --- | --- |
| 开团前 | 开群服务 | `.bot on`（群主/管理员，需 @ 骰娘） |
| 开团前 | 掷点开卡 | `.dndx`（绑定属性名）、`.dnd`（纯数值）、`.dnd3`（多掷几组） |
| 开团前 | 记录角色卡 | `.角色卡记录` + 卡面（模板用 `.角色卡模板` 取） |
| 开团前 | 定本团书目 | `.查询范围 PHB24,DMG24,MM25`（缩写用 `.规则书` 对照、`.查询范围 全部` 恢复） |
| 游戏前 | 开新一场 | `.br` |
| 游戏前 | 玩家掷先攻 | `.先攻检定`（读卡，推荐）、`.ri`、`.ri+7` |
| 游戏前 | 怪物 / 友军入表 | `.ri18 木乃伊`（固定值）、`.ri+2 2#骷髅`（批量派生）、`.ri+2 向导/狼`（多项）、`.ri+2 @玩家`（代入表） |
| 游戏前 | 公开血量 | `.hp 骷髅a 13/13` → 读数 `HP:3/13` |
| 游戏前 | 隐藏血量 | 不记上限；第一次受伤自动记 `损失HP:n` |
| 游戏前 | 友军跨战斗保持 | `.hp 向导 22/22` + `.npc 持久 向导`（恢复用 `.npc 临时 向导`） |
| 游戏前 | 同值定先后 | `.init first 名称`（别名 `.先攻 提前`）；`.init` 看终表 |
| 游戏中 | 检定提速 | `.感知检定`、`.隐匿检定`、`.敏捷豁免`（`@玩家` 可代掷） |
| 游戏中 | 攻击提速 | 玩家 `.刺剑攻击`（`@玩家` 可代掷）、`.刺剑伤害`（`重击`/`偷袭`/`副手` 后缀） |
| 游戏中 | 伤害·玩家不熟悉怪 | 玩家 `.匕首伤害` → 你 `.hp 木乃伊抗性 -6` 手动扣血（伤害类型已随读数给出） |
| 游戏中 | 伤害·玩家熟悉怪 | 玩家 `.hp 骷髅a易伤 -战锤伤害`（一条命令掷骰 + 扣血） |
| 游戏中 | 代发武器伤害 | `.hp 骷髅b易伤 -火焰箭伤害（洛恩）`（括号写角色名或 @玩家，用其卡上武器项） |
| 游戏中 | 伤害·你的回合 | `.hp 向导 -d6+3`（掷怪伤害一步到位） |
| 游戏中 | 一发多目标 | `.hp 骷髅a;骷髅b;木乃伊易伤 -8d6`（掷一次、逐目标结算） |
| 游戏中 | 推进 / 跳转 | `.ed`（可代玩家发）、`.回合`、`.回合+3`、`.回合-1`、`.回合 名称`、`.轮次+1` |
| 游戏中 | 暗骰 | `.rhd+3 木乃伊潜行`（结果私聊掷骰者） |
| 游戏中 | 查看全场 | `.init`（先攻表）、`.hp list`（PC 在前、NPC 在后） |
| 游戏后 | 长休 | `.长休`、`.长休 @玩家` |
| 游戏后 | 下一场 | 直接 `.br`（无需收尾） |

上一站：[查询范围](./query-scope.md)；玩家侧进阶从[角色卡与属性](./character-card.md)起步，命令全量速查见[命令总览](./overview.md)。
