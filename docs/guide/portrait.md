# 立绘裁切

`.立绘` 给当前角色卡设置头像图，卡面右上角的方框会显示它。完整的立绘口径见[角色卡图与立绘](./card-image.md#立绘)。

角色卡的立绘框是 **1:1 方框（146×146）**，而插件对上传的图片**原图直存、不裁不缩**，非方图会被拉伸。因此建议先在本页把图裁成方形，再发给骰娘；本页工具导出固定 **512×512 PNG**，远小于插件的 4 MB 上限。

## 怎么发给骰娘

1. 在本页选图，拖动图片、用滑块缩放，把脸或主体放到方框中心。
2. 点「复制图片」，到群里把图片粘贴进输入框，并在**同一条消息**里输入 `.立绘` 后发送。
3. 浏览器不允许复制图片时，点「下载 PNG」，在 QQ 里选择这张图，同样附上 `.立绘` 后发送。

只发 `.立绘` 不带图片时，骰娘只会回用法提示；图片与 `.立绘` 分成两条消息发送也不会生效。

设置成功后，`.角色卡图` 的立绘框会换成新图；立绘属于当前角色卡，`.角色卡清除` 会连同立绘一起删除，重新发送整卡不会丢失已设置的立绘。

## 说明

- 图片只在浏览器本地处理，**不会上传、也不会保存**；刷新或关闭页面后需要重新选择。
- 导出始终是正方形 512×512 PNG。当前卡面没有其他比例的版式，所以不提供 3:4 / 4:5 预设，避免做出会被拉伸的图。
- 支持 PNG / JPG / WebP，单张输入上限 20 MB；导出的 512px PNG 通常只有一两百 KB。
- 立绘目前**仅限群聊**设置与展示，私聊建卡与跨群绑定留待后续的卡库功能。
