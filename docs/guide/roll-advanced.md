# 掷骰进阶

表达式的写法与读法见[掷骰基础](./roll-basics.md)。

本页收集让掷骰更贴近跑团实战的进阶用法：优势与劣势、取高取低、骰子修饰符、抗性/易伤、连掷、暗骰与掷骰原因。示例同样取自示例团的试骰。

## 优势与劣势

DND 里最常见的修正：**优势**掷两次取高、**劣势**掷两次取低。直接写中文关键词，或写等价的保留语法：

| 写法 | 含义 | 等价表达式 |
| --- | --- | --- |
| `d优势` | 掷两次取高 | `2dkh1` |
| `d劣势` | 掷两次取低 | `2dkl1` |
| `2dkh1` / `2dk1` | 保留最高 1 颗 | — |
| `2dkl1` | 保留最低 1 颗 | — |

::: chat
老猫 | .rd优势
屠龙骰 | 塔莉 的掷骰结果为 2D20K1=MAX{[3], [15]}=15
:::

::: chat
阿岩 | .rd劣势
屠龙骰 | 布鲁姆 的掷骰结果为 2D20KL1=MIN{[20], [1]}=1 哇哦！大失败!

注：被丢掉的那颗 20 不参与判定——大成功/大失败只看保留下来的那颗（见[掷骰基础](./roll-basics.md#大成功与大失败)）。
:::

> **书写顺序**：面数写在优势/劣势**之前**（`.rd劣势+6`）。
>
> 把数字写到劣势后面（`.rd劣势20+6`）会被拒绝并提示正确写法。该写法有歧义：面数错序，或漏写 `+` 号。

::: chat
老猫 | .rd劣势+6
屠龙骰 | 塔莉 的掷骰结果为 2D20KL1+6=MIN{[15], [4]}+6=10

注：正确：加值写成 `+6` 接在劣势之后。

老猫 | .rd劣势20+6
屠龙骰 | 优势/劣势 后不能直接跟数字：骰子面数请写在前面（如 d20劣势+6），加值请写成 +N（如 d劣势+2）

注：错误：面数跑到了劣势后面，直接拒绝执行。
:::

## 取高与取低（k / kh）

`k` 后面跟数字，保留最大的几颗（`kh` / `kl` 是「保留高/低」的显式写法）：

::: chat
小满 | .r4d6k3
屠龙骰 | 洛恩 的掷骰结果为 4D6K3=MAX{[1], [4], [2], [6]}=12
小满 | .r2dkh1
屠龙骰 | 洛恩 的掷骰结果为 2D20K1=MAX{[7], [18]}=18
:::

> `4d6k3`（掷 4 取最高 3）是掷点建卡的经典写法；插件的[属性生成](./character-card.md)命令内部即用这套掷法，也支持你手写。

## 骰子修饰符

修饰符直接跟在骰子后、只作用于该组骰子，可与加值自由组合（如 `2d6r1+3`）：

| 语法 | 含义 |
| --- | --- |
| `R<比较>` | **重掷**：出目满足条件时重掷一次并替换（结果以删除线标注，如 `1̶→3`） |
| `X<值>` | **爆炸骰**：出目 ≥ 值则追加掷一颗，可连锁 |
| `XO<值>` | 爆炸骰的克制版：每颗骰子最多追加一次 |
| `M<值>` | **最小值**：低于值的出目按值计 |
| `CS>=<值>` | **成功计数**：统计满足条件的骰子数，结果即成功次数 |
| `P<值>` | **预兆**：出目直接取该值 |
| `F` | **命运骰**（福骰） |

::: chat
老猫 | .r2d6r1+3
屠龙骰 | 塔莉 的掷骰结果为 2D6R=1+3=[1̶→3][5]+3=11
小满 | .rd6x6
屠龙骰 | 洛恩 的掷骰结果为 1D6X>=6=[6|3]=9
小满 | .rd6xo6
屠龙骰 | 洛恩 的掷骰结果为 1D6XO>=6=[6]‹3›=9
阿岩 | .rd6m2
屠龙骰 | 布鲁姆 的掷骰结果为 1D6M2=[1→2]=2

注：爆炸骰用 `|` 分隔连续追加的骰子；`xo` 追加的那颗显示为 `‹›`。
:::

::: chat
老猫 | .r2d6cs>=5
屠龙骰 | 塔莉 的掷骰结果为 2D6CS>=5=[5+2] >= 5(1次成功1次失败)=1
小满 | .rdp10
屠龙骰 | 洛恩 的掷骰结果为 1D20P10=[=10]=10
小满 | .rdf
屠龙骰 | 洛恩 的掷骰结果为 1D20F=[5]=5
:::

> 比较运算符支持 `>` `<` `>=` `<=` `=` `==`；不写比较时默认「等于」（`2d6r1` 即重掷出 1 的骰子）。

## 抗性与易伤

DM 结算伤害时，把 `抗性` / `易伤` 缀在**表达式末尾**，骰娘会先算总和、再减半（向下取整）或加倍：

::: chat
白鸦 | .rd12+2d8+5抗性
屠龙骰 | 白鸦 的掷骰结果为 (1D12+2D8+5)/2=([8]+[3+6]+5)/2=11
白鸦 | .r2d6易伤
屠龙骰 | 白鸦 的掷骰结果为 (2D6)*2=[4+2]*2=12
:::

> 后缀必须写在表达式最后——写在中途会直接报「意外字符」。角色卡伤害结算里的 `抗性/易伤`（`.hp` 的伤害目标后缀）见 [HP 与长休](./hp-rest.md)。

## 连掷（N#）

`N#` 把整套表达式连掷 N 次（1~10 次），逐条列出：

::: chat
老猫 | .r3#2d6
屠龙骰 | 塔莉 的掷骰结果为 3次 2D6:
[5+3]=8,
[4+2]=6,
[6+1]=7
:::

连掷里出现大成功/大失败时，会在末尾**按次汇总**：

::: chat
老猫 | .r2#d
屠龙骰 | 塔莉 的掷骰结果为 2次 1D20:
[20]=20,
[1]=1 1次 大成功 1次 大失败
:::

> 次数写在最前面（`2#`）；超出 1~10 或不合法时按 1 次处理。

## 只显数值（s）

`s` 标志只显示最终数值、不列逐骰过程——连掷很多次时能少刷屏：

::: chat
小满 | .rs2d6+3
屠龙骰 | 洛恩 的掷骰结果为 2D6+3=10
小满 | .rs2#d6
屠龙骰 | 洛恩 的掷骰结果为 2次 1D6: [5, 2]
:::

## 暗骰（h / .rh）

需要瞒着其他玩家的掷骰（潜行、被动察觉之类）用**暗骰**：群聊里只播报一句提示，结果通过**私聊**发给掷骰者本人：

::: chat
老猫 | .rhd+5 潜行
屠龙骰 | 塔莉 进行了一次暗骰
屠龙骰（私聊） | 塔莉 为 潜行 进行的暗骰结果为 1D20+5=[12]+5=17
:::

> 写法是 `h` 标志紧跟在 `.r` 之后（`.rhd+5`），`h` 取 hidden 之意。若私聊发送失败（如对方未开启临时会话），命令仍会正常结束（仅记录日志），掷骰者收不到结果。

## 带原因的掷骰

在表达式后空一格再写一段说明，结果文案会带上「为 … 进行」，复盘时一眼能看出这骰是干什么的：

::: chat
阿茶 | .rd+2 力量检定
屠龙骰 | 薇拉 为 力量检定 进行的掷骰结果为 1D20+2=[15]+2=17
白鸦 | .rd8+3 哥布林弯刀
屠龙骰 | 白鸦 为 哥布林弯刀 进行的掷骰结果为 1D8+3=[6]+3=9
:::

> 有角色卡时，检定点命令（`.力量检定`）会自动代入属性调整值、熟练与卡上额外加值，比手写表达式更省事，见[角色卡与检定](./character-card.md)。
