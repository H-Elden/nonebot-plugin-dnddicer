# 规则版本与击晕

本页讲**本群跑哪版规则**：5e（2014）与 5r（2024）在若干处结算规则不同，骰娘把这些差异点统一交给一个群级设置 `.规则版本`。命令**仅限群聊**。

## 群级规则版本

查看与设置都**不需要管理权限**，任何群成员都能改（与 `.查询范围`、`.查询图片` 一致）：

::: chat
白鸦 | .规则版本
屠龙骰 | 本群规则版本：2024（5r）（跟随骰主默认）。发送 .规则版本 5e 或 .规则版本 5r 可为本群单独设置。
白鸦 | .规则版本 5e
屠龙骰 | 已设置：本群规则版本为 2014（5e）。
白鸦 | .规则版本
屠龙骰 | 本群规则版本：2014（5e）。发送 .规则版本 5e 或 .规则版本 5r 修改。
白鸦 | .规则版本 默认
屠龙骰 | 已清除本群规则版本设置，恢复跟随骰主默认（当前 2024（5r））。
:::

写法上 `5e`（或 `2014`）与 `5r`（或 `2024`、`5.5e`）都认；`.规则版本 默认` 清除本群设置，回落到骰主的默认值（骰主用 `.env` 里的 `DNDDICER_DEFAULT_RULES_VERSION` 配置，默认 2024）。

受这个设置影响的差异点（后续新增的差异点也会走同一处设置）：

| 差异点 | 5e（2014） | 5r（2024） |
| --- | --- | --- |
| 长休恢复生命骰 | 回复总数的一半（至少 1 颗） | 恢复全部已消耗 |
| `.hp` 的击晕写法 | 可用：HP 归 0、昏迷但伤势稳定 | 可用：改为降到 1 HP、昏迷并开始短休 |

## 击晕（留活口，两版都有）

**击晕**是把敌人打晕而不是打死的写法：近战攻击把目标打到 0 HP 时，可以改为击晕。两版规则都有这条，**差别只在结果**，骰娘按本群规则版本自动选：

- **5e（2014）**：被击晕的目标陷入昏迷，**但伤势稳定**（不再掷死亡豁免）；
- **5r（2024）**：改为降到 **1 点 HP**，昏迷并视为开始一次短休。

写法是在伤害末尾加一个 `击晕`。5r 群里：

::: chat
白鸦 | .hp 薇拉 20/54
屠龙骰 | 薇拉: HP=20/54
当前HP:20/54
白鸦 | .hp 薇拉 -20 击晕
屠龙骰 | 薇拉: 已击晕（生命值降为 1 点并陷入昏迷，视为开始一次短休）
:::

同一操作在 5e 群里（把本群规则版本切到 5e 后）结果是「归 0 且稳定」：

::: chat
白鸦 | .规则版本 5e
屠龙骰 | 已设置：本群规则版本为 2014（5e）。
白鸦 | .hp 薇拉 20/54
屠龙骰 | 薇拉: HP=20/54
当前HP:20/54
白鸦 | .hp 薇拉 -20 击晕
屠龙骰 | 薇拉: 已击晕（生命值降为 0 点并陷入昏迷，但伤势稳定、无需死亡豁免）
白鸦 | .规则版本 默认
屠龙骰 | 已清除本群规则版本设置，恢复跟随骰主默认（当前 2024（5r））。
:::

注：击晕是**可选参数**，只有写出来才生效；不写就按普通伤害结算（可能进濒死，见[死亡豁免](./death-save.md)）。没有伤害的写法（如 `.hp 20/30 击晕`）会被挡下并提示用法。

被击晕后如何收尾：5e 的那位已经「伤势稳定」，等治疗把 HP 拉回正数即可；5r 的那位是 1 HP，规则上是「开始一次短休」。NPC 血量条目不做死亡豁免，想让怪物「被打晕而不是打死」时，直接用 `.hp 名称 1/上限` 或 `.hp 名称 0/上限` 改血量即可（怪物没有濒死流程）。
