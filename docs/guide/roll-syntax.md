# 掷骰语法

掷骰是本插件最核心的能力：`.r` 接受 DicePP 风格的**掷骰表达式**——支持加值运算、保留最高/最低、重掷、爆炸骰等完整语法。所有示例均为真实运行输出，昵称（艾琳）为发送者显示名，骰值为示例中的实际出目。

## 基本用法

```
.r [标志][表达式] [原因]
```

| 部分 | 说明 | 示例 |
| --- | --- | --- |
| 表达式 | 要掷的骰子与运算 | `2d6+3`、`d20+4`、`2d20kh1` |
| 原因 | 可选，附在结果文案中说明掷骰目的 | `.r d20+2 力量检定` |
| 标志 | `h` 暗骰 / `s` 只显数值 / `N#` 连掷 N 次 | `.rh d20`、`.r s 2d6`、`.r 2#d20` |

```text
你发送：.r 2d6+3
骰娘回复：艾琳 的掷骰结果为 2D6+3=[5+2]+3=10
```

结果文本的读法：`2D6+3` 是表达式原文；`[5+2]` 是两个 d6 的**逐骰过程**；`+3` 是固定加值；最后的 `=10` 是合计。

若逐骰过程为空（只有固定数），只显示一次 `=`。

## 基本骰子与运算

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| `NdM` | N 个 M 面骰 | `2d6`、`1d20`、`3d8` |
| `N` | 固定数值 | `+3`、`-2`、`*2`、`/2`（除法向下取整？见下） |
| `d` / `3d` | 省略面数 = 掷**默认骰面**（默认 d20，见「默认骰面」） | `.r d` 等价 `.r 1d20` |
| `+ - * / ( )` | 四则运算与括号 | `(1d6+2)*2`、`2d6-1` |

```text
你发送：.r (1d6+2)*2
骰娘回复：艾琳 的掷骰结果为 (1D6+2)*2=([4]+2)*2=12
```

```text
你发送：.r d20+5
骰娘回复：艾琳 的掷骰结果为 1D20+5=[10]+5=15
```

## 优势 / 劣势

DND 最常见的修正——直接写关键词，或写两个骰取高/低：

| 写法 | 含义 | 等价表达式 |
| --- | --- | --- |
| `d20优势` | 掷两次取高 | `2d20kh1` |
| `d20劣势` | 掷两次取低 | `2d20kl1` |
| `2d20kh1` / `2d20k1` | 保留最高 1 个 | — |
| `2d20kl1` | 保留最低 1 个 | — |
| `4d6k3` | 掷 4 取最高 3（建卡掷点常用） | — |

```text
你发送：.r d20优势
骰娘回复：艾琳 的掷骰结果为 2D20K1=MAX{[3], [15]}=15
```

```text
你发送：.r d20劣势
骰娘回复：艾琳 的掷骰结果为 2D20KL1=MIN{[20], [1]}=1 哇哦！大失败!
```

> 注意：优势掷出 20 与 1 时保留 20 → 判定**大成功**（被丢弃的 1 不计）；劣势反之。
> `MAX{[3], [15]}` 中的 `K1` 表示从 2 个出目中保留最高 1 个。

```text
你发送：.r 4d6k3
骰娘回复：艾琳 的掷骰结果为 4D6K3=MAX{[1], [4], [2], [6]}=12
```

## 骰子后缀修饰符

修饰符直接跟在骰子后、作用于该组骰子，可与加值自由组合（如 `2d6r1+3`）：

| 语法 | 含义 | 示例与输出 |
| --- | --- | --- |
| `R`/`R<值` 等 | **重掷**：出目满足条件（默认等于）则重掷一次并替换（删除线标注） | `2d6r1`：掷出 1 重掷 → `2D6R=1=[1̶→5][3]=8`；`d20r<3` → `1D20R<3=[2̶→17]=17` |
| `X值` / `XO值` | **爆炸骰**：出目 ≥ 值则追加掷一颗（`XO` 每个骰只追加一次） | `d6x6` → `1D6X>=6=[6|3]=9`；`d6xo6` → `1D6XO>=6=[6]‹3›=9`；连续爆炸 `[6|6|4]=16` |
| `M值` | **最小值**：低于值的出目按值计 | `d6m2`：掷 1 → `1D6M2=[1→2]=2` |
| `CS>=值` | **成功计数**：统计满足条件的骰子数，结果为成功次数 | `2d6cs>=5` → `2D6CS>=5=[5+2] >= 5(1次成功1次失败)=1` |
| `P值` | **预兆**（法师预言子类）：出目直接取该值 | `d20p10` → `1D20P10=[=10]=10` |
| `F` | 命运骰（福骰） | `d20f` → `1D20F=[5]=5` |

```text
你发送：.r 2d6r1+3
骰娘回复：艾琳 的掷骰结果为 2D6R=1+3=[1̶→5][3]+3=11
```

> 删除线 `1̶→5` = 出目 1 被重掷为 5；爆炸骰的 `|` 分隔连续追加的骰子。
> 比较运算符支持 `>` `<` `>=` `<=` `=` `==`（如 `d20r<3`、`1d6x4`）。

## 连掷（N#）与只显数值（s）

```text
你发送：.r 3#2d6
骰娘回复：艾琳 的掷骰结果为 3次 2D6:
[5]=5,
[3]=3,
[1]=1
```

- 连掷次数 **1 ~ 10**；越界或不合法时按 1 次处理。
- 连掷中若出现大成功/大失败，会在末尾**汇总**播报（见下节）。

```text
你发送：.r s 2d6+3        ← s：只显示最终数值，不看逐骰过程
骰娘回复：艾琳 的掷骰结果为 2D6+3=11

你发送：.r s 2#1d6
骰娘回复：艾琳 的掷骰结果为 2次 1D6: [5, 2]
```

## 大成功 / 大失败

大成功/大失败**只由 d20 产生**：表达式含 d20 且出目为 20 → 追加「好耶！大成功!」，
出目为 1 → 追加「哇哦！大失败!」。判定只看**被保留**的骰子（优势掷出 20+1 算大成功）。
非 d20 表达式（`2d6`、`d8`、`d100`…）不会播报。

```text
你发送：.r d20
骰娘回复：艾琳 的掷骰结果为 1D20=[20]=20 好耶！大成功!

你发送：.r d20+4+1d4
骰娘回复：艾琳 的掷骰结果为 1D20+1D4=[20]+[2]=22 好耶！大成功!
```

连掷时按次汇总：

```text
你发送：.r 2#d20
骰娘回复：艾琳 的掷骰结果为 2次 1D20:
[20]=20,
[1]=1  1次 大成功 1次 大失败
```

## 暗骰（h / .rh）

`h` 标志或命令名带 h（`.rh`）即为**暗骰**：群聊中只播报"某人进行了一次暗骰"，
结果通过**私聊**发给掷骰者本人，其他玩家看不到。

```text
你发送（群聊）：.rh d20+5 潜行
群内播报：艾琳 进行了一次暗骰
艾琳收到的私聊：艾琳 的暗骰结果为 1D20+5=[12]+5=17
```

带原因的暗骰私聊文案：`艾琳 为 潜行 进行的暗骰结果为 …`。若私聊发送失败（如对方关闭了临时会话），命令仍正常结束并记录告警日志。

## 带原因的掷骰

```text
你发送：.r d20+2 力量检定
骰娘回复：艾琳 为 力量检定 进行的掷骰结果为 1D20+2=[15]+2=17
```

> 在已有角色卡的前提下，更推荐直接用角色检定点命令（`.力量检定`）——它会自动代入角色卡上的属性调整值、熟练与额外加值，见 [角色卡与检定](./character-card.md)。

## 默认骰面

省略面数的 `d` / `3d` 使用**默认骰面**：未配置时默认 **d20**；若群主用 `.dset`
设置了本群默认骰面（如 d12），则本群的裸 `d` 改为掷 d12（详见 [群管理与 FAQ](./faq.md)）。
