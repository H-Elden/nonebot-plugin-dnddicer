# 角色卡字段

本页是角色卡文本的字段参考，供两种时候查：网页建卡器没有覆盖到的写法，或者卡被骰娘拒收、需要排查原因时。正常建卡直接用[网页建卡器](./card-builder.md)生成命令即可，不需要手写这些字段；卡库与命令见[角色卡录入](./character-card.md)。

## 书写总则

- 一段一行，段名用 `$` 包住写在行首，后面跟内容，例如 `$等级$ 5`；
- 段内分隔符只有三种半角字符：条目用 `;`、字段用 `|`、键值用 `:`；数值对（属性、生命值、法术位）用 `/`。全角标点不再作为分隔符，旧写法会按格式错误报出；
- 除 `$故事$` 可以多行外，一段只写一行；段内不要再出现 `$`；
- 段的顺序不限，可整段省略；未知段名会直接报错，不会静默忽略；
- `.角色卡新建` 至少要写 `$姓名$`、`$等级$` 与 `$属性$`，其余段都可以后补；
- `.角色卡修改` 只写要改的段即可，段名后不写内容表示清空该段，`$姓名$` / `$等级$` / `$属性$` 不能清空；
- 网页建卡器导出的整卡命令如果超过单条消息上限，会按段拆成 `.角色卡新建` 加多条 `.角色卡修改` 依次发送，不要打乱顺序。

## 段落一览

以下按用途分三组。**加粗**为 `.角色卡新建` 必填；其余段可省略。属性调整值、豁免与技能加值、先攻、被动察觉与下一级经验由骰娘现算，不写进卡文本。

### 核心段

| 段落 | 说明 | 必填 |
| --- | --- | --- |
| **`$姓名$`** | 角色名，用于检定落款、先攻列表与卡面显示；不写时 `.角色卡新建` 会拒绝 | **必填** |
| **`$等级$`** | 等级；熟练加值 = 2 + (等级 − 1) ÷ 4 向下取整（5 级 → +3） | **必填** |
| **`$属性$`** | 六个**最终值**（已含种族、背景、专长等全部加值），用 `/` 分隔，依次对应 **力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力**；调整值 = (数值 − 10) ÷ 2 向下取整 | **必填** |
| `$生命值$` | `当前/最大(临时)`，如 `54/54`、`20/30 (5)`；HP 结算改的是这里，见[生命值管理](./hp.md) | 可选 |
| `$生命骰$` | `当前/总数 D骰面`，如 `5/5 D8`；`.生命骰` 花骰与长休回复都按此结算 | 可选 |
| `$熟练$` | 熟练条目，用 `;` 分隔；写**豁免**用 `感知豁免` 全名，写技能直接写技能名（如 `隐匿`）；`2*隐匿` 为**专精**（双倍熟练）；**先攻**也支持。<br>还可加四类展示分组：`护甲:轻甲,中甲`、`武器:简易武器`、`工具:书法工具`、`语言:通用语,精灵语`（组内用 `,` 分隔）。<br>书写顺序不限，查看时按「技能 → 豁免」的固定次序显示 | 可选 |
| `$半熟练$` | 半熟练规则：`范围:取整`，多条用 `;` 分隔；范围 `全部` / `技能` / `力敏体`，取整 `向下` / `向上`；见[半熟练](#半熟练) | 可选 |
| `$额外加值$` | 属性检定 / 技能检定 / 豁免 / 先攻的额外加值，见[额外加值](#额外加值) | 可选 |
| `$战斗$` | `AC:18; 速度:30`；只写 AC 与速度；**先攻**与**被动察觉**由骰娘现算，不需要写 | 可选 |
| `$进度$` | 经验与英雄激励：`经验:6500; 激励:有`；**下一级经验**由骰娘按等级表计算，不需要写；激励可用 `.激励` 命令查看、获得、消耗与转赠 | 可选 |

### 身份与展示段

| 段落 | 说明 | 必填 |
| --- | --- | --- |
| `$种族$` | 种族（如 `半精灵`），记录与展示用 | 可选 |
| `$职业$` | 标准 12 职业规范名之一或扩展职业名（如 `法师`、`机关术师`）；只有**游荡者**的偷袭后缀会按等级自动附加偷袭骰；暂不支持兼职 | 可选 |
| `$子职$` | 子职（如 `塑能师`）；5r 全部职业 3 级获得，5e 按职业（牧师/术士/魔契师 1 级、德鲁伊/法师 2 级、其余 3 级） | 可选 |
| `$专长$` | 已获专长，用 `;` 分隔；可补一行说明：`巨武器大师:…; 幸运` | 可选 |
| `$种族特性$` | 种族特性，`名称:说明`，多项用 `;` 分隔：`黑暗视觉:60 尺内微光视为明亮` | 可选 |
| `$职业特性$` | 职业特性，`等级\|名称:说明`，多项用 `;` 分隔：`3\|塑能学者:法术书免费加入…`；卡图按等级升序显示「N级」徽标 | 可选 |
| `$物品$` | 背包：`名称x数量`，多项用 `;` 分隔，如 `治疗药水x2; 长剑x1`；魔法物品写到 `$魔法物品$` | 可选 |
| `$钱币$` | 五种币值：`CP:0; SP:8; EP:0; GP:18; PP:0`，只写有值的，未写按 0 显示；收支用 `.钱币` 命令 | 可选 |
| `$背景$` | 固定键 `背景 / 阵营 / 信仰 / 体型 / 年龄 / 外貌 / 个性`（5e 另有 `理想 / 羁绊 / 缺点`），`键:值` 多项用 `;` 分隔；空值不写 | 可选 |
| `$故事$` | 背景故事，可多行、多段，最多 1000 字（换行不计）；卡面每段首行缩进两字 | 可选 |
| `$战斗记录$` | 战斗中的临时记录，自由文本多项用 `;` 分隔，如 `祝福术(专注,3轮); 中毒`；条目里不能有 `$`，增删用 `.战斗记录` 命令 | 可选 |

### 武器、资源与法术段

| 段落 | 说明 | 必填 |
| --- | --- | --- |
| `$武器$` | 自定义武器/法术项：`名称+命中加值\|伤害表达式+类型[\|备注]`（如 `短剑+4\|1d4+2穿刺\|灵巧, 轻型`），多项用 `;` 分隔；名称尾加 `x` 表示不可攻击检定（如 `火球术x\|8d6火焰`）；备注只用于卡面图；见[武器与攻击](./weapons.md) | 可选 |
| `$限定资源$` | 有使用次数的资源：`名称:当前/上限恢复档[\|说明]`，多项用 `;` 分隔；恢复档 `短休` / `长休` / `两者` / `手动`，可加 `+N` 或 `满`（如 `引导神力:2/2短休+1,长休`）；见[休息与资源](./resources.md) | 可选 |
| `$魔法物品$` | `名称\|标签\|说明`，多项用 `;` 分隔；说明用 `//` 分段（合计 ≤500 字）：`防护斗篷\|奇物，非普通（需同调）\|AC 和豁免 +1。//银线织成。`；正文里不能出现 `//`；卡面单独显示 | 可选 |
| `$法术$` | 法术清单：三个保留键 `施法属性` / `豁免DC` / `法术攻击`，其余为 `法术名:环阶[*]`，多项用 `;` 分隔；`0` = 戏法、尾部 `*` = 今日已准备；需要卡面详情时在条目后接一条竖线再写 `时间:1动作\|距离:150尺\|专注:是\|仪式:否\|材料:是\|备注:…`（只用于卡面图）；见[休息与资源](./resources.md) | 可选 |
| `$法术位$` | 各环与契约法术位：`环阶:当前/上限`，契约写 `契约3:2/2`，多项用 `;` 分隔；见[休息与资源](./resources.md) | 可选 |

`$专长$`、`$种族特性$`、`$职业特性$`、`$限定资源$` 的说明可以多段（合计 ≤400 字）：网页建卡器里每行一段（空行忽略），卡文本用 `//` 分段；正文里不能出现 `//`，条目之间仍用 `;` 分隔。

## 整卡、分段与修改

- `.角色卡新建` 按整卡解析，必须含 `$姓名$`、`$等级$` 与 `$属性$`；其他段可省略，建好后用 `.角色卡修改` 补；
- `.角色卡修改` 永远按段合并：写一个或多个段都只覆盖写到的段，未提到的段保持原样；
- 段名后不写内容表示清空该段；`$姓名$` / `$等级$` / `$属性$` 不能清空；
- 一次写多个段时，只要有一段非法，整条命令拒绝，原卡不变；
- 网页建卡器超过 4500 字时会拆成第一段 `.角色卡新建` 与后续 `.角色卡修改`，按顺序发送即可。

## 半熟练

半熟练是「在未熟练时加一半熟练加值」的规则，写成 `范围:取整`，多条用 `;` 分隔。

| 范围 | 适用条目 | 对应官方来源 |
| --- | --- | --- |
| `全部` | 所有属性检定：技能、纯属性检定、先攻、被动；**不含豁免** | 2014 吟游诗人「万事通」 |
| `技能` | 18 个正式技能（**不含先攻**；含对应的被动察觉/调查/洞悉） | 2024 吟游诗人「万事通」 |
| `力敏体` | 力量/敏捷/体质属性检定：含先攻、运动、体操、巧手、隐匿等；**不含豁免** | 2014 勇士「运动健将」 |

取整 `向下` 与 `向上` 的差别只在熟练加值为奇数时出现：熟练 +3 时向下 +1、向上 +2；熟练 +5 时向下 +2、向上 +3。

2014 吟游诗人的万事通：

```text
$半熟练$ 全部:向下
```

2014 勇士的运动健将：

```text
$半熟练$ 力敏体:向上
```

2024 吟游诗人的万事通：

```text
$半熟练$ 技能:向下
```

- 半熟练只在**没有熟练或专精**时生效；已有 `$熟练$` 或 `2*` 专精时不叠加。
- 只作用于属性检定（含技能、先攻、纯属性检定），**不作用于豁免**。
- `全部` 会同时作用于先攻与被动；`技能` 不含先攻，但会作用于技能对应的被动；`力敏体` 含先攻与力量/敏捷/体质技能。
- 多个规则重叠时取较高的半熟练，例如诗人/勇士兼职同时写 `全部:向下; 力敏体:向上`，力量/敏捷/体质检定取向上，其余取向下。
- 网页建卡器在「属性」与「熟练」之间提供预设：5e 的万事通/运动健将、5r 的万事通；选中后胶囊右边显示该来源的半熟练加值。

## 额外加值

格式为 `条目:取值`，多个用 `;` 分隔；取值是**可选**的 `优势`/`劣势` 前缀加一段 ±掷骰表达式：

- 条目键：六属性名、技能名、`力量豁免`/`敏捷豁免`…；
- 另有作用于**全部**豁免的全局键：`豁免`；
- 没有内容就整段省略；卡上带优劣势时，对应检定会直接掷出优势/劣势。

只登记**算得进检定**的部分，示例团两处加值都来自 2024 城主指南的魔法物品（数值出处见[示例团与人物](./cast.md#建卡依据)）：

| 角色 | 卡上的写法 | 含义 |
| --- | --- | --- |
| 塔莉 | `隐匿:优势` | 精灵之靴：潜行自带优势 |
| 布鲁姆 | `豁免:+1` | 防护斗篷：所有豁免 +1（另有一条 `隐匿:劣势` 来自链甲） |

武器的命中与伤害加值不走这里，直接写进 `$武器$` 项（薇拉的长剑 +1 已在 `长剑+8|1d8+5挥砍` 里），见[武器与攻击](./weapons.md)。

限时效果的加值（祝福术 `+1d4`、激励骰…）**不要写进卡**，写成命令里的临时加值即可，见[检定与豁免](./checks.md#临时加值-不进角色卡)。

## 卡面自动算出的值

卡图的六属性调整值、豁免与技能加值、先攻、被动察觉、熟练加值与下一级经验都由骰娘按卡面现算，不需要写进卡文本：

- 调整值 = (属性 − 10) ÷ 2 向下取整；
- 豁免 / 技能加值 = 属性调整值 + 熟练（专精 ×2）+ 半熟练 + 额外加值；
- 先攻 = 敏捷调整值 + 先攻熟练 + 半熟练 + 额外加值；
- 被动察觉 = 10 + 察觉检定加值（优势 +5、劣势 -5）；
- 熟练加值 = 2 + (等级 − 1) ÷ 4 向下取整；
- 下一级经验按等级表计算。

AC 与速度以 `$战斗$` 的值为准；旧卡里写过的 `先攻` / `被动察觉` 键会被忽略，以现算值为准。2014 观察力这类只加被动值的专长暂不自动识别。

## 常见错误

卡被拒收时，骰娘会直接回原因，原卡不受影响。下列提示最常见：

| 提示 | 常见原因 | 怎么改 |
| --- | --- | --- |
| `必须设定等级与属性` | 漏了 `$等级$` 或 `$属性$` | 补上；`.角色卡新建` 还必须有 `$姓名$` |
| `必须设定全部的6项属性` | `$属性$` 不是 6 个数值 | 写成 6 个 `/` 分隔的数值 |
| `属性值必须为正整数!` | 属性里有非数字、全角数字或空格 | 改成半角阿拉伯数字 |
| `必须使用冒号(:)分割额外加值条目和内容` | `$额外加值$` 条目没写冒号 | 写成 `条目:取值` |
| `未知段: $xxx$（可用段见网页建卡器）` | 段名拼错或用了旧段名 | 对照上面的段落一览 |
| `必须设定姓名` / `姓名不能为空` | `$姓名$` 为空 | 写角色名 |
| `卡名最多 20 个字符` / `卡名不能包含空白` / `卡名不能包含 $ 或 @` | 卡名不合规 | 换一个短卡名 |
| `角色卡最多 10 张` | 卡库满 | 删除不需要的卡 |

还有一个**不会报错**的坑：`$属性$` 的六个数值按「力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力」固定对应，顺序写错不会拒收，但检定会全部对错列。网页建卡器会按正确顺序生成；只有手改卡文本时才需要自己核对。
