# 检定与豁免

登记过[角色卡](./character-card.md)之后，检定就不必再手写算式：`.力量检定`、`.敏捷豁免`、`.隐匿检定` 这类**检定点命令**会把卡上的属性调整值、熟练加值与额外加值一次代入，当场给出结果。

本页示例取自示例团在碎星隘口的探路与遭遇战（队伍信息见[示例团与人物](./cast.md)）。

## 语法

```
.[次数#][条目][优势|劣势][±临时加值]
```

| 部分 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| 次数 `N#` | 否 | 连掷 N 次（1~9），逐次独立掷骰并显示 | `.2#察觉检定` |
| 条目 | 是 | 属性 / 技能 / 豁免，见下表 | `.隐匿检定`、`.感知豁免` |
| 优势 / 劣势 | 否 | 本次的临时优劣势，与卡上自带优劣势**叠加、可抵消** | `.隐匿检定劣势` |
| 临时加值 | 否 | 限时效果的 ±掷骰表达式，写在命令里、**不进卡** | `.运动检定+1d4` |

| 类型 | 条目 | 说明 |
| --- | --- | --- |
| 属性检定 | 力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力 | 条目加后缀「检定」，如 `.力量检定` |
| 技能检定 | 运动、体操、巧手、隐匿、先攻、奥秘、历史、调查、自然、宗教、驯兽、洞悉、医药、察觉、求生、欺瞒、威吓、表演、游说 | 18 项技能；支持常见同义写法（潜行→隐匿、观察→察觉、妙手→巧手…），见[同义词表](#条目同义词) |
| 豁免 | 六属性名 + 「豁免」 | 如 `.感知豁免`；卡上的全局键 `豁免` 也会计入 |

## 输出怎么读

回复由「过程说明 + 掷骰算式」两段构成，过程说明列出这次检定用到的每一项加值：

::: chat
阿岩 | .感知检定
屠龙骰 | 布鲁姆进行【感知检定】：
无熟练加值 感知调整值:4
1D20+4=[12]+4=16
:::

`无熟练加值` 表示 `$熟练$` 里没有这一项：**豁免/技能默认全部未熟练**；属性调整值则来自 `$属性$`（感知 18 → +4）。

熟练项会写进说明，专精（`2*`，双倍熟练）标成 `熟练加值:3*2`：

::: chat
老猫 | .隐匿检定
屠龙骰 | 塔莉进行【隐匿检定】：
熟练加值:3*2 敏捷调整值:4 自带优势
2D20K1+4+6=MAX{[15], [4]}+4+6=25
:::

`自带优势` 来自卡上的 `$额外加值$`（塔莉的 `隐匿:优势`），卡上带优劣势时，算式会直接变成 `2D20K1`（取高）。

卡上的加值项标成 `额外加值:`，跟在属性调整值之后：

::: chat
阿岩 | .感知豁免
屠龙骰 | 布鲁姆进行【感知豁免】：
熟练加值:3 感知调整值:4 额外加值:+1
1D20+4+3+1=[11]+4+3+1=19
:::

上例里的 `额外加值:+1` 来自全局键 `豁免:+1`（防护斗篷），**同一个 +1 会进每一项豁免**，无论那次豁免是否熟练；条目级加值（如 `隐匿:优势`）只进对应的那一条，写法见[角色卡与属性](./character-card.md#额外加值)。

## 临时加值（不进角色卡）

限时效果（祝福术、诗人激励、临时增益）写进命令即可，标成 `临时加值:`：

::: chat
阿茶 | .运动检定+1d4
屠龙骰 | 薇拉进行【运动检定】：
熟练加值:3 力量调整值:4 临时加值:+1d4
1D20+4+3+1D4=[20]+4+3+[3]=30 好耶！大成功!
:::

为什么不写进卡？卡面只装「一直算得进」的部分：写进卡的加值会在每次检定里常驻，限时效果一旦过期就容易忘记删。卡的写法见[角色卡与属性](./character-card.md#额外加值)。

## 优劣势的叠加与抵消

检定时的临时优劣势由**当前情况**（埋伏、遮蔽、地形）决定，写进命令即可。它与卡上自带的优劣势只有两种关系，即**同向不叠、反向抵消**：

::: chat
老猫 | .隐匿检定优势
屠龙骰 | 塔莉进行【隐匿检定】：
熟练加值:3*2 敏捷调整值:4
2D20K1+4+6=MAX{[13], [7]}+4+6=23

注：卡上已有「隐匿:优势」，再给一次优势不会叠成三次取高，仍是一颗优势骰（`2D20K1`）。

老猫 | .隐匿检定劣势
屠龙骰 | 塔莉进行【隐匿检定】：
熟练加值:3*2 敏捷调整值:4 优劣抵消
1D20+4+6=[9]+4+6=19

注：优势与劣势相抵，回到普通掷，并在说明里标「优劣抵消」。
:::

也就是说，优劣势只有**优势 / 普通 / 劣势**三个档位：同向的来源再多也只掷一颗优势骰（`2D20K1`，不会叠成三次取高）；正反相抵则回到普通掷，说明行标 `优劣抵消`。

## 大成功与大失败

检定与豁免共用掷骰命令那套判定：**被保留的 D20 出目 20 → 「好耶！大成功!」，出目 1 → 「哇哦！大失败!」**（`N#` 连掷时按次汇总）。

> 武器攻击检定不用这套文案：掷出天然 20/1 时提示「重击 / 必失」，见[武器与攻击](./weapons.md#攻击检定)：

::: chat
阿岩 | .力量检定
屠龙骰 | 布鲁姆进行【力量检定】：
无熟练加值 力量调整值:2
1D20+2=[1]+2=3 哇哦！大失败!
:::

上面那记 `.运动检定+1d4` 掷出 D20=20，同样是一条「大成功」：判定只看被保留的 D20（优势/劣势里被丢掉的那颗不计），与 `.r` 完全一致。

## 连掷 N#

`N#` 前缀连掷 N 次（1~9），每次独立掷骰、逐行显示；标题会标成 `N次`：

::: chat
小满 | .2#察觉检定
屠龙骰 | 洛恩进行【2次察觉检定】：
熟练加值:3 感知调整值:0
1D20+3=[15]+3=18
1D20+3=[3]+3=6
:::

## 代不在场的玩家掷（@）

把 `@玩家` 写在表达式右侧，骰娘改用**该玩家的角色卡**代入并以其角色名落款；`优势/劣势` 与 `±加值` 写在 @ 前后皆可，连掷也支持。（武器攻击与伤害同样支持 `@`，见[武器与攻击](./weapons.md)）：

::: chat
白鸦 | .智力豁免 @小满
屠龙骰 | 洛恩进行【智力豁免】：
熟练加值:3 智力调整值:4
1D20+4+3=[13]+4+3=20
:::

- @ 的目标需已建卡，否则回复真 @ 引导建卡；
- @ 写在命令**前面**不生效（`@小满 .智力豁免` 会按发送者自己掷，无卡则回「找不到角色卡」），请始终写在表达式右侧。

## 无角色卡时

未建卡时提示「找不到角色卡」，建卡入口是 `.角色卡记录`：

::: chat
小鹿 | .敏捷检定
屠龙骰 | 找不到角色卡
:::

## 先攻检定

`.先攻检定` 是检定类命令中的特例：用角色卡的敏捷调整值（熟练「先攻」再加熟练加值）掷 D20，掷完**自动写入本群先攻列表**（掷骰行会被替换为入表反馈）：

::: chat
阿岩 | .先攻检定
屠龙骰 | 布鲁姆进行【先攻检定】：
无熟练加值 敏捷调整值:-1
布鲁姆的先攻值是 1D20-1=[16]-1=15
:::

- 先攻掷骰**不播报**大成功/大失败（先攻没有重击的概念），掷出 20 也照常入表；
- 注意区分 `.先攻`（查看先攻列表）与 `.先攻检定`（掷骰入表），完整用法见[先攻列表](./initiative.md#先攻检定-读角色卡入表)。

## 不做 DC 判定

检定只掷出结果数值，**不对 DC 做成功与否的判定**，难度比较交由玩家与 DM 自行完成。想要「带 DC 的一次性判定」，在群里说清 DC、对着结果比即可。

用卡上的武器结算攻击时同理：`.刺剑攻击` 只负责掷攻击检定，命中与否自行比较 AC（见[武器与攻击](./weapons.md)）。

## 条目同义词

技能与属性支持常见的中文别名，用词不必与技能表逐字一致：

| 别名 | 对应条目 | 别名 | 对应条目 |
| --- | --- | --- | --- |
| 潜行 / 隐蔽 / 隐秘 / 躲藏 | 隐匿 | 观察 | 察觉 |
| 特技 | 体操 | 妙手 | 巧手 |
| 驯养 / 驯服 | 驯兽 | 医疗 / 医术 | 医药 |
| 生存 | 求生 | 欺骗 / 欺诈 / 哄骗 | 欺瞒 |
| 威胁 | 威吓 | 说服 | 游说 |

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| 检定点命令 | `.[N#][条目][优势\|劣势][±加值]` | 读角色卡掷检定 / 豁免；右侧可加 `@玩家` 代掷 |
| 武器攻击 / 伤害 | `.武器名攻击`、`.武器名伤害` | 用卡上自定义武器结算（含 `副手`/`重击`/`偷袭` 后缀），见[武器与攻击](./weapons.md) |
| `.先攻检定` | `.先攻检定`、`.先攻检定 @玩家` | 掷先攻并自动入表（不播报大成功/大失败） |
| `.角色卡` / `.状态` | `.角色卡`、`.状态 @玩家` | 查看卡面 / HP 与生命骰摘要，见[角色卡与属性](./character-card.md) |
