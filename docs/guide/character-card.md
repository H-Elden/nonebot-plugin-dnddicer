# 角色卡与属性

角色卡是检定的基础：把等级、六属性、熟练与额外加值登记成一张卡，之后用 `.力量检定`、`.敏捷豁免`、`.隐匿检定` 这类点命令时，骰娘会自动代入卡上的加值，不必每次手写算式。属性调整值、豁免与技能加值都由骰娘按等级、属性、熟练与额外加值现算，卡面图也会显示算出的结果，不需要手填展示值。

攻击检定与伤害掷骰需要手动录卡，走卡上的 `$武器$` 条目，见[武器与攻击](./weapons.md)；有使用次数的限定资源与法术资源走 `$限定资源$` / `$法术$` / `$法术位$`，见[休息与资源](./resources.md)；想让卡面以图片展示或设置立绘，见[角色卡图与立绘](./card-image.md)。

本页解决两件事：**属性从哪来**、**卡怎么登记**；卡登记好之后怎么掷检定，见[检定与豁免](./checks.md)。

> 角色卡库**按 QQ 归属**，一个 QQ 最多同时持有 10 张卡，可分别绑定到多个群；群内依赖卡的命令只认**本群当前绑定**的卡，未绑定会提示先绑定。新建、查看、修改与绑定都可以在私聊完成；检定点命令仍仅限群聊。没建卡也能掷骰，只是检定点不会代入卡上加值。

## 属性怎么来

DND 建卡的六属性有两条路：**购点**是纸面计算，**掷点**交给骰子。插件只参与后者。

### 购点法：纸面计算

标准做法是 27 点购点 → 叠加背景属性加值 → 再叠加属性值提升，最后把六个数值填进 `$属性$`。这一步插件不参与，示例团四张卡的完整算法与核对表见[示例团与人物](./cast.md#建卡依据)。

### 掷点法：.dnd 与 .dndx

两者都按 4D6K3 生成六项属性（每项掷 4 颗 D6、去掉最低的一颗、其余求和），区别只在结果**是否绑定属性名**：

| 命令 | 输出 | 适用场景 |
| --- | --- | --- |
| `.dnd` | 六项数值的**降序**列表（只出数值，不绑定） | 想自行把数值分配给六属性 |
| `.dndx` | 数值按固定顺序**直接绑定属性名**（不排序） | 掷出即定，直接抄进角色卡 |

命令后可跟**次数**与**原因**：`.dnd2` 一次掷两组（上限 20），原因会写进标题。DM 给客串 NPC 掷点：

::: chat
白鸦 | .dnd
屠龙骰 | 白鸦 DND人物作成:
74 : [18, 14, 13, 11, 10, 8]
白鸦 | .dnd2 替补
屠龙骰 | 白鸦 DND人物作成——替补:
70 : [17, 14, 13, 12, 7, 7]
76 : [18, 15, 14, 12, 9, 8]
:::

读法：`74` 是六项合计，`[18, 14, …]` 是六项数值的降序列表（第一项 18 出自 `6,6,6,1`，去掉 1 后 6+6+6），自行挑六个数字分配给属性即可。

次数写错时骰娘会直接说明，既不掷点、也不悄悄改次数：

::: chat
白鸦 | .dnd30
屠龙骰 | 次数超出上限：最多 20 次
白鸦 | .dndx 0
屠龙骰 | 次数至少为 1
:::

`.dndx` 的顺序与 `$属性$` 行完全一致（力量/敏捷/体质/智力/感知/魅力），掷出即定、按序抄写；小鹿试掷并登记：

::: chat
小鹿 | .dndx
屠龙骰 | 小鹿 DND人物作成(属性绑定):
75 : 力量 9、敏捷 15、体质 15、智力 15、感知 12、魅力 9
小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$生命值$ 8/8
$属性$ 9/15/15/15/12/9
屠龙骰 | 已新建角色卡「小鹿」并绑定到本群。
:::

## 新建与修改角色卡（.角色卡新建 / .角色卡修改）

新建一张卡用 `.角色卡新建 <卡名> <完整卡内容>`：标准三步是 ① 发送 `.角色卡模板` 取一份模板；② 按角色改好各段内容（也可以直接抄[示例团与人物](./cast.md)里的现成卡改）；③ 在卡面最前面加上 `.角色卡新建 <卡名>`，卡面从第二行起顶头写。卡内容必须包含 `$姓名$`、`$等级$` 与 `$属性$`，否则整条拒绝、不会建卡。

卡名是你在卡库里的标识（≤20 字符，不能含空格、`$`、`@`），与卡内的 `$姓名$` 分开。群聊新建成功后会自动绑定到本群；私聊新建不会自动绑定，建好后用 `.角色卡绑定 <卡名> <群号>` 绑到跑团群。一个 QQ 最多同时持有 10 张卡。

改卡用 `.角色卡修改 <卡名> <段条目>`：只覆盖你写到的段，未提到的段保持原样；可以一次写多个段，空段表示清空该段，`$姓名$` / `$等级$` / `$属性$` 不能清空。私聊有多张卡时必须带卡名；只有一张时可以省略。群聊只能修改本群当前绑定的卡，省略卡名时默认就是它。

不想手打整张卡时，可以用[网页建卡器](./card-builder.md)填表，再复制生成的整卡命令或分段命令；已有的卡也能粘回表单继续改。

### 段落一览

**加粗**为必填。表中的核心段用于检定与资源结算；后半部分扩展段用于完整卡面展示，不填也能正常跑团，填了才会出现在 `.角色卡图` 的图片卡上。属性调整值、豁免与技能加值均由骰娘按 `$属性$`、`$等级$`、`$熟练$` 与 `$额外加值$` 现算，不需要手填展示值。

| 段落 | 说明 | 是否必填 |

| `$姓名$` | 角色名，用于检定落款与先攻列表；不写时显示名回退到群名片 | 可选 |
| `$种族$` | 种族（如 `半精灵`），记录与展示用 | 可选 |
| `$职业$` | 标准 12 职业规范名之一或扩展职业名（如 `法师`、`机关术师`）；只有**游荡者**的偷袭后缀会按等级自动附加偷袭骰 | 可选 |

| `$物品$` | 背包：`名称x数量`，多项用 `;` 分隔，如 `治疗药水x2; 长剑x1`；魔法物品写到 `$魔法物品$` | 可选 |
| `$钱币$` | 五种币值：`CP:0; SP:8; EP:0; GP:18; PP:0`，只写有值的，未写按 0 显示 | 可选 |
| `$背景$` | 固定键 `背景 / 阵营 / 信仰 / 体型 / 年龄 / 外貌 / 个性`（5e 另有 `理想 / 羁绊 / 缺点`），`键:值` 多项用 `;` 分隔；空值不写 | 可选 |
| `$故事$` | 背景故事，可多行、多段，最多 1000 字（换行不计）；卡面每段首行缩进两字 | 可选 |
| `$战斗记录$` | 战斗中的临时记录，自由文本多项用 `;` 分隔，如 `祝福术(专注,3轮); 中毒` | 可选 |
| `$限定资源$` | 有使用次数的资源：`名称:当前/上限恢复档[|说明]`，多项用 `;` 分隔；恢复档 `短休` / `长休` / `两者` / `手动`，可加 `+N` 或 `满`（如 `引导神力:2/2短休+1,长休`）；见[休息与资源](./resources.md) | 可选 |
| `$魔法物品$` | `名称\|标签\|说明`，多项用 `;` 分隔；说明用 `//` 分段：`防护斗篷\|奇物，非普通（需同调）\|AC 和豁免 +1。//银线织成。`；卡面单独显示 | 可选 |
| `$武器$` | 自定义武器/法术项：`名称+命中加值,伤害表达式+类型[,备注]`（如 `短剑+4,1d4+2穿刺,灵巧`），多项用 `/` 分隔；<br>名称尾加 `x` 表示不可攻击检定（如 `火球术x,8d6火焰`）；备注只用于卡面图；见[武器与攻击](./weapons.md) | 可选 |
| `$法术$` | 法术清单：头三个保留键 `施法属性` / `豁免DC` / `法术攻击`，其余为 `法术名:环阶[*][|详情]`，多项用 `;` 分隔；`0` = 戏法、尾部 `*` = 今日已准备；<br>详情写 `时间=1动作,距离=150尺,专注=是,仪式=否,材料=是,备注=…`（只用于卡面图）；见[休息与资源](./resources.md) | 可选 |
| `$法术位$` | 各环与契约法术位：`环阶:当前/上限`，契约写 `契约3:2/2`，多项用 `;` 分隔；见[休息与资源](./resources.md) | 可选 |

各段**顺序不限、可整段省略**（洛恩的卡就整段省掉了 `$额外加值$`）。新建成功后回「已新建角色卡…并绑定到本群。」。

### 修改现有卡（.角色卡修改）

补全卡面后整卡文本会很长，超过 QQ 单条消息上限；改卡不必重发整张卡，用 `.角色卡修改 <卡名> <段条目>` 只写要改的段即可：

| 输入 | 行为 |
| --- | --- |
| 一个或多个 `$段名$` | 只覆盖写到的段，其余段保持原样；`$等级$` / `$属性$` 同样只改这两段 |
| 段名后不写内容 | 清空该段（`$姓名$` / `$等级$` / `$属性$` 不能清空） |
| 多个段中有非法内容 | 整条命令拒绝，卡一点不变 |
| 群聊省略卡名 | 改本群当前绑定的卡；写卡名时必须是本群绑定卡 |
| 私聊省略卡名 | 仅当卡库只有一张卡时可用；多张必须写卡名 |

例如只补战斗数据：

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
:::

一次改多个段也可以；只写要改的段，没写的段不会动。要新增第二张卡请用 `.角色卡新建`，不要用 `.角色卡修改`。

## 额外加值

格式为 `条目:取值`，多个用 `/` 分隔；取值是**可选**的 `优势`/`劣势` 前缀加一段 ±掷骰表达式：

- 条目键：六属性名、技能名、`力量豁免`/`敏捷豁免`…；
- 另有作用于**全部**豁免的全局键：`豁免`；
- 没有内容就整段省略（洛恩的卡就省掉了 `$额外加值$`）；卡上带优劣势时，对应检定会直接掷出优势/劣势。

只登记**算得进检定**的部分，示例团两处加值都来自 2024 城主指南的魔法物品（数值出处见[示例团与人物](./cast.md#建卡依据)）：

| 角色 | 卡上的写法 | 含义 |
| --- | --- | --- |
| 塔莉 | `隐匿:优势` | 精灵之靴：潜行自带优势 |
| 布鲁姆 | `豁免:+1` | 防护斗篷：所有豁免 +1（另有一条 `隐匿:劣势` 来自链甲） |

武器的命中与伤害加值不走这里。直接写进 `$武器$` 项（薇拉的长剑 +1 已在 `长剑+8,1d8+5挥砍` 里），见[武器与攻击](./weapons.md)。

限时效果的加值（祝福术 `+1d4`、激励骰…）**不要写进卡**，写成命令里的临时加值即可，见[检定与豁免](./checks.md#临时加值-不进角色卡)。

## 修改与清除

改卡用 `.角色卡修改 <卡名> <段条目>`（只覆盖提到的段）；删除用 `.角色卡清除 <卡名> 确认`。**已绑定到群的卡不能直接删**：先在群里 `.角色卡解绑`（或在私聊 `.角色卡解绑 <群号>`），再删除。小鹿试完卡后删掉了它：

::: chat
小鹿 | .角色卡
屠龙骰 | $姓名$ 小鹿
$生命值$ 8/8
$等级$ 1
$属性$ 9/15/15/15/12/9
小鹿 | .角色卡解绑
屠龙骰 | 已解除本群的角色卡绑定
小鹿 | .角色卡清除 小鹿 确认
屠龙骰 | 角色卡「小鹿」已删除
:::

> 只想改 HP 不必动卡：`.hp 20/30` 直接覆盖（见[生命值管理](./hp.md)与[HP 进阶与长休](./hp-advanced.md)）。

## 常见错误

三类最常踩的坑，都会被**整体拒收**（原卡不受影响）：

::: chat
小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$属性$ 10/10/10/10/10/10
屠龙骰 | 必须设定等级与属性

注：漏了必填的 `$等级$`。

小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$属性$ 10/10/10
屠龙骰 | 必须设定全部的6项属性

注：`$属性$` 必须是 6 个数值。

小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$属性$ 10/10/10/10/10/10
$额外加值$ 隐匿优势+2
屠龙骰 | 必须使用冒号(:)分割额外加值条目和内容

注：`$额外加值$` 要写成 `条目:取值` 的冒号形式。
:::

还有一个**不会报错**的坑：`$属性$` 的六个数值按「力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力」固定对应，顺序写错不会拒收，但检定会全部对错列，登记前对着表核一遍。
