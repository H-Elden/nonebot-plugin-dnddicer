# 角色卡与检定

角色卡是 DND 检定的基础：把等级、六属性、熟练与额外加值记成一张卡，之后用
`.力量检定`、`.敏捷豁免`、`.敏捷攻击` 等点命令时，骰娘会自动代入卡上的
**属性调整值 + 熟练加值 + 额外加值**，不用每次手写算式。

> 角色卡与检定点命令**仅限群聊使用**（私聊提示「该指令仅在群聊中可用」），
> 每人在每个群拥有一张独立的卡（键 = 群号 + QQ）。

## 命令一览

| 命令 | 作用 |
| --- | --- |
| `.角色卡` | 查看自己的角色卡（$…$ 段落文本，可直接复制保存） |
| `.角色卡记录 <模板文本>` | 记录/覆盖自己的角色卡 |
| `.角色卡模板` | 查看示例卡与段落填写说明 |
| `.角色卡清除` | 删除自己的角色卡 |
| `.状态` | 查看 HP 与生命骰摘要 |
| `.xx检定` / `.xx豁免` / `.xx攻击` | 检定点命令（见下节） |

## 记录角色卡（.角色卡记录）

模板由 `$关键字$` 段落组成，示例（可直接复制修改）：

```text
你发送：.角色卡记录 $姓名$ 伊丽莎白
$等级$ 5
$生命值$ 20/30(5)
$生命骰$ 3/4 D8
$属性$ 15/14/13/12/10/8
$熟练$ 力量/隐匿
$额外加值$ 隐匿:优势
骰娘回复：角色卡已设置
```

| 段落 | 说明 | 是否必填 |
| --- | --- | --- |
| `$姓名$` | 角色名（检定反馈与先攻列表使用） | 可选 |
| `$等级$` | 角色等级（决定熟练加值） | 必填 |
| `$属性$` | 六个数值，用 `/` 分隔，依次对应 **力量/敏捷/体质/智力/感知/魅力** | 必填 |
| `$生命值$` | `当前/最大(临时)`，如 `20/30(5)` | 可选 |
| `$生命骰$` | `已用/总数 D骰面`，如 `3/4 D8` | 可选 |
| `$熟练$` | 熟练条目，用 `/` 分隔；`2*隐匿` 为双倍熟练，`0*隐匿` 显式关闭 | 可选 |
| `$额外加值$` | 见下节 | 可选 |

**属性调整值** = `(属性值 − 10) ÷ 2` 向下取整（如 15 → +2，8 → −1）；
**熟练加值** = `2 + (等级 − 1) ÷ 4` 向下取整（5 级 → +3）。
攻击/豁免/技能的熟练项**默认全部未熟练**——`$熟练$` 声明了哪些条目才有熟练加值。

### 额外加值（$额外加值$）

格式：`条目:取值`，多个用 `/` 分隔。取值可带 `优势`/`劣势` 前缀，再跟 `+`/`-` 开头的掷骰表达式：

- 条目键：六属性名、技能名、`力量豁免`/`敏捷豁免`…、`力量攻击`/`敏捷攻击`…，以及作用于所有豁免/攻击的**全局键 `豁免` / `攻击`**
- 示例：`隐匿:优势+2`（隐匿自带优势并 +2）、`豁免:+2`（所有豁免 +2）、`敏捷攻击:+1d4`

```text
你发送：.角色卡
骰娘回复：$姓名$ 伊丽莎白
$生命值$ 20/30 (5)
$生命骰$ 3/4 D8
$等级$ 5
$属性$ 15/14/13/12/10/8
$熟练$ 力量/隐匿
$额外加值$ 隐匿:优势
```

### 查看示例模板（.角色卡模板）

```text
你发送：.角色卡模板
骰娘回复：$姓名$ 张三
$生命值$ 20/30 (5)
$生命骰$ 3/4 D8
$等级$ 4
$属性$ 10/15/12/13/8/11
$熟练$ 体操/2*隐匿/敏捷豁免/敏捷攻击
$额外加值$ 敏捷攻击:+1d4/豁免:+2

——提示（记录时请仅复制上方模板段并修改）——
属性段六个数值依次对应: 力量/敏捷/体质/智力/感知/魅力
额外加值段键 = 六属性/技能/豁免/攻击条目, 另有作用于全部的全局键: 豁免 与 攻击
额外加值取值 = 可选 优势/劣势 前缀 + ±掷骰表达式, 如: 隐匿:优势+2
```

## 检定点命令

### 语法

```
.[次数#][条目](检定|豁免|攻击)[优势|劣势][±临时加值]
```

| 类型 | 条目 | 示例 |
| --- | --- | --- |
| 检定 | 六属性名 / 18 技能名 / 先攻（含常见同义词，如 观察→察觉、潜行→隐匿） | `.力量检定`、`.运动检定+1`、`.2#察觉检定`、`.先攻检定` |
| 豁免 | 六属性名 + 豁免 | `.体质豁免`、`.智力豁免+d4` |
| 攻击 | 六属性名 + 攻击 | `.敏捷攻击`、`.3#敏捷攻击优势+d8` |

- `N#` 前缀连掷 N 次（1~9，逐次独立掷骰并显示）；
- 临时 `优势`/`劣势` 与卡上自带优劣势**叠加、可抵消**（同名两次优劣势抵消后提示「优劣抵消」）；
- 检定只掷出裸数值（d20+加值），**不对 DC 做判定**——是否成功由玩家/DM 自行比较（与 DicePP 一致）；
- 无角色卡时提示「找不到角色卡」。

### 示例（伊丽莎白：5 级，力量 15 且力量熟练，体质 13，敏捷 14）

```text
你发送：.力量检定
骰娘回复：伊丽莎白进行【力量检定】：
熟练加值:3 力量调整值:2
1D20+2+3=[10]+2+3=15
```

```text
你发送：.体质豁免          ← 体质13 → 调整+1；未在 $熟练$ 声明 → 无熟练加值
骰娘回复：伊丽莎白进行【体质豁免】：
无熟练加值 体质调整值:1
1D20+1=[9]+1=10
```

```text
你发送：.敏捷攻击          ← 攻击默认不熟练（$熟练$ 未声明敏捷攻击）
骰娘回复：伊丽莎白进行【敏捷攻击】：
无熟练加值 敏捷调整值:2
1D20+2=[3]+2=5
```

### 大成功 / 大失败

检定 / 豁免 / 攻击点命令与 `.r` 使用同一套判定：**被保留的 d20 出目 20 → 播报
「好耶！大成功!」，出目 1 → 播报「哇哦！大失败!」**（攻击自然 1 同样播报——
5e 规则中攻击出目 1 必定失误）。`N#` 连掷时按次汇总（`1次 大成功`）。

```text
你发送：.力量检定
骰娘回复：伊丽莎白进行【力量检定】：
熟练加值:3 力量调整值:2
1D20+2+3=[20]+2+3=25 好耶！大成功!
```

### 先攻检定（.先攻检定）

`.先攻检定` 掷出先攻值后**自动加入本群先攻列表**（掷骰行会被替换为入表反馈）。
**先攻掷骰没有大成功/大失败播报**（规则上先攻无重击概念），掷出 20 也照常入表：

```text
你发送：.先攻检定
骰娘回复：伊丽莎白进行【先攻检定】：
无熟练加值 敏捷调整值:0
伊丽莎白的先攻值是 1D20=[20]=20
```

再次投掷会替换旧条目并提示「你重复投掷了先攻」。先攻列表的查看与管理见
[先攻列表](./initiative.md)。
