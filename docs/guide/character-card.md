# 角色卡与属性

角色卡是检定的基础：把等级、六属性、熟练与额外加值登记成一张卡，之后用 `.力量检定`、`.敏捷豁免`、`.隐匿检定` 这类点命令时，骰娘会自动代入卡上的加值，不必每次手写算式。

攻击检定与伤害掷骰需要手动录卡，走卡上的 `$武器$` 条目，见[武器与攻击](./weapons.md)；有使用次数的能力与法术资源走 `$能力$` / `$法术$` / `$法术位$`，见[休息与资源](./resources.md)；想让卡面以图片展示或设置立绘，见[角色卡图与立绘](./card-image.md)。

本页解决两件事：**属性从哪来**、**卡怎么登记**；卡登记好之后怎么掷检定，见[检定与豁免](./checks.md)。

> 角色卡与检定点命令**仅限群聊**；每人在每个群**只可拥有一张**独立的卡（键 = 群号 + QQ）。没建卡也能掷骰，只是检定点命令会提示「找不到角色卡」。

## 属性怎么来

DND 建卡的六属性有两条路：**购点**是纸面计算，**掷点**交给骰子。插件只参与后者。

### 购点法：纸面计算

标准做法是 27 点购点 → 叠加背景属性加值 → 再叠加属性值提升，最后把六个数值填进 `$属性$`。这一步插件不参与，示例团四张卡的完整算法与核对表见[示例团与人物](./cast.md#建卡依据)。

### 掷点法：.dnd 与 .dndx

两者都按 4D6K3 生成六项属性（每项掷 4 颗 D6、去掉最低的一颗、其余求和），区别只在结果**是否绑定属性名**：

| 命令 | 输出 | 适用场景 |
| --- | --- | --- |
| `.dnd` | 六项数值的**降序**列表（只出数值，不绑定） | 想自行把数值分配给六属性 |
| `.dndx` | 数值按固定顺序**直接绑定属性名**（不排序） | 掷出即定，直接抄进角色卡 |

命令后可跟**次数**与**原因**：`.dnd2` 一次掷两组（上限 20），原因会写进标题。DM 给客串 NPC 掷点：

::: chat
白鸦 | .dnd
屠龙骰 | 白鸦 DND人物作成:
74 : [18, 14, 13, 11, 10, 8]
白鸦 | .dnd2 替补
屠龙骰 | 白鸦 DND人物作成——替补:
70 : [17, 14, 13, 12, 7, 7]
76 : [18, 15, 14, 12, 9, 8]
:::

读法：`74` 是六项合计，`[18, 14, …]` 是六项数值的降序列表（第一项 18 出自 `6,6,6,1`，去掉 1 后 6+6+6），自行挑六个数字分配给属性即可。

次数写错时骰娘会直接说明，既不掷点、也不悄悄改次数：

::: chat
白鸦 | .dnd30
屠龙骰 | 次数超出上限：最多 20 次
白鸦 | .dndx 0
屠龙骰 | 次数至少为 1
:::

`.dndx` 的顺序与 `$属性$` 行完全一致（力量/敏捷/体质/智力/感知/魅力），掷出即定、按序抄写；小鹿试掷并登记：

::: chat
小鹿 | .dndx
屠龙骰 | 小鹿 DND人物作成(属性绑定):
75 : 力量 9、敏捷 15、体质 15、智力 15、感知 12、魅力 9
小鹿 | .角色卡记录
$姓名$ 小鹿
$等级$ 1
$生命值$ 8/8
$属性$ 9/15/15/15/12/9
屠龙骰 | 角色卡已设置
:::

### 段落一览

**加粗**为必填。表中的核心段用于检定与资源结算；后半部分扩展段用于完整卡面展示，不填也能正常跑团，填了才会出现在 `.角色卡图` 的图片卡上。

| 段落 | 说明 | 是否必填 |
| --- | --- | --- |
| `$姓名$` | 角色名，用于检定落款与先攻列表；不写时显示名回退到群名片 | 可选 |
| `$种族$` | 种族（如 `半精灵`），记录与展示用 | 可选 |
| `$职业$` | 12 职业规范名之一（如 `游荡者`）；**游荡者**的偷袭后缀会按等级自动附加偷袭骰 | 可选 |
| `$子职$` | 子职（如 `刺客`），记录与展示用 | 可选 |
| **`$等级$`** | 等级；熟练加值 = 2 + (等级 − 1) ÷ 4 向下取整（5 级 → +3） | **必填** |
| **`$属性$`** | 六个数值，用 `/` 分隔，依次对应 **力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力**；<br>骰娘自动计算：调整值 = (数值 − 10) ÷ 2 向下取整 | **必填** |
| `$生命值$` | `当前/最大(临时)`，如 `54/54`、`20/30 (5)`；<br>HP 结算改的是这里，见[生命值管理](./hp.md) | 可选 |
| `$生命骰$` | `当前/总数 D骰面`，如 `5/5 D8`；`.生命骰` 花骰与长休回复都按此结算 | 可选 |
| `$熟练$` | 熟练条目，用 `/` 分隔；`2*隐匿` 为**专精**（双倍熟练）；**先攻**也支持。<br>还可加四类展示分组：`护甲:轻甲·中甲`、`武器:军用武器`、`工具:盗贼工具`、`语言:通用语·精灵语`（组内用 `·` 分隔） | 可选 |
| `$额外加值$` | 见[下节](#额外加值) | 可选 |
| `$属性值$` | 六属性展示值：`力量:18/+4; 敏捷:12/+1; …`，六项全写；**仅展示，不参与检定** | 可选 |
| `$战斗$` | `AC:18; 先攻:+1; 速度:30; 被动察觉:13`；固定四项，只写有值的 | 可选 |
| `$进度$` | 经验与英雄激励：`经验:6500/14000; 激励:有`；经验写「当前/下一级」（可只写当前），激励写 `有` / `无` | 可选 |
| `$豁免$` | 六项豁免展示值：`力量:+7; 体质:+6`；只写有值的 | 可选 |
| `$技能$` | 技能展示值：`运动:+7; 隐匿:+5*; …`；尾部 `*` 表示专精，只写有值的 | 可选 |
| `$专长$` | 已获专长，用 `/` 分隔；可补一行说明：`巨武器大师:…/幸运` | 可选 |
| `$特性$` | 种族 / 职业 / 背景特性，用 `/` 分隔，可写来源与说明：`黑暗视觉（种族）:60 尺内微光视为明亮` | 可选 |
| `$物品$` | 背包：`名称x数量[装备]`，多项用 `;` 分隔，如 `治疗药水x2; 长剑x1[装备]` | 可选 |
| `$钱币$` | 五种币值：`CP:0; SP:8; EP:0; GP:18; PP:0`，只写有值的，未写按 0 显示 | 可选 |
| `$背景$` | 背景、阵营、信仰、体型、年龄、外貌、个性等，`键:值` 多项用 `;` 分隔 | 可选 |
| `$故事$` | 背景故事长文本，单行 ≤300 字；卡面「背景故事」面板 | 可选 |
| `$战斗记录$` | 战斗中的临时记录，自由文本多项用 `;` 分隔，如 `祝福术(专注,3轮); 中毒` | 可选 |
| `$能力$` | 有使用次数的能力：`名称:当前/上限恢复档[|说明]`，多项用 `;` 分隔；恢复档 `短休` / `长休` / `两者` / `手动`，可加 `+N` 或 `满`（如 `引导神力:2/2短休+1,长休`）；见[休息与资源](./resources.md) | 可选 |
| `$武器$` | 自定义武器/法术项：`名称+命中加值,伤害表达式+类型[,备注]`（如 `短剑+4,1d4+2穿刺,灵巧`），多项用 `/` 分隔；<br>名称尾加 `x` 表示不可攻击检定（如 `火球术x,8d6火焰`）；备注只用于卡面图；见[武器与攻击](./weapons.md) | 可选 |
| `$法术$` | 法术清单：头三个保留键 `施法属性` / `豁免DC` / `法术攻击`，其余为 `法术名:环阶[*][|详情]`，多项用 `;` 分隔；`0` = 戏法、尾部 `*` = 今日已准备；<br>详情写 `时间=1动作,距离=150尺,专注=是,仪式=否,材料=是,备注=…`（只用于卡面图）；见[休息与资源](./resources.md) | 可选 |
| `$法术位$` | 各环与契约法术位：`环阶:当前/上限`，契约写 `契约3:2/2`，多项用 `;` 分隔；见[休息与资源](./resources.md) | 可选 |

各段**顺序不限、可整段省略**（洛恩的卡就整段省掉了 `$额外加值$`）。记录成功后回「角色卡已设置」。

### 分段录入

补全卡面后整卡文本会很长，超过 QQ 单条消息上限。因此 `.角色卡记录` 支持只发一个段来改一处：

| 输入 | 行为 |
| --- | --- |
| 只带**一个** `$段名$` | 只改该段，其余段保持原样（改等级、属性、战斗数据都这样写） |
| 带**两个及以上**段 | 按整卡覆盖：没写的可选段会被清空，用于重录整张卡 |
| 没有卡时只发一个段 | 提示先发送完整卡面（需包含 `$等级$` 与 `$属性$`） |

例如只补战斗数据：

::: chat
小满 | .角色卡记录 $战斗$ AC:15; 先攻:+2; 速度:30; 被动察觉:13
屠龙骰 | 角色卡已设置
:::

只改等级与属性要分两条发；两条都属于单段修改，不会清空其他段。

再次发送带多个段的整卡会**整体覆盖**旧卡（立绘保留）：

$种族$ 人类
$职业$ 圣武士
$子职$ 奉献之誓
$等级$ 5
$生命值$ 54/54
$生命骰$ 5/5 D10
$属性$ 18/10/14/8/10/16
$熟练$ 感知豁免/魅力豁免/运动/威吓/洞悉/游说/察觉
$能力$ 圣疗:25/25长休; 引导神力:2/2短休+1,长休
$武器$ 长剑+8,1d8+5挥砍
$法术$ 施法属性:魅力; 制裁斩:1*; 治疗真言:1*; 神恩:1*

## 额外加值

格式为 `条目:取值`，多个用 `/` 分隔；取值是**可选**的 `优势`/`劣势` 前缀加一段 ±掷骰表达式：

- 条目键：六属性名、技能名、`力量豁免`/`敏捷豁免`…；
- 另有作用于**全部**豁免的全局键：`豁免`；
- 没有内容就整段省略（洛恩的卡省掉了 `$额外加值$`）；卡上带优劣势时，对应检定会直接掷出优势/劣势。

只登记**算得进检定**的部分，示例团两处加值都来自 2024 城主指南的魔法物品（数值出处见[示例团与人物](./cast.md#建卡依据)）：

| 角色 | 卡上的写法 | 含义 |
| --- | --- | --- |
| 塔莉 | `隐匿:优势` | 精灵之靴：潜行自带优势 |
| 布鲁姆 | `豁免:+1` | 防护斗篷：所有豁免 +1（另有一条 `隐匿:劣势` 来自链甲） |

武器的命中与伤害加值不走这里。直接写进 `$武器$` 项（薇拉的长剑 +1 已在 `长剑+8,1d8+5挥砍` 里），见[武器与攻击](./weapons.md)。

## 常见错误

三类最常踩的坑，都会被**整体拒收**（原卡不受影响）：

::: chat
小鹿 | .角色卡记录
$姓名$ 小鹿
$属性$ 10/10/10/10/10/10
屠龙骰 | 必须设定等级与属性

注：漏了必填的 `$等级$`。

小鹿 | .角色卡记录
$等级$ 1
$属性$ 10/10/10
屠龙骰 | 必须设定全部的6项属性

注：`$属性$` 必须是 6 个数值。

小鹿 | .角色卡记录
$等级$ 1
$属性$ 10/10/10/10/10/10
$额外加值$ 隐匿优势+2
屠龙骰 | 必须使用冒号(:)分割额外加值条目和内容

注：`$额外加值$` 要写成 `条目:取值` 的冒号形式。
:::

还有一个**不会报错**的坑：`$属性$` 的六个数值按「力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力」固定对应，顺序写错不会拒收，但检定会全部对错列，登记前对着表核一遍。
