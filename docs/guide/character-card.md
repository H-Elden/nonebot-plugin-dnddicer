# 角色卡与属性

角色卡是检定的基础：把等级、六属性、熟练与额外加值登记成一张卡，之后用 `.力量检定`、`.敏捷豁免`、`.隐匿检定` 这类点命令时，骰娘会自动代入卡上的加值，不必每次手写算式。属性调整值、豁免与技能加值都由骰娘按等级、属性、熟练与额外加值现算，卡面图也会显示算出的结果，不需要手填展示值。

攻击检定与伤害掷骰需要手动录卡，走卡上的 `$武器$` 条目，见[武器与攻击](./weapons.md)；有使用次数的限定资源与法术资源走 `$限定资源$` / `$法术$` / `$法术位$`，见[休息与资源](./resources.md)；想让卡面以图片展示或设置立绘，见[角色卡图与立绘](./card-image.md)。

本页解决两件事：**属性从哪来**、**卡怎么登记**；卡登记好之后怎么掷检定，见[检定与豁免](./checks.md)。

> 角色卡库**按 QQ 归属**，一个 QQ 最多同时持有 10 张卡；**每位玩家在每个群最多绑定一张卡**，并**推荐一张卡只绑定一个群**。同一张卡技术上可以绑到多个群，但生命值、激励、死亡豁免等随卡数据会共用，详见下文[卡库与群绑定](#卡库与群绑定-一卡一群)。群内依赖卡的命令只认**本群当前绑定**的卡，未绑定会提示先绑定（`.hp` 与 `.死亡豁免` 例外，无卡也能记录）。新建、查看、修改与绑定都可以在私聊完成；检定点命令仍仅限群聊。没建卡也能掷骰，只是检定点不会代入卡上加值。群内发 `.角色卡` 但还没有卡时，回复会提示绑定，并给出网页建卡器地址。

## 属性怎么来

DND 建卡的六属性有两条路：**购点**是纸面计算，**掷点**交给骰子。插件只参与后者。

### 购点法：纸面计算

标准做法是 27 点购点 → 叠加背景属性加值 → 再叠加属性值提升，最后把六个数值填进 `$属性$`。这一步插件不参与，示例团四张卡的完整算法与核对表见[示例团与人物](./cast.md#建卡依据)。

### 掷点法：.dnd 与 .dndx

两者都按 4D6K3 生成六项属性（每项掷 4 颗 D6、去掉最低的一颗、其余求和），区别只在结果**是否绑定属性名**：

| 命令 | 输出 | 适用场景 |
| --- | --- | --- |
| `.dnd` | 六项数值的**降序**列表（只出数值，不绑定） | 想自行把数值分配给六属性 |
| `.dndx` | 数值按固定顺序**直接绑定属性名**（不排序） | 掷出即定，直接抄进角色卡 |

命令后可跟**次数**与**原因**：`.dnd2` 一次掷两组（上限 20），原因会写进标题。DM 给客串 NPC 掷点：

::: chat
白鸦 | .dnd
屠龙骰 | 白鸦 DND人物作成:
74 : [18, 14, 13, 11, 10, 8]
白鸦 | .dnd2 替补
屠龙骰 | 白鸦 DND人物作成——替补:
70 : [17, 14, 13, 12, 7, 7]
76 : [18, 15, 14, 12, 9, 8]
:::

读法：`74` 是六项合计，`[18, 14, …]` 是六项数值的降序列表（第一项 18 出自 `6,6,6,1`，去掉 1 后 6+6+6），自行挑六个数字分配给属性即可。

次数写错时骰娘会直接说明，既不掷点、也不悄悄改次数：

::: chat
白鸦 | .dnd30
屠龙骰 | 次数超出上限：最多 20 次
白鸦 | .dndx 0
屠龙骰 | 次数至少为 1
:::

`.dndx` 的顺序与 `$属性$` 行完全一致（力量/敏捷/体质/智力/感知/魅力），掷出即定、按序抄写；小鹿试掷并登记：

::: chat
小鹿 | .dndx
屠龙骰 | 小鹿 DND人物作成(属性绑定):
75 : 力量 9、敏捷 15、体质 15、智力 15、感知 12、魅力 9
小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$生命值$ 8/8
$属性$ 9/15/15/15/12/9
屠龙骰 | 已新建角色卡「小鹿」并绑定到本群。
:::

## 新建与修改角色卡（.角色卡新建 / .角色卡修改）

新建一张卡用 `.角色卡新建 <卡名> <完整卡内容>`：卡面按 `$段名$ 内容` 逐行写（也可以直接抄[示例团与人物](./cast.md)里的现成卡改，或在[网页建卡器](./card-builder.md)里填表生成命令）；在卡面最前面加上 `.角色卡新建 <卡名>`，卡面从第二行起顶头写。卡内容必须包含 `$姓名$`、`$等级$` 与 `$属性$`，否则整条拒绝、不会建卡。

卡名是你在卡库里的标识（≤20 字符，不能含空格、`$`、`@`），与卡内的 `$姓名$` 分开。群聊新建成功后会自动绑定到本群；私聊新建不会自动绑定，建好后用 `.角色卡绑定 <卡名> <群号>` 绑到跑团群。一个 QQ 最多同时持有 10 张卡。

改卡用 `.角色卡修改 <卡名> <段条目>`：只覆盖你写到的段，未提到的段保持原样；可以一次写多个段，空段表示清空该段，`$姓名$` / `$等级$` / `$属性$` 不能清空。私聊有多张卡时必须带卡名；只有一张时可以省略。群聊只能修改本群当前绑定的卡，省略卡名时默认就是它。

不想手打整张卡时，可以用[网页建卡器](./card-builder.md)填表，再复制生成的整卡命令或分段命令；已有的卡也能粘回表单继续改。

### 段落一览

**加粗**为必填。表中的核心段用于检定与资源结算；后半部分扩展段用于完整卡面展示，不填也能正常跑团，填了才会出现在 `.角色卡` 的图片卡上。属性调整值、豁免与技能加值均由骰娘按 `$属性$`、`$等级$`、`$熟练$` 与 `$额外加值$` 现算，不需要手填展示值。

| 段落 | 说明 | 是否必填 |
| --- | --- | --- |
| `$姓名$` | 角色名，用于检定落款与先攻列表；不写时显示名回退到群名片 | 可选 |
| `$种族$` | 种族（如 `半精灵`），记录与展示用 | 可选 |
| `$职业$` | 标准 12 职业规范名之一或扩展职业名（如 `法师`、`机关术师`）；只有**游荡者**的偷袭后缀会按等级自动附加偷袭骰 | 可选 |
| `$子职$` | 子职（如 `塑能师`）；5r 全部职业 3 级获得，5e 按职业（牧师/术士/魔契师 1 级、德鲁伊/法师 2 级、其余 3 级） | 可选 |
| **`$等级$`** | 等级；熟练加值 = 2 + (等级 − 1) ÷ 4 向下取整（5 级 → +3） | **必填** |
| **`$属性$`** | 六个**最终值**（已含种族、背景、专长等全部加值），用 `/` 分隔，依次对应 **力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力**；<br>骰娘自动计算：调整值 = (数值 − 10) ÷ 2 向下取整 | **必填** |
| `$生命值$` | `当前/最大(临时)`，如 `54/54`、`20/30 (5)`；<br>HP 结算改的是这里，见[生命值管理](./hp.md) | 可选 |
| `$生命骰$` | `当前/总数 D骰面`，如 `5/5 D8`；`.生命骰` 花骰与长休回复都按此结算 | 可选 |
| `$熟练$` | 熟练条目，用 `/` 分隔；写**豁免**用 `感知豁免` 全名，写技能直接写技能名（如 `隐匿`）；`2*隐匿` 为**专精**（双倍熟练）；**先攻**也支持。<br>还可加四类展示分组：`护甲:轻甲·中甲`、`武器:简易武器`、`工具:书法工具`、`语言:通用语·精灵语`（组内用 `·` 分隔） | 可选 |
| `$额外加值$` | 属性检定 / 技能检定 / 豁免 / 先攻的额外加值，见[下节](#额外加值) | 可选 |
| `$战斗$` | `AC:18; 速度:30`；只写 AC 与速度；**先攻**由骰娘按敏捷调整值、先攻熟练与额外加值计算，**被动察觉** = 10 + 察觉检定加值（优势 +5、劣势 -5），都不需要写；2014 观察力这类只加被动值的专长暂不自动识别 | 可选 |
| `$进度$` | 经验与英雄激励：`经验:6500; 激励:有`；**下一级经验**由骰娘按等级表计算，不需要写；激励可用 `.激励` 命令查看、获得、消耗与转赠 | 可选 |
| `$专长$` | 已获专长，用 `/` 分隔；可补一行说明：`巨武器大师:…/幸运` | 可选 |
| `$种族特性$` | 种族特性，`名称:说明`，多项用 `/` 分隔：`黑暗视觉:60 尺内微光视为明亮` | 可选 |
| `$职业特性$` | 职业特性，`等级\|名称:说明`，多项用 `/` 分隔：`3\|塑能学者:法术书免费加入…`；卡图按等级升序显示「N级」徽标 | 可选 |
| `$物品$` | 背包：`名称x数量`，多项用 `;` 分隔，如 `治疗药水x2; 长剑x1`；魔法物品写到 `$魔法物品$` | 可选 |
| `$钱币$` | 五种币值：`CP:0; SP:8; EP:0; GP:18; PP:0`，只写有值的，未写按 0 显示；收支用 `.钱币` 命令 | 可选 |
| `$背景$` | 固定键 `背景 / 阵营 / 信仰 / 体型 / 年龄 / 外貌 / 个性`（5e 另有 `理想 / 羁绊 / 缺点`），`键:值` 多项用 `;` 分隔；空值不写 | 可选 |
| `$故事$` | 背景故事，可多行、多段，最多 1000 字（换行不计）；卡面每段首行缩进两字 | 可选 |
| `$战斗记录$` | 战斗中的临时记录，自由文本多项用 `;` 分隔，如 `祝福术(专注,3轮); 中毒`；增删用 `.战斗记录` 命令 | 可选 |
| `$限定资源$` | 有使用次数的资源：`名称:当前/上限恢复档[|说明]`，多项用 `;` 分隔；恢复档 `短休` / `长休` / `两者` / `手动`，可加 `+N` 或 `满`（如 `引导神力:2/2短休+1,长休`）；见[休息与资源](./resources.md) | 可选 |
| `$魔法物品$` | `名称\|标签\|说明`，多项用 `;` 分隔；说明用 `//` 分段：`防护斗篷\|奇物，非普通（需同调）\|AC 和豁免 +1。//银线织成。`；卡面单独显示 | 可选 |
| `$武器$` | 自定义武器/法术项：`名称+命中加值,伤害表达式+类型[,备注]`（如 `短剑+4,1d4+2穿刺,灵巧`），多项用 `/` 分隔；<br>名称尾加 `x` 表示不可攻击检定（如 `火球术x,8d6火焰`）；备注只用于卡面图；见[武器与攻击](./weapons.md) | 可选 |
| `$法术$` | 法术清单：头三个保留键 `施法属性` / `豁免DC` / `法术攻击`，其余为 `法术名:环阶[*][|详情]`，多项用 `;` 分隔；`0` = 戏法、尾部 `*` = 今日已准备；<br>详情写 `时间=1动作,距离=150尺,专注=是,仪式=否,材料=是,备注=…`（只用于卡面图）；见[休息与资源](./resources.md) | 可选 |
| `$法术位$` | 各环与契约法术位：`环阶:当前/上限`，契约写 `契约3:2/2`，多项用 `;` 分隔；见[休息与资源](./resources.md) | 可选 |

各段**顺序不限、可整段省略**（洛恩的卡就整段省掉了 `$额外加值$`）。新建成功后回「已新建角色卡…并绑定到本群。」。

### 修改现有卡（.角色卡修改）

补全卡面后整卡文本会很长，超过 QQ 单条消息上限；改卡不必重发整张卡，用 `.角色卡修改 <卡名> <段条目>` 只写要改的段即可：

| 输入 | 行为 |
| --- | --- |
| 一个或多个 `$段名$` | 只覆盖写到的段，其余段保持原样；`$等级$` / `$属性$` 同样只改这两段 |
| 段名后不写内容 | 清空该段（`$姓名$` / `$等级$` / `$属性$` 不能清空） |
| 多个段中有非法内容 | 整条命令拒绝，卡一点不变 |
| 群聊省略卡名 | 改本群当前绑定的卡；写卡名时必须是本群绑定卡 |
| 私聊省略卡名 | 仅当卡库只有一张卡时可用；多张必须写卡名 |

例如只补战斗数据：

::: chat
小满 | .角色卡修改 洛恩 $战斗$ AC:15; 速度:30
屠龙骰 | 角色卡「洛恩」已修改
:::

一次改多个段也可以；只写要改的段，没写的段不会动。要新增第二张卡请用 `.角色卡新建`，不要用 `.角色卡修改`。

## 额外加值

格式为 `条目:取值`，多个用 `/` 分隔；取值是**可选**的 `优势`/`劣势` 前缀加一段 ±掷骰表达式：

- 条目键：六属性名、技能名、`力量豁免`/`敏捷豁免`…；
- 另有作用于**全部**豁免的全局键：`豁免`；
- 没有内容就整段省略（洛恩的卡就省掉了 `$额外加值$`）；卡上带优劣势时，对应检定会直接掷出优势/劣势。

只登记**算得进检定**的部分，示例团两处加值都来自 2024 城主指南的魔法物品（数值出处见[示例团与人物](./cast.md#建卡依据)）：

| 角色 | 卡上的写法 | 含义 |
| --- | --- | --- |
| 塔莉 | `隐匿:优势` | 精灵之靴：潜行自带优势 |
| 布鲁姆 | `豁免:+1` | 防护斗篷：所有豁免 +1（另有一条 `隐匿:劣势` 来自链甲） |

武器的命中与伤害加值不走这里。直接写进 `$武器$` 项（薇拉的长剑 +1 已在 `长剑+8,1d8+5挥砍` 里），见[武器与攻击](./weapons.md)。

限时效果的加值（祝福术 `+1d4`、激励骰…）**不要写进卡**，写成命令里的临时加值即可，见[检定与豁免](./checks.md#临时加值-不进角色卡)。

- **私聊按卡名选卡**：没有默认卡；卡库只有一张时可以省略卡名，多张时必须写 `.角色卡 <卡名>`（`.角色卡导出` 同）；
- `.状态` 查看他人支持 `@玩家` 与角色名两种写法（与 `.角色卡` 同源搜索）；
- `$熟练$` 的书写顺序不限，查看时按「技能 → 豁免」的固定次序显示；
- 除 `.hp` / `.ds` 外，@ 到未绑定成员会提示先绑定；角色名命中 NPC 条目时提示「是NPC条目，没有角色卡」。

## 卡库与群绑定（一卡一群）

角色卡按 QQ 归属：每位玩家在每个群最多绑定一张卡，推荐**一张卡只绑定一个群**。骰娘不会阻止你把同一张卡绑到第二个群，绑定会照常执行，但回复末尾会提醒「注意：同一张卡绑定多个群聊可能造成数据冲突！」；生命值、激励、死亡豁免、法术位、限定资源等数据都记在卡上，同一张卡在两个群同时使用会读写同一份数据，一个团的消耗与状态会带到另一个团。

要同时跑两个团，请**另建一张卡名不同、内容相同的卡**，分别绑定到各自的群：先用 `.角色卡导出 [卡名]` 复制原卡文本，再用 `.角色卡新建 <新卡名>` 建一张新卡（也可以在[网页建卡器](./card-builder.md)里导入原卡文本、改好卡名后生成命令），最后在群里 `.角色卡绑定 <新卡名>` 或私聊 `.角色卡绑定 <新卡名> <群号>`。两张卡的立绘与资源各自独立。

如果一张卡已经绑到多个群，`.角色卡清除` 会拒绝删除，需要先在各个绑定的群用 `.角色卡解绑`（或在私聊用 `.角色卡解绑 <群号>` 逐个解除），再删除。

## 快速记录（.激励 / .战斗记录 / .钱币）

这三段都有专门命令直接改卡，不需要整段重写，其他段（包括经验、物品、武器等）不会被覆盖。

### 英雄激励（.激励）

2024 / 5r 群称「英雄激励」，2014 / 5e 群称「激励」；称呼随[群级规则版本](./rules-version.md)变化，数据仍记在 `$进度$` 的 `激励:` 键上，值只有 `有` / `无`，没写过时显示「未记录」。

- `.激励` 或 `.激励 状态`：查看本人当前状态；
- `.激励 +` / `.激励 -`：获得 / 消耗；已有激励时不能叠加，没有时不能消耗；
- `.激励 给予 <目标>`：把本人的激励转赠给 `@玩家` 或本群角色名，目标须已绑定角色卡且当前没有激励；名称精确优先、其次子串，多候选只列清单不猜。

示例团薇拉把两次激励分别转给塔莉和布鲁姆，洛恩在后面的 5e 群里看到的是「激励」：

::: chat
阿茶 | .激励
屠龙骰 | 薇拉的英雄激励：未记录
阿茶 | .激励 +
屠龙骰 | 薇拉获得了英雄激励。
阿茶 | .激励 给予 @老猫
屠龙骰 | 薇拉将英雄激励转赠给塔莉。
老猫 | .激励
屠龙骰 | 塔莉的英雄激励：有
阿茶 | .激励 +
屠龙骰 | 薇拉获得了英雄激励。
阿茶 | .激励 给予 布鲁姆
屠龙骰 | 薇拉将英雄激励转赠给布鲁姆。
阿岩 | .激励
屠龙骰 | 布鲁姆的英雄激励：有
白鸦 | .规则版本 5e
屠龙骰 | 已设置：本群规则版本为 2014（5e）。
小满 | .激励
屠龙骰 | 洛恩的激励：未记录
小满 | .激励 +
屠龙骰 | 洛恩获得了激励。
白鸦 | .规则版本 5r
屠龙骰 | 已设置：本群规则版本为 2024（5r）。
:::

### 战斗记录（.战斗记录）

`$战斗记录$` 用来记专注中的法术、中毒、短暂状态等临时信息，最多 20 条、每条 60 字，条目里不能有 `$`。

- `.战斗记录` 按序号列出全部条目；
- `.战斗记录 +文本` 追加一条，文本含 `;` 时一次追加多条；
- `.战斗记录 -序号` 按 1 起的序号删除，多个序号用 `/` 或 `;` 分隔（如 `-1/3`）；
- `.战斗记录 清` 清空全部。

::: chat
老猫 | .战斗记录
屠龙骰 | 还没有战斗记录。可用 .战斗记录 +文本 添加（多项用 ; 分隔）
老猫 | .战斗记录 +祝福术(专注,3轮)
屠龙骰 | 已添加 1 条战斗记录：祝福术(专注,3轮)（当前共 1 条）
老猫 | .战斗记录 +中毒; 目盲
屠龙骰 | 已添加 2 条战斗记录：中毒；目盲（当前共 3 条）
老猫 | .战斗记录
屠龙骰 | 战斗记录（3 条）：
1. 祝福术(专注,3轮)
2. 中毒
3. 目盲
老猫 | .战斗记录 -2
屠龙骰 | 已删除战斗记录：中毒
老猫 | .战斗记录 清
屠龙骰 | 已清空战斗记录（2 条）
:::

### 钱币收支（.钱币）

- `.钱币` 查看 CP / SP / EP / GP / PP 五种币值；
- `.钱币 +20GP-5SP` 紧凑写法，大小写不敏感，可连续写多条，按书写顺序结算；操作之间允许空格；
- 加法只加指定币种，**不做汇率换算**；
- 减法先扣指定币种，不足时按「最接近的更高币种优先」破开（CP 用 SP/EP/GP/PP，SP 用 EP/GP/PP，EP 用 GP/PP，GP 用 PP），更高币种仍不足才用更低币种按面值抵扣；换算率固定 `1 PP = 10 GP`、`1 GP = 10 SP = 100 CP`、`1 EP = 5 SP`；
- 整条命令原子：任一条减法总价值不足就整条拒绝，不部分扣款；
- 结算行只列出**数值发生变化**的币种。

::: chat
老猫 | .钱币
屠龙骰 | 钱币：CP 0；SP 0；EP 0；GP 0；PP 0
老猫 | .钱币 +20GP-5SP
屠龙骰 | 钱币：+20GP，-5SP
SP 不足：拆 1 GP → +10 SP，扣 5 SP，余 5 SP
GP:0 → 19；SP:0 → 5
老猫 | .钱币 -19GP
屠龙骰 | 钱币：-19GP
GP:19 → 0
老猫 | .钱币 +10SP
屠龙骰 | 钱币：+10SP
SP:5 → 15
老猫 | .钱币 -1GP
屠龙骰 | 钱币：-1GP
GP 不足：用 10 SP 折算 1 GP，扣 10 SP，余 5 SP
SP:15 → 5
:::

## 修改与清除

改卡用 `.角色卡修改 <卡名> <段条目>`（只覆盖提到的段）；删除用 `.角色卡清除 <卡名> 确认`。**已绑定到群的卡不能直接删**：先在各个已绑定的群用 `.角色卡解绑`（或在私聊用 `.角色卡解绑 <群号>` 逐个解除），再删除。小鹿建了一张名为「角色卡1」的临时卡，试完后删掉了它：

::: chat
小鹿 | .角色卡
屠龙骰 | $姓名$ 小鹿
$生命值$ 8/8
$等级$ 1
$属性$ 9/15/15/15/12/9
小鹿 | .角色卡解绑
屠龙骰 | 已解除本群的角色卡绑定
小鹿 | .角色卡清除 角色卡1 确认
屠龙骰 | 角色卡「角色卡1」已删除
:::

> 只想改 HP 不必动卡：`.hp 20/30` 直接覆盖（见[生命值管理](./hp.md)与[HP 进阶](./hp-advanced.md)）。

## 常见错误

三类最常踩的坑，都会被**整体拒收**（原卡不受影响）：

::: chat
小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$属性$ 10/10/10/10/10/10
屠龙骰 | 必须设定等级与属性

注：漏了必填的 `$等级$`。

小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$属性$ 10/10/10
屠龙骰 | 必须设定全部的6项属性

注：`$属性$` 必须是 6 个数值。

小鹿 | .角色卡新建 小鹿
$姓名$ 小鹿
$等级$ 1
$属性$ 10/10/10/10/10/10
$额外加值$ 隐匿优势+2
屠龙骰 | 必须使用冒号(:)分割额外加值条目和内容

注：`$额外加值$` 要写成 `条目:取值` 的冒号形式。
:::

还有一个**不会报错**的坑：`$属性$` 的六个数值按「力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力」固定对应，顺序写错不会拒收，但检定会全部对错列，登记前对着表核一遍。
