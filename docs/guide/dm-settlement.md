# 血量与伤害结算（DM）

战斗里伤害怎么落账，本页是 DM 的结算手册：给怪记血与扣血、给玩家角色扣血，以及三种常用打法。记血策略与 `.hp` 基础写法见[生命值管理](./hp.md)，`@` 代掷机制见[代掷与代操作](./dm-proxy.md)。

## 给怪物扣血

前提是怪物**已入先攻表**，否则记血会被直接挡下：

::: chat
白鸦 | .hp 木乃伊 58/58
屠龙骰 | 找不到木乃伊的生命值信息
新NPC需要先加入先攻表才可设置HP
:::

入表后按策略记血：能公开的杂兵记「当前 / 上限」，Boss 留白（第一次挨打自动从 `损失HP:0` 记起），友军记完再挂 `.npc 持久` 跨战斗沿用。结算时把承伤特性挂在目标名后，读数自动折算；范围伤害用 `;` 分隔目标、**掷一次逐目标结算**：

::: chat
白鸦 | .hp 骷髅a;骷髅b;木乃伊易伤 -8d6
屠龙骰 | 骷髅a: 当前HP减少[2+3+1+4+2+5+1+3]=21; HP:3/13 -> HP:0/13 昏迷
骷髅b: 当前HP减少[2+3+1+4+2+5+1+3]=21; HP:6/13 -> HP:0/13 昏迷
木乃伊: 当前HP减少[2+3+1+4+2+5+1+3]=21（易伤加倍→42）; 损失HP:3 -> 损失HP:45

注：小满去接水了，洛恩的火球术由 DM 代发；三大目标里只有木乃伊对火焰易伤。
:::

## 给玩家角色扣血与治疗

玩家角色走角色卡：`@` 直连本人卡，写名称则走三层搜索（见[代掷与代操作](./dm-proxy.md)）；治疗同理，且不会超过上限：

::: chat
白鸦 | .hp @小满 -2d6
屠龙骰 | 洛恩: 当前HP减少[4+3]=7
HP:34/37 -> HP:27/37
:::

::: chat
阿岩 | .hp 薇拉 +2d8+4
屠龙骰 | 薇拉: 当前HP增加[3+4]+4=11
HP:40/54 -> HP:51/54
:::

## 三种结算打法

**① 玩家不熟悉特性的怪**：让玩家用 `.X伤害` 掷伤害（读数自带伤害类型），你按裁定手动打进 `.hp`，避免玩家直接操作敌人血量时漏算抗性 / 易伤：

::: chat
老猫 | .匕首攻击
屠龙骰 | 塔莉进行【匕首攻击检定】：
武器命中加值:+7
1D20+7=[19]+7=26
白鸦 | 命中！请掷伤害骰！
老猫 | .匕首伤害
屠龙骰 | 塔莉用【匕首】造成了 6 点穿刺伤害：
1D4+4=[2]+4=6
白鸦 | .hp 木乃伊抗性 -6
屠龙骰 | 木乃伊: 当前HP减少6（抗性减半→3）
损失HP:0 -> 损失HP:3
:::

**② 玩家熟悉的怪**：让玩家用 `.hp` 一条命令掷伤加扣血（伤害位置写卡上武器项，见[HP 进阶与长休](./hp-advanced.md)）：

::: chat
阿岩 | .战锤攻击
屠龙骰 | 布鲁姆进行【战锤攻击检定】：
武器命中加值:+5
1D20+5=[16]+5=21
阿岩 | .hp 骷髅a易伤 -战锤伤害
屠龙骰 | 布鲁姆用【战锤】造成了 10 点钝击伤害：
骷髅a: 当前HP减少[3]+2=5（易伤加倍→10）
HP:13/13 -> HP:3/13
:::

**③ 你的回合**（怪物与 NPC 行动）：你知道全场数据，直接 `.hp` 一步到位：

::: chat
白鸦 | .hp 向导 -d6+3
屠龙骰 | 向导: 当前HP减少[5]+3=8
HP:22/22 -> HP:14/22
:::

## 代发：玩家离席时

玩家临时离席，代他把伤害打出来：武器来源写在**尾部括号**里（角色名支持模糊匹配，也可写 `@玩家`），武器项取该玩家角色卡：

::: chat
白鸦 | .hp 骷髅b易伤 -火焰箭伤害（洛恩）
屠龙骰 | 洛恩用【火焰箭】造成了 4 点火焰伤害：
骷髅b: 当前HP减少[1+1]=2（易伤加倍→4）
HP:13/13 -> HP:9/13
白鸦 | .hp 骷髅b -匕首伤害（@小满）
屠龙骰 | 洛恩用【匕首】造成了 3 点穿刺伤害：
骷髅b: 当前HP减少[1]+2=3
HP:9/13 -> HP:6/13
:::

## 结算速记

| 场景 | 写法 |
| --- | --- |
| 记怪血 | `.hp 骷髅a 13/13`（先入先攻表）；Boss 留白、友军记完加 `.npc 持久` |
| 怪物受伤 | `.hp 木乃伊抗性 -6`、`.hp 向导 -d6+3` |
| 玩家受伤（代结算） | `.hp @玩家 -4d6`（或名称写法 `.hp 角色名 -8`） |
| 玩家治疗 | `.hp @玩家 +2d8+4` |
| 代发武器伤害 | `.hp 骷髅b易伤 -火焰箭伤害（洛恩）` |
| 代玩家收尾 | `.长休 @玩家` |
