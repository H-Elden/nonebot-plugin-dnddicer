# 先攻列表（.init / .ri / .先攻）

先攻列表按**群**维护：入表实体按先攻值降序排列，战斗轮复用这张表推进回合。实体名称是**入表时的快照**（角色卡名 → 群名片 → QQ 昵称 → 「未知玩家（QQ号）」，见[名称显示规则](./overview.md#名称显示规则)）；绑定 QQ 的玩家重掷会替换自己的旧条目。列表查看/管理仅限群聊。

## 投掷先攻入表（.ri）

| 用法 | 含义 |
| --- | --- |
| `.ri` | 为自己掷先攻（d20 + 无加值）并入表 |
| `.ri优势+1` / `.ri+2` | 带优劣势/加值 |
| `.ri20 地精` | 固定先攻值 20 入表（DM 常用） |
| `.ri+3 地精/兽人` | 多个目标**各自独立掷骰**入表 |
| `.ri+2 地精优势/灵活地精+1` | 名称后跟它的专属修正 |
| `.ri 3#食人魔僵尸` | 批量同名实体（自动加 a/b/c 后缀） |
| `.ri+3 @玩家` | 代不在场的玩家掷：条目名取**角色卡名**并与该玩家绑定 |
| `.ri 地精/@玩家` | @ 与 NPC 条目混写（各自掷骰） |

```text
你发送：.ri
骰娘回复：艾琳的先攻值是 1D20=[10]=10

你发送：.ri20 地精
骰娘回复：地精的先攻值是 20

你发送：.ri优势+2 地精
骰娘回复：地精的先攻值是 2D20K1+2=MAX{[9], [7]}+2=11
```

同名重掷会**替换旧条目**并提示（不需要先删除再投）：

```text
你发送：.ri10 地精
骰娘回复：你重复投掷了先攻
地精的先攻值是 10
```

复数目标批量入表：

```text
你发送：.ri 兽人/食尸鬼
骰娘回复：兽人的先攻值是 1D20=[3]=3
食尸鬼的先攻值是 1D20=[4]=4
```

### 代不在场的玩家（.ri @玩家）

用 **@群成员** 代掷先攻：条目名取该玩家的**角色卡名**，并与其 QQ **绑定**——
之后重掷替换其旧条目、轮到该条目时照常 @ 提醒、`.hp` 按名称也能命中该角色卡：

```text
你发送：.ri+3 @布兰克
骰娘回复：布兰克的先攻值是 1D20+3=[10]+3=13
```

| 写法 | 含义 |
| --- | --- |
| `.ri @布兰克优势` / `.ri @布兰克+2` | 优劣势/加值写在标记**之后**照常生效 |
| `.ri 20 @布兰克` / `.ri+3 @布兰克` | 固定值 / 加值代掷 |
| `.ri 地精/@布兰克` | 与 NPC 条目混写（各自独立掷骰） |

- @ 的目标需已建卡，否则回复
  `@玩家 还没有在本群建立角色卡（可用 .角色卡记录 建卡后再试）；如需临时加同名怪物条目，可直接写名称（.ri+3 名称）`；
- `.ri 3#@玩家` 这类批量写法不支持（批量会派生 a/b/c 后缀）：提示「请直接写条目名称」；
- **游离 @**：`@玩家 .ri+3`、`.ri @玩家 布兰克` 这类 @ 不在表达式右侧的写法**不执行**，
  提示「未执行：目标请写在表达式右侧，例如 .ri+3 @玩家」（避免静默给发送者自己掷先攻）。

### NPC 血量自动回满

NPC（显式命名入表的条目）若已有设过上限的血量记录，以**新条目**入表时自动
回满，并给出「沿用上次血量 / 跨战斗保持」的写法（详见 [HP 管理](./hp-rest.md)
的「NPC / 怪物血量」）：

```text
你发送：.ri15 哥布林
骰娘回复：哥布林的先攻值是 15
注：哥布林 已自动回满 20/20（上次 16/20）
如需沿用上次血量:
.hp 哥布林 16/20
如需跨战斗保持血量:
.npc 持久 哥布林
```

> 同名条目在同一场战斗中重掷先攻不触发回满；只记录受损（`损失HP:N`）的条目
> 与 `.npc 持久` 标记的条目同样不参与。

## 查看列表（.init / .先攻）

```text
你发送：.init
骰娘回复：先攻列表如下: 
当前是第1轮,地精的回合
1.地精 先攻:20 
2.食尸鬼 先攻:4 
3.兽人 先攻:3
```

- 列表按先攻值**降序**；有 HP 记录的条目会附 `HP:20/30` 摘要——PC 取角色卡
  血量，NPC 取 `.hp 名称 ...` 记录（先 `.ri` 入表后即可记录，见 [HP 管理](./hp-rest.md)）；
- 出现相同先攻值时两实体并存，并提示 DM 处理：

```text
骰娘回复：兽人的先攻值是 10
出现相同先攻值，请DM来决定由谁先行动，若不决定将保持默认顺序：
回复.init first 名称 将该对象提前（同先攻值: 兽人 / 地精）
```

## 管理子指令

| 子指令 | 作用 | 示例 |
| --- | --- | --- |
| `list` / `列表` | 查看（同无参数） | `.init list` |
| `del` / `删除` / `clr` / `清除` | 删除条目 / 清空整个列表 | `.init del 地精a/地精b`、`.先攻清除` |
| `first` / `fst` / `提前` | 相同先攻值中提前 | `.init first 兽人` |
| `swap` / `交换` | 互换两个条目的先攻值与位置 | `.init swap 地精/兽人` |

`del` / `first` / `swap` 的目标除名称外也支持 **@玩家**——按**归属**定位条目，
角色卡改名后仍有效；@ 的玩家不在先攻表时会回复 `@玩家 不在先攻列表中`：

```text
你发送：.init del @布兰克          ← 按归属移除该玩家的条目（不涉及 NPC 血量）
骰娘回复：已从先攻列表中移除 布兰克

你发送：.init first @布兰克        ← 同先攻值内提前
骰娘回复：布兰克的先攻已在相同先攻值中被提前

你发送：.init swap @布兰克/兽人    ← 单参数形式中自己一侧恒为发送者
骰娘回复：布兰克与兽人的先攻值已互换
```

```text
你发送：.init del 精a              ← 支持部分匹配（唯一匹配即删除）
骰娘回复：已从先攻列表中移除 地精a

你发送：.init del 地精
骰娘回复：先攻对象名称地精存在歧义，可能是['地精a', '地精b']   ← 匹配多个时报歧义

你发送：.init swap 地精/兽人
骰娘回复：地精与兽人的先攻值已互换
```

无列表/空列表时查看提示「没有找到先攻列表」；未知子指令会列出可用子指令。
`del` 删除 NPC 条目时会一并删除其血量记录；`clr` 清空时清理 NPC 的临时血量
（未设上限、只记受损的条目），设过上限与 `.npc 持久` 的记录保留。

## 先攻检定联动（.先攻检定）

**绑定角色卡**的玩家可直接发 `.先攻检定`：骰娘用角色卡的敏捷调整等自动掷先攻、把结果**直接写入先攻列表**并把掷骰行替换为入表反馈（先攻掷骰不播报大成功/大失败）：

```text
你发送：.先攻检定
骰娘回复：伊丽莎白进行【先攻检定】：
无熟练加值 敏捷调整值:0
伊丽莎白的先攻值是 1D20=[7]=7
```

见 [角色卡与检定 - 先攻检定](./character-card.md#先攻检定-先攻检定)。

## 相关

- 入表后即可开始战斗轮：[战斗轮](./battle.md)。
- `.先攻` 与 `.先攻检定` 是两个命令：前者查看列表，后者掷骰入表。
