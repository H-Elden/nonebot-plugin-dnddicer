# 掷骰基础

掷骰是骰娘最核心的能力：一条 `.r` 命令加一段**掷骰表达式**，就能掷出任意组合的骰子。

本页面讲解最基础的掷骰命令，其中示例来自[示例团](./cast.md#这支小队)出发前在旅店里的试骰。

优势/劣势、修饰符、连掷、暗骰等进阶掷法见[掷骰进阶](./roll-advanced.md)。

## 命令格式

```
.r[标志][表达式] [原因]
```

| 部分 | 必填 | 默认 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| 标志 | 否 | 直接全部完整显示信息，可省略空格 | `h` 暗骰 / `s` 只显数值 / `N#` 连掷 | `.rhd`、`.rs2d6`、`.r3#2d6` |
| 表达式 | 否 | 掷骰默认骰 | 要掷的骰子与运算，可省略空格 | `2d6+3`、`d+5`、`(d6+2)*2` |
| 原因 | 否 | 无原因 | 原因会写进结果文案。空格可省略，但为方便阅读，**建议以空格隔开** | `.rd+2 力量检定` |

标志的完整用法见[掷骰进阶](./roll-advanced.md)；有角色卡时更推荐用检定点命令（`.力量检定`），骰娘会自动代入卡上的加值。

### 边界情况

此处列出了一些省略一个或者多个参数时的边界情况，熟悉命令的玩家可以更加简单的发送简短命令。

| 掷骰命令 | 说明 |
| --- | --- |
| `.r` | 投掷默认骰（默认 D20） |
| `.rs` / `.rsd` | 投掷默认骰并简短回复 |
| `.rh` / `.rhd` | 暗投一个默认骰 |
| `.r2#` / `.r2#d` | 独立投掷两个默认骰 |
| `.r2` | 固定投掷结果为 2 |
| `.rd优势` | 投掷两颗默认骰取高 |
| `.r攻击` | 以攻击作为原因，投掷一个默认骰 |
| `.r优势` | ❌这是一条错误指令，你并不能这么做 |
| `.rd6+2 3个地精攻击` | 以“3个地精攻击”为原因，掷骰 `1D6+2` |
| `.rd6+23个地精攻击` | ❌以“个地精攻击”为原因，掷骰 `1D6+23` |

最后一个例子中，用户的掷骰原因与前面表达式没有以空格隔开，导致数字粘连，引发了意料之外的掷骰结果。因此，**建议原因与前方表达式始终以空格隔开。**

## 骰子怎么写

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| `NdM` | N 个 M 面骰 | `2d6`、`3d8` |
| 数字 | 固定数值，参与四则运算 | `+3`、`-2`、`*2`、`/2` |
| 裸 `d` / `2d` | 省略面数 = 掷**默认骰面**（默认 D20，见下节） | `.rd`、`.r2d+1` |
| `+ - * / ( )` | 四则运算与括号 | `(d6+2)*2` |

两处能省就省：**不写骰数默认 1 颗**（`d6` 就是 `1d6`）；**不写面数按默认骰面**（`d` 默认就是 D20，所以 `.rd+5` 等价于 D20+5）。大小写不敏感（`2D6` 与 `2d6` 等价）。

::: chat
老猫 | .r3d8
屠龙骰 | 塔莉 的掷骰结果为 3D8=[3+5+1]=9
阿茶 | .rd+5
屠龙骰 | 薇拉 的掷骰结果为 1D20+5=[10]+5=15
:::

## 结果怎么读

掷骰回复由四段拼成：

::: chat
阿茶 | .r2d6+3
屠龙骰 | 薇拉 的掷骰结果为 2D6+3=[5+2]+3=10
:::

`2D6+3` 是表达式原文；`[5+2]` 是**逐骰过程**（每颗骰子的出目）；`+3` 是固定加值；末尾 `=10` 是合计。想只看合计时，用 `s` 标志（见[掷骰进阶](./roll-advanced.md)）。

## 运算与括号

运算按普通四则运算优先级，除法使用**向下取整**（如 `7/2` 得 3），括号内的骰子照常逐颗掷出。

::: chat
小满 | .r(d6+2)*2
屠龙骰 | 洛恩 的掷骰结果为 (1D6+2)*2=([4]+2)*2=12
小满 | .r2d6-1
屠龙骰 | 洛恩 的掷骰结果为 2D6-1=[3+4]-1=6
:::

## 默认骰面

省略面数的 `d` / `2d` 使用**默认骰面**：未配置时默认 **D20**。群主可以用 `.dset` 把本群默认骰面改成别的（如 D12），改动只影响本群：

::: chat
老猫 | .rd
屠龙骰 | 塔莉 的掷骰结果为 1D20=[17]=17
老猫 | .r2d+1
屠龙骰 | 塔莉 的掷骰结果为 2D20+1=[9+14]+1=24
:::

> `.dset` 的用法与权限见[群管理与 FAQ](./faq.md#群默认骰面)。

## 大成功与大失败

无论如何，大成功/大失败**只由 D20 产生**：表达式里掷了 D20，且**保留下来**的出目为 20，则追加「好耶！大成功!」；出目为 1，则追加「哇哦！大失败!」。其余骰子掷出多大的数字都不播报：

::: chat
阿岩 | .rd+4
屠龙骰 | 布鲁姆 的掷骰结果为 1D20+4=[20]+4=24 好耶！大成功!
老猫 | .r2d6
屠龙骰 | 塔莉 的掷骰结果为 2D6=[6+6]=12

注：2D6 掷出 12 也不会播报：判定只看 D20，且只看被保留的骰子（优势/劣势里被丢掉的那颗不计）。
:::

::: chat
小满 | .rd
屠龙骰 | 洛恩 的掷骰结果为 1D20=[1]=1 哇哦！大失败!
:::

## 常见错误

空格之后的内容会被当成**原因**，而不是表达式的一部分：

::: chat
阿茶 | .r3d8
屠龙骰 | 薇拉 的掷骰结果为 3D8=[2+6+4]=12

注：正确：一次掷 3 颗 D8。

阿茶 | .r3d 8
屠龙骰 | 薇拉 为 8 进行的掷骰结果为 3D20=[11+3+19]=33

注：错误：`3d 8` 被拆成表达式 `3d`（3 颗默认骰）+ 原因「8」，结果掷的是 3D20，注意文案里的「为 8 进行」。
:::

> 反过来，如果你**确实**想写原因，表达式后空一格再写即可（`.rd+2 力量检定`）；写法示例见[掷骰进阶](./roll-advanced.md#带原因的掷骰)。

## 相关命令

| 命令 | 用法 | 说明 |
| --- | --- | --- |
| `.r` | `.r[标志][表达式] [原因]` | 掷骰；表达式支持四则运算与括号 |
| `.rd` / `.r2d` | 省略面数 | 按默认骰面掷（默认 D20，群可用 `.dset` 改） |
| `.dset` | `.dset d12` | 调整本群默认骰面（群主/管理员，见[群管理与 FAQ](./faq.md#群默认骰面)） |
