## [0.4.1] - 2026-09-26

### 新增

- **规则查询速查子命令**（推荐优先使用）：`.查询法术` / `.查询怪物` / `.查询物品` / `.查询专长` / `.查询职业` / `.查询起源` / `.查询术语` / `.查询单位`，按名称精确查找对应类型词条；候选带环阶、CR、稀有度与出处缩写，命中唯一时直接出词条正文。
- **骰主命令 `.查询索引`**（仅骰主私聊，`.帮助` 不显示）：查看速查索引状态（构建时间与各类条目数）或按类手动刷新（如 `.查询索引 刷新 法术`）；速查索引约 3500 条，插件启动时后台构建。

### 变更

- **规则查询输出升级**：词条正文按《5e不全书》站点样式渲染（标签语义配色、2024 怪物数据卡规格、关键词高亮、中文避头尾折行）。
- **候选展示调整**：唯一候选直接展示词条（不再回数字）；只有一页结果时不显示页码与翻页提示；专长等候选与正文补齐分类信息。

### 文档

- 《规则查询》新增「速查子命令」章节（含推荐口径与通用检索的局限说明）；《命令总览》《快速开始》《群管理与 FAQ》与 README 同步。
- **文档站新增国内镜像**：<https://dnddicer.netlify.app/>（GitHub Pages 访问不畅时可直接使用，内容随发版同步）。

## [0.4.0] - 2026-09-26

### 新增

- **规则查询**（`.查询` / `.搜索`，别名 `.检索`；需骰主开启）：
    - 两种检索：`.查询` 按词条名称匹配、`.搜索` 做全文检索；多关键词用空格分隔表示同时满足、`|` 表示任一满足。
    - 命中多条时先列候选（回数字看词条、`+` / `-` 翻页，60 秒内只认发起者本人）。
    - 内容来自《5e不全书》，只用于当次回复与短时内存缓存，不落盘、不随插件分发。
- **规则查询图片模式**：骰主开启总开关并安装可选依赖（`[render]`）后，`.查询图片 on` 可让本处的词条正文以图片返回（仿《5e不全书》的卡片样式）；渲染失败或未装依赖时自动回退为文字。
- **查询范围**：`.查询范围` 按群 / 私聊限定本处可查的书目（英文缩写，含 31 本书与 4 个整目录键，默认全部开放）；`.规则书` 列出中文书名与缩写对照（骰主开启图片模式时默认出图）。

### 变更

- **文档站按前置条件重排为四章**：第一章 · 基础操作、第二章 · 玩家进阶、第三章 · DM 进阶、第四章 · 最佳实践；HP 与代掷内容按「无需角色卡 / 已绑定角色卡 / DM」分层重排，旧的《HP 与长休》《DM 实战指南》地址失效，请从侧栏进入新页。
- **大成功/大失败播报另起一行**：`.r` / `.rh` 的 `N#` 连掷按次汇总、检定点的单轮与连掷播报都单独成行，不再与结果末行相连。
- **修饰符回显加括号**：带比较符的修饰符（`R` / `X` / `XO` / `CS`）在回复里以括号包裹（如 `2D6(R=1)+3`），与结果分隔的 `=` 区分开；`K` / `KL` / `M` / `P` / `F` 保持原样。
- `.bot` 简介与插件描述补充「规则查询」表述。

### 修复

- 查询范围受限时未命中的提示分命令处理：`.查询` 会附一句建议改用 `.搜索` 做全文检索；`.搜索` 自身同受范围约束，只说明范围、不再建议改用自己。

### 文档

- 使用文档站新增《规则查询》《自建查询服务》两页；《命令总览》《快速开始》《群管理与 FAQ》同步规则查询的命令、配置与书目缩写表。

## [0.3.0] - 2026-09-25

### 新增

- **自定义武器与攻击系统**：
    - 角色卡新增 `$武器$` 段（`名称+命中加值,伤害表达式+类型`，多项用 `/` 分隔；名称尾加 `x` 表示不可攻击检定的纯伤害法术），并新增 `$种族$` / `$职业$` / `$子职$` 段（游荡者的偷袭骰按等级自动计算）。
    - `.武器名攻击` / `.武器名命中`：用卡上该武器的命中加值掷攻击检定，支持 优势/劣势、`N#` 连掷、`±` 临时加值与 `@玩家` 代掷；天然 20 提示重击、天然 1 提示必失。
    - `.武器名伤害`：掷该武器的伤害并报出伤害类型，`副手` / `重击` / `偷袭` 后缀可组合、可加 `±` 临时加值。
    - `.设置武器` / `.删除武器`：便捷维护卡上武器（列表查看、同名覆盖、多名称删除）。
- **`.hp` 伤害位置支持武器写法**：
    - `.hp 骷髅a易伤 -战锤重击伤害+1d4` 一条命令完成掷伤与扣血；回复先报「谁用【哪件武器】造成了多少伤害」，再列出各目标的扣血读数（单目标报实际结算值、含抗性/易伤折算；一发多目标报掷出的原始值）。
    - DM 代发不在场的玩家：尾部括号指定武器来源（`.hp 骷髅b -火焰箭伤害（洛恩）` 或 `（@玩家）`，角色名支持模糊匹配）。

### 变更

- **属性攻击命令退役（破坏性变更）**：`.力量攻击` 等六属性攻击命令整体移除，攻击检定统一走角色卡 `$武器$` 项；`$熟练$` 与 `$额外加值$` 不再接受攻击条目（含全局「攻击」键），攻击加值一律折算进武器项。**旧角色卡需重新登记**：新版本读取旧卡会报错，发送 `.角色卡清除` 后重录即可。
- `.bot` 简介与插件描述补充「自定义武器与攻击」表述。

### 文档

- 使用文档站新增《武器与攻击》页，全站手册同步（检定与豁免、角色卡与属性、DM 实战指南、HP 与长休、命令总览与 FAQ 等）；示例团四张角色卡补齐武器与职业段，战斗示例统一到武器流程。

## [0.2.2] - 2026-09-24

### 变更

- **定位表述统一**：`.bot` 插件简介与插件元数据描述更新为「功能最全面、体验最好的 DND 骰娘」口径，清理旧的对齐式表述（掷骰引擎上游来源的致谢仅保留在许可位置）。

### 修复

- **掷骰说明文字按四则运算还原**：修复算式说明里常量复合子表达式与一元负号的错位——如 `.rd6+2*2` 旧显示为 `1D6+2*2=[4]*2+4=8`（乘号挪用了骰块）、`-1d6+3` 丢负号、`12/(1+2)`、`3*d6` 同类错显；说明文字现与表达式结构一一对应，骰子结果与取骰规则不变。
- **私聊下的群聊限定命令不再静默**：角色卡、检定/豁免/攻击点、HP、先攻与战斗轮等按群归属的命令在私聊中发送时，会如常收到「该指令仅在群聊中可用。」提示（此前部分命令族没有回应）。
- **`.bot` 私聊回应文案修正**：不再写「私聊可直接使用本插件的全部功能」，改为如实说明私聊可用范围（掷骰、属性生成、`.帮助` 等可用；角色卡、检定、HP、先攻与战斗轮、群配置等仅限群聊）。

### 文档

- **使用文档站上线**：手册式 15 页（快速开始、三章教程、参考组、更新日志），配固定示例团的真实取证示例；推 `v*` 标签时自动构建并部署到 GitHub Pages。
- README 改为手册式目录并挂文档站入口；全站正文统一骰记法（D20 等）与命令示例的最简写法。

## [0.2.1] - 2026-09-22

### 新增

- **@ 提及目标（DM 代操作）**：`.hp`、`.npc`、`.ri`、`.init del|first|swap`、`.回合`、`.角色卡`（可查看他人整卡，记录/清除仍仅限本人）、`.状态`、`.长休` 以及各检定点命令（含 `.先攻检定`）均可直接 @ 某位玩家，作用于其角色卡或先攻条目；游离的 @ 会被拦截并提示，不再静默按自己处理（此前 `.hp @玩家 -d4` 会误扣自己血量）。
- **玩家名称显示统一**：凡是需要显示玩家名的场景（`.r`/`.rh`、`.dnd`/`.dndx`、检定反馈、`.hp`、`.ri` 入表名等）统一按「角色卡名 → 群名片 → QQ 昵称 → 未知玩家（QQ号）」回退，末端兜底附带 QQ 号，便于 DM 定位是谁。

### 变更

- `.hp del` / `.hp clr` 语义修订为**仅作用于 NPC 血量**：`del` 删除指定 NPC（支持 `/` 分隔多名称）、`clr` 清空本群全部 NPC 血量（含跨战斗保持的）；无对象时只提示用法，目标解析到玩家角色卡时改为引导使用 `.角色卡清除`，不再直接删除整张角色卡。

### 修复

- 优势/劣势别名粘连：`.rd劣势20+6` 这类面数错序写法不再被静默改写成错误骰式，改为报错引导；`K`/`KL` 取点超量时给出报错而非错误结果。
- `.hp` 目标匹配改为完全匹配优先（与 `.init` 一致）：修复「地精」与「熊精」并存时 `.hp 地精` 命中错对象、`.hp del 地精` 删不掉的问题。
- 伤害/治疗结算最低为 0：修复伤害掷出负值后经抗性/易伤计算反而变成回血的问题；治疗为 0 时不再触发昏迷唤醒。
- `.hp` 目标未命中时补充引导提示（新建 NPC 需先加入先攻表才能设置 HP）；回满提示中的命令独立成行，便于直接复制。

### 文档

- README 命令表与使用文档（角色卡 / HP 管理 / 先攻列表 / 战斗轮 / 快速开始）补充 @ 用法与示例。

## [0.2.0] - 2026-09-21

### 新增

- **NPC / 怪物血量**：`.hp` 目标搜索扩展为三层（玩家角色卡 → NPC 血量 → 先攻表，NPC 经先攻表按需建立记录）；先攻列表与 `.hp list` 显示 NPC 血量，`.hp del` 支持指定对象；`.init clr` / `.br` 清理未设最大值的临时血量，`.init del` 连带删除对应记录。
- **NPC 血量自动回满与跨战斗保持**：同名 NPC 以新条目加入先攻表时自动回满并给出提示（同一场战斗内重掷不触发）；`.npc 持久` / `.npc 临时` 控制血量是否跨战斗保持。
- **`.dndx` 属性名绑定掷点**：4D6K3 掷点后将六项数值按固定顺序绑定力量/敏捷/体质/智力/感知/魅力（不降序排列，掷出即定配对，可直接抄入角色卡），与 `.dnd` 并存。

### 修复

- `.dnd` 原因参数不再被静默丢弃：首词不是数字时整段视为原因（如 `.dnd 开卡`），分隔符放宽为任意空白。

### 文档

- HP 管理新增「NPC / 怪物血量」章节；先攻列表、战斗轮、FAQ、命令总表与 README 同步。
