## [0.5.0] - 2026-10-27

本版上线角色卡库、休息与资源、网页建卡器等一批功能；角色卡存储、段语法与分隔符有破坏性调整，从 0.4.x 升级请先读「变更」前四条，并用网页建卡器重新建卡。

### 新增

- **休息与资源**：角色卡新增 `$限定资源$` / `$法术$` / `$法术位$` 三段，配套 `.能力` / `.设置能力` / `.删除能力`、`.法术` / `.设置法术` / `.删除法术`、`.法术位`（别名 `.ss`）三族命令；次数、环阶与恢复档全部按卡面记账，不按职业表推算；`.能力` 与 `.法术位` 支持 `@玩家` 或角色名代操作，其余资源命令只作用于本人。
- **休息与施法**：`.生命骰 [数量] [@玩家]` 花生命骰回血，`.短休 [@玩家]` 恢复短休类资源与契约位（不自动花生命骰），`.长休 [@玩家]` 回满 HP、清除死亡标记并恢复长休类资源与全部法术位；`.施法`（别名 `.cast`）按卡面环阶施法，支持绝对升环（`.施法 火球术4环`）、相对升环（`.施法 火球术+1环`）与纯环阶（`.施法 3`），普通位优先、契约位兜底，戏法不耗位，未准备时附提醒（`.法术 提醒 on/off` 按群开关）。
- **群级规则版本**：`.规则版本 [5e|5r]`（别名 `.rules`）查看或设置本群规则版本，`.规则版本 默认` 清除设置并跟随骰主配置项 `dnddicer_default_rules_version`；生命骰结算、长休生命骰恢复量、击晕结果、施法准备提醒与激励名称按版本区分。
- **死亡豁免闭环**：`.死亡豁免` / `.ds` 在 0 HP 时掷 1d20（≥10 成功、≤9 失败、自然 20 回 1 点 HP、自然 1 记两次失败），3 次成功稳定、3 次失败死亡；`.ds 状态` / `.ds 重置` / `.ds 成功+N` / `.ds 失败+N` 供查看与手动裁决；`.hp` 新增 `击晕` 参数（5e 归 0 且伤势稳定、5r 降到 1 HP），0 HP 受伤自动记失败（重击记两次），单次伤害达到或超过 HP 上限即死。复活可用 `.ds 重置` 后治疗，或直接走一次 `.长休`。
- **角色卡库**：角色卡改为卡库，每人最多 10 张，立绘按卡独立保存；新增 `.角色卡新建 卡名` + 完整卡面、`.角色卡修改 [卡名] 段条目`、`.角色卡改名 旧卡名 新卡名`、`.角色卡列表`、`.角色卡绑定` / `.角色卡解绑`、`.角色卡清除 卡名 确认`、`.角色卡导出`；群聊新建自动绑定本群、群内只改当前绑定卡，私聊按卡名选中（只有一张时可省略）。
- **私聊建卡与查看**：`.角色卡` / `.角色卡导出` / `.状态` 可在私聊按卡名使用；`.角色卡绑定` 私聊写 `卡名 群号`；`.角色卡清除` 仅能删除未绑定的卡（连同立绘），末尾需照抄「确认」；卡名最多 20 字符，不能含空格、`$` 或 `@`。
- **无卡生命值与死亡豁免**：`.hp` 与 `.死亡豁免` 不再要求绑定角色卡，没有卡时读写群级 HP 记录（无卡时先发 `.hp 当前/最大` 建立记录）；之后绑定角色卡时以卡面 `$生命值$` 为准、旧记录丢弃；`.hp list` 按有卡玩家、无卡记录、NPC 的顺序列出；`.状态` 与休息类命令仍需角色卡。
- **网页建卡器**：文档站新增建卡器页面，按身份、属性与检定、战斗、特性与专长、法术、装备等分章填写，支持 5e / 5r 切换、职业组合、结构化熟练与半熟练预设、法术豁免 DC 与攻击公式、导入导出、角色卡实时预览与立绘裁切，并直接生成 `.角色卡新建` / `.角色卡修改` 命令；整卡超过 4500 字时自动拆成 `.角色卡新建` 加多条 `.角色卡修改`。
- **角色卡图改版**：卡图改为单页高密度版式，立绘放进左上角方框；新增 `$钱币$` / `$进度$` / `$故事$` / `$种族特性$` / `$职业特性$` / `$魔法物品$` 段，`$武器$` 支持备注、`$法术$` 支持详情；`.角色卡` 在配置项 `dnddicer_card_image_enabled` 开启且渲染可用时出图，否则输出文字卡；`.角色卡导出` 始终输出可复制的文字卡。
- **卡面长说明**：`$故事$` 可多段、最多 1000 字（换行不计）；专长、种族特性、职业特性、限定资源的说明合计 ≤400 字、魔法物品 ≤500 字，多段用 `//` 分段（网页建卡器里每行一段），卡图按段显示并首行缩进。
- **半熟练加值**：新增 `$半熟练$` 段（`范围:取整`，范围 `全部` / `技能` / `力敏体`，取整 `向下` / `向上`，多项用 `;` 分隔），按范围作用于属性检定、技能、先攻与被动察觉；已有熟练或专精时不叠加，卡面技能加值后标「半」。
- **快速记录**：`.激励 [状态|+|-|给予 目标]` 查看、获得、消耗与转赠英雄激励（2014 群称「激励」，2024 群称「英雄激励」）；`.战斗记录 [清|+文本|-序号]` 增删清 `$战斗记录$`（最多 20 条、每条 60 字）；`.钱币 [+20GP-5SP]` 查看五种币值并做紧凑收支，减法不足时自动破币并播报明细。
- **立绘命令**：`.立绘` 不带图即查看（群聊看本群绑定卡、`@玩家` 或角色名看他人，私聊用 `.立绘 [卡名]` 看本人），带图即设置（PNG / JPG / WebP，单张不超过 4 MB，原图直存；群聊只能改本群绑定卡）。
- **配置项**：新增 `dnddicer_default_rules_version`（骰主默认规则版本，默认 2024）与 `dnddicer_card_image_enabled`（角色卡图开关，默认关闭，需安装 `[render]` 可选依赖）。

### 变更

- **破坏性变更：角色卡改存卡库**：角色卡从「每群每人一张」改为卡库模式，旧版按群保存的角色卡不会自动迁移；升级后请用网页建卡器重新建卡，再用 `.角色卡绑定` 绑到跑团群。
- **破坏性变更：角色卡段语法调整**：`$属性值$` / `$豁免$` / `$技能$` 三段退役，属性调整值、豁免与技能加值改由 `$属性$`、等级、`$熟练$` 与 `$额外加值$` 现算；`$特性$` 删除，`$能力$` 改名为 `$限定资源$`，物品的 `[装备]` 标记删除，未知段直接报错；含旧段的卡文本会被拒绝，请用网页建卡器重新生成。
- **破坏性变更：三个命令退役**：`.角色卡记录`、`.角色卡图`、`.角色卡模板` 移除；查看卡统一用 `.角色卡`（按开关出图或文字），需要纯文字时用 `.角色卡导出`，建卡模板改由网页建卡器提供。
- **破坏性变更：角色卡文本分隔符统一**：卡片文本改为段内条目一律用半角 `;`、字段用 `|`、键值用 `:`（如 `$武器$ 长剑+8|1d8+5挥砍; 匕首+5|1d4+2穿刺`、`$法术$ 火球术:3*|时间:1动作|距离:150尺`），全角标点不再当分隔符；旧格式文本（逗号分隔、全角标点）会被拒绝，需按新格式改写或用网页建卡器重新填写。
- **无卡玩家不再隐式建卡**：`.hp` 对未绑定角色卡的玩家不再创建空白卡，改为提示先绑定；生命值与死亡豁免改走群级记录，绑定卡后以卡面为准。
- **卡面派生值改为现算**：`$战斗$` 只写 AC 与速度，先攻、被动察觉由骰娘按属性、熟练与额外加值计算；`$进度$` 只存当前经验，下一级经验按等级表计算。卡文本里写过的 `先攻` / `被动察觉` 键会被忽略。
- **命令格式记号统一**：全站与骰娘文案统一为 `[]` 可省略、`|` 表示二选一、不加括号的中文为占位词，不再使用尖括号；`.hp` 的「对象」统一称「目标」，查询范围的「缩写」统一称「书目缩写」，`.能力` 的用法摊平为 `[名称] [±N]`。
- **一卡一群提醒**：同一张卡绑定到第二个群时照常绑定并在回复末尾提醒数据冲突（生命值、激励、死亡豁免、法术位随卡保存、多个群共用）；绑回已绑过的群不重复提醒。
- **`.bot` 文案精简**：插件简介改为短句，关闭与未开启的提示去掉冗长括注，群聊用法行只在群聊显示，私聊只回状态与文档链接。
- **钱币与资源显示**：`.钱币` 结算只列出数值变化的币种；限定资源恢复档显式写「回满」，卡图同步展示。

### 修复

- **卡片字体栈失效**：模板里的 CSS 被 HTML 转义，`font-family` 的字体名全部失配，表现为汉字用日文字形、同一行中英文基线不一致；改为原样输出样式与字体规则，配置项 `dnddicer_query_image_font_family` 重新生效。
- **抗性 / 易伤被双重折算**：易伤 10 点伤害此前按扣 20 后再翻倍判定即死，改为按实际扣除的伤害判定。
- **HP 状态行落后一步**：濒死计数在 HP 状态行之后才更新，旧输出会显示「濒死(成功0 失败0)」却同时报失败 +1；现在状态行同步刷新。
- **直接设置 0 HP 的濒死显示**：`.hp 0` / `.hp 0/30` 现在同步昏迷与濒死状态，与 `.ds` 判定一致；纯损失记录也能用 `.hp` 与 `.hp list` 查看。
- **`$额外加值$` 仅优劣势条目丢失**：`隐匿:优势` 这类没有数值的条目在 `.角色卡` 查看后再记录会丢失，改为按固定顺序统一回写。
- **建卡器分隔符提示**：背景外貌、专长、特性、限定资源、魔法物品等自由文本含 `;` 时给出明确提示，不再只报「背景条目不完整」。

## [0.4.3] - 2026-09-30

### 新增

- **武器名模糊匹配**：除 `设置武器` 之外，`.X攻击` / `.X命中` / `.X伤害`、`.hp` 等命令的武器均支持模糊匹配，即精确优先、子串匹配。
- **一条命令结算多件武器**：`.刺剑伤害、匕首副手伤害`（分隔符 `、` / `，` / `/` 均可），逐件掷伤后给出一行合计；伤害类型不同时按类型分组报出，后缀与临时加值各项独立。多武器攻击同样支持（`.刺剑攻击优势、匕首攻击+2`），`.hp` 的伤害位置也已接入。
- **`.master <消息>` 反馈骰主**：群聊与私聊均支持，由骰娘私聊转达给骰主；单条限 200 字、同一人 60 秒限一条。
- **新增四个配置项**：
    - `dnddicer_master_qq`：骰主 QQ 号，`.master` 的收件人
    - `dnddicer_master_contact`：只在 `.help 联系` 展示
    - `dnddicer_master_group`：只在 `.help 联系` 展示
    - `dnddicer_query_image_default`：查询默认展示形态

### 变更

- **`.help` 帮助体系重构**：无参数看总览，`.help 命令` 给七组目录，`.help <组名>` 给组清单，`.help <命令>` 给「用法 + 缩进说明」的简版详情；另有 `.help 链接` / `.help 关于` / `.help 骰主` / `.help 联系` 四个入口。长帮助不再刷屏。
- **帮助详情给文档深链**：详情末尾的链接行指向该命令对应的文档页（不再一律指向站点首页）；`.help 链接 on/off` 按处开关，群聊默认关、私聊默认开。
- **`.dnd` / `.dndx` 次数上限由 10 提到 20**：次数越界（含 0 与负数）不再静默按 1 次掷点，改为提示并拒绝执行。
- **`.角色卡模板` 提示更新**：熟练段补充「六属性 / 技能 / 豁免条目 / 先攻」，并精简额外加值两行。

### 修复

- **速查条目拿错卡、丢正文**：修 `.查询法术 火墙术` 返回排在它前面的生物卡、召唤类法术丢失法术正文等问题（改为判断标题是否落在数据卡内）。
- **图片卡片排版**：修正文上下大片空白、句中折行与孤字行，以及文字模式跟着图片一起折行（消息里多出换行）三个问题。
- **图片中英文错位**：卡片字体栈改为中文优先且中西文同源，服务器上不再中英各用一套字体、中文也不再回退成日文字形；可用新增配置项 `dnddicer_query_image_font_family` 指定字体。

### 文档

- README 顶部新增 logo 头图，简介区新增交流反馈 QQ 群入口。
- 《武器与攻击》新增「两把武器一起结算（多武器写法）」与「武器名支持模糊匹配」两节；《群管理与 FAQ》新增「联系骰主」小节；《快速开始》《命令总览》与 README 同步新帮助入口、`.master` 与配置项。

## [0.4.0] - 2026-09-26

### 新增

- **规则查询**（`.查询` / `.搜索`，别名 `.检索`；需骰主开启）：
    - 两种检索：`.查询` 按词条名称匹配、`.搜索` 做全文检索；多关键词用空格分隔表示同时满足、`|` 表示任一满足。
    - 命中多条时先列候选（回数字看词条、`+` / `-` 翻页，60 秒内只认发起者本人）。
    - 内容来自《5e不全书》，只用于当次回复与短时内存缓存，不落盘、不随插件分发。
