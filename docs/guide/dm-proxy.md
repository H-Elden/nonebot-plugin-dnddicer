# 代掷与代操作（@ 指定玩家）

玩家不在场、手机没电，或者干脆代控一位缺席的朋友：多数带目标的命令都支持用 **@群成员**（下文记作 `@玩家`）指定目标，骰娘**直连该成员在本群的角色卡**，不用替对方报数，也不受同名 NPC 与角色卡改名影响。

- `@` 要写在命令的**目标位置**（表达式右侧 / 目标位），写在别处不生效；
- `@` 的目标需**已在本群建卡**，否则回复真 @ 引导建卡；
- `@` 与名称可以**混写**（分隔符 `;` 或空白，一发 AOE 同时结算玩家与怪物）；
- **游离 @ 会被拦下**：`@` 没写在目标位置时不执行、并回纠正示例，避免静默按发送者自己结算；
- 此类写法**仅限群聊**（私聊没有「本群角色卡」的上下文）。

## 代掷清单（@ 能用在哪些命令）

| 场景 | 写法 | 说明 |
| --- | --- | --- |
| 检定 / 豁免 | `.力量豁免 @玩家`、`.2#隐匿检定优势 @玩家` | 用目标角色的属性 / 熟练 / 加值代入，以其角色名落款 |
| 先攻入表 | `.先攻检定 @玩家`、`.ri+2 @玩家` | 条目名取角色卡名并与该玩家**绑定**：重掷替换、`.回合 @玩家`、HP 解析同步生效 |
| 武器攻击 / 伤害 | `.刺剑攻击 @玩家`、`.刺剑重击伤害 @玩家` | 用目标角色卡上的武器项 |
| HP 结算 / 查看 | `.hp @玩家 -4d6`、`.hp @玩家易伤 -d8`、`.hp @玩家` | 结算或查看摘要；多名可连写 |
| 长休 | `.长休 @玩家` | 用目标角色卡完成长休结算 |
| 代发武器伤害 | `.hp 骷髅b -火焰箭伤害（@玩家）` | 伤害来源写 `@玩家`（也可写角色名），见[血量与伤害结算](./dm-settlement.md) |
| 定位先攻条目 | `.init del @玩家`、`.init first @玩家`、`.init swap @玩家/兽人`、`.回合 @玩家` | 按归属定位，改名后仍有效 |
| 查看角色卡 / 状态 | `.角色卡 @玩家`、`.状态 @玩家` | 查看对任何人开放；**记录 / 清除仅限本人** |

## 示例

先攻入表：条目名取角色卡名（洛恩），并与该玩家绑定：

::: chat
白鸦 | .ri+2 @小满
屠龙骰 | 洛恩的先攻值是 1D20+2=[7]+2=9
:::

检定代入：玩家不在场时替他掷豁免，说明行列出的都是**他那张卡**的加值：

::: chat
白鸦 | .智力豁免 @小满
屠龙骰 | 洛恩进行【智力豁免】：
熟练加值:3 智力调整值:4
1D20+4+3=[13]+4+3=20
:::

查看他人状态：

::: chat
白鸦 | .状态 @小满
屠龙骰 | 洛恩: HP:37/37
生命骰:5/5 D6
:::

回合定位：按归属跳转，不受改名与同名歧义影响：

::: chat
白鸦 | .回合 @小满
屠龙骰 | 现在是洛恩的回合。请玩家@小满开始行动。
:::

游离 @ 会被拦下（提示不执行，避免静默按发送者自己结算）：

::: chat
白鸦 | .hp -d6 @小满
屠龙骰 | 未执行：目标请写在目标位置，例如 .hp @小明 -d4
:::

@ 的玩家不在先攻表时，会给出明确提示：

::: chat
白鸦 | .init del @小满
屠龙骰 | @小满 不在先攻列表中
:::

- `.ri 3#@玩家` 这类**批量与 @ 混写**会被拦下（批量会派生 a/b/c 后缀，与「条目绑定玩家」的语义冲突），逐个 @ 或直接写条目名即可；
- 与「直接写名称」入表的区别（名称按字面、不绑定玩家）见[先攻列表](./initiative.md)。
