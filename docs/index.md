# 屠龙骰（DNDDicer）使用文档

屠龙骰是专精 **DND5e / DND5r** 跑团的 [NoneBot2](https://nonebot.dev/) 骰娘插件（OneBot V11 适配器），为 QQ 群跑团提供一站式支持：掷骰表达式、角色卡与检定点命令、HP 管理、先攻列表与战斗轮。命令手感对齐 [nonebot-dicepp](https://github.com/pear-studio/nonebot-dicepp)（梨骰）。

> **版本**：v0.2.1。规则范围：**仅支持 DND5e/5r**。安装与配置见 [快速开始](./guide/quickstart.md)。

## 功能一览

| 功能 | 说明 | 文档 |
| --- | --- | --- |
| 🎲 掷骰表达式 | d20/优势劣势/保留最高/重掷/爆炸骰/连掷/暗骰/原因，仅 d20 有大成功/大失败播报 | [掷骰语法](./guide/roll-syntax.md) |
| 📋 角色卡与检定 | `$…$` 模板建卡；`.力量检定` `.敏捷豁免` `.敏捷攻击` 点命令自动代入调整值/熟练/加值 | [角色卡与检定](./guide/character-card.md) |
| 🎯 属性生成 | `.dnd` 4D6K3 掷点（附合计与降序）；`.dndx` 绑定属性名不排序 | [属性生成](./guide/attributes.md) |
| ❤️ HP 管理 | `.hp` 记录/伤害/治疗/临时 HP/列表（含 NPC/怪物血量与跨战斗保持）；`.长休` 一键结算 | [HP 管理](./guide/hp-rest.md) |
| ⚔️ 先攻列表 | `.ri` 掷先攻入表、`.init/.先攻` 查看与删除/提前/交换；`.先攻检定` 自动联动 | [先攻列表](./guide/initiative.md) |
| 🔄 战斗轮 | `.br` 开局，`.回合/.轮次/.ed` 推进（`.回合±n` 可连续跳转），轮到玩家自动 @ 提醒 | [战斗轮](./guide/battle.md) |
| ⚙️ 群管理 | `.dset` 群默认骰面；`.bot` 群聊服务开关（白名单）与常见问题 | [群管理与 FAQ](./guide/faq.md) |

## 名称显示规则

全插件的玩家名称显示统一按一条回退链取值——所有需要显示玩家名称的地方（掷骰落款、
检定/豁免/攻击反馈、`.dnd` 属性生成、HP 相关反馈与列表、先攻入表名等）共用：

**角色名（`$姓名$`）→ 群名片 → QQ 昵称 → 「未知玩家（QQ号）」**

即优先取角色卡上的姓名；没有卡名时取群名片，其次 QQ 昵称；都取不到时显示
`未知玩家（123456789）` 便于定位到具体成员。自己触发的命令取消息自带的名称字段
（零额外查询）；显示他人名称时才查询群成员信息。先攻列表里的 NPC 名称与 NPC 血量
条目名由使用者指定，不参与该回退链。

## @ 提及目标（DM 代操作）

多数带目标的命令支持用 **@群成员**（下文记作 `@玩家`）指定目标——**直连该成员在本群
的角色卡**，不受同名 NPC、角色卡改名的歧义影响；@ 与名称可混写（分隔符 `;` 或空白）：

| 场景 | 写法 |
| --- | --- |
| 代结算 HP | `.hp @玩家 -4d6`、`.hp @玩家;地精 -d4`（AOE 混写）、`.hp @玩家易伤 -d8`、`.hp @玩家`（查看）、`.hp @玩家 @玩家2` |
| 代长休 | `.长休 @玩家` |
| 代掷先攻 | `.ri+3 @玩家`（条目名取角色卡名并与该玩家绑定，重掷替换、回合提醒与 `.hp` 解析同步生效） |
| 按玩家定位条目 | `.init del @玩家`、`.init first @玩家`、`.init swap @玩家/兽人`、`.回合 @玩家`（改名后仍有效） |
| 查看他人角色卡 / 状态 | `.角色卡 @玩家`（或 `.角色卡 角色名`）、`.状态 @玩家`（**查看**对任何人开放；**记录/清除仅限本人**） |
| 代掷检定 | `.力量豁免 @玩家`、`.2#敏捷攻击优势 @玩家`、`.先攻检定 @玩家`（以该玩家为归属入表） |

约定：

- @ 目标需该成员**已在本群建立角色卡**，否则用真 @ 回复并引导建卡
  （`.角色卡记录 建卡后再试`）；
- `@机器人自身` 不作为目标（`.hp -d4` 仍按发送者自己结算）；
- 游离 @（未写在目标位置，如 `.hp -4d6 @玩家`、`@玩家 .hp -4d6`）**不执行**并回
  纠正示例，避免误结算到发送者自己；`.ri` 的提示为「目标请写在表达式右侧」；
- `.ri 3#@玩家` 不支持批量写法（提示直接写条目名称）；`.hp del/clr` 与 `.npc` 是
  NPC 专用命令，@ 到玩家会提示不适用（移除玩家先攻条目用 `.init del`）。

## 命令总表

### 掷骰

| 命令 | 说明 |
| --- | --- |
| `.r [N#][hs][表达式] [原因]` | 掷骰表达式（`#` 连掷 1~10、`h` 暗骰、`s` 只显数值） |
| `.rh [表达式] [原因]` | 暗骰（群内提示、结果私聊） |

### 角色卡与检定（群聊）

| 命令 | 说明 |
| --- | --- |
| `.角色卡模板` | 查看示例卡与提示 |
| `.角色卡记录 <模板>` | 记录/覆盖角色卡 |
| `.角色卡` / `.角色卡清除` | 查看 / 删除角色卡 |
| `.角色卡 @玩家` / `.角色卡 角色名` | 查看他人整卡（任何人可查看；记录/清除仅限本人） |
| `.状态` / `.状态 @玩家` | 查看自己 / 他人的 HP 与生命骰摘要 |
| `.xx检定`（属性/技能/先攻） | 如 `.力量检定`、`.2#察觉检定+1` |
| `.xx豁免` / `.xx攻击` | 如 `.体质豁免+d4`、`.敏捷攻击优势` |
| `.xx检定/豁免/攻击 … @玩家` | 表达式右侧加 @ 代掷（用目标角色的属性/熟练/加值） |
| `.先攻检定` / `.先攻检定 @玩家` | 掷先攻并自动写入本群先攻列表（@ 形式以该玩家为归属入表） |

### 属性生成（群聊/私聊）

| 命令 | 说明 |
| --- | --- |
| `.dnd [次数] [原因]` | 4D6K3 掷点生成六项属性（降序、自行分配） |
| `.dndx [次数] [原因]` | 4D6K3 掷点并绑定属性名（不排序，可直接抄入角色卡） |

### HP 与长休（群聊）

| 命令 | 说明 |
| --- | --- |
| `.hp [对象] 20/30 (5)` | 设置自己/队友/NPC HP（含临时 HP） |
| `.hp [对象] -10` / `+2d6` | 伤害 / 治疗（支持掷骰表达式与临时 HP） |
| `.hp @玩家 …` / `.hp @玩家` | 对 @ 的玩家角色卡结算 / 查看（可与名称混写，见 [@ 提及目标](#-提及目标dm-代操作)） |
| `.hp` / `.hp list` | 查看自己 / 本群列表（PC + NPC） |
| `.hp del 名称` / `.hp clr` | 删除单个 / 清空全部 NPC 血量记录（玩家角色卡请用 `.角色卡清除`） |
| `.npc 持久/临时 名称` | NPC 血量跨战斗保持 / 恢复默认（同名 NPC 新入先攻表默认自动回满） |
| `.长休` / `.长休 @玩家` | 长休结算（回满 HP、清临时 HP、回复一半生命骰）；@ 形式代不在场的玩家收尾 |

### 先攻与战斗轮（群聊）

| 命令 | 说明 |
| --- | --- |
| `.ri[修正] [名称/…]` | 掷先攻入表（`.ri20 地精` 固定值、`3#` 批量） |
| `.ri+3 @玩家` | 代不在场的玩家掷先攻（条目名取角色卡名并与该玩家绑定） |
| `.init` / `.先攻` | 查看先攻列表（`del/clr/first/swap` 子指令） |
| `.init del/first/swap @玩家` | 子指令按玩家归属定位条目（改名后仍有效） |
| `.br` / `.战斗轮` | 新建战斗轮（清空先攻表） |
| `.回合` / `.轮次` | 查看/跳转当前回合与轮次（`.回合+2` 连续推进） |
| `.回合 @玩家` | 跳转到该玩家的条目（不受改名/同名歧义影响） |
| `.ed` / `.结束` | 结束当前回合并自动推进 |

### 群管理（群聊）

| 命令 | 说明 |
| --- | --- |
| `.dset [表达式]` | 设置/查看群默认骰面（群主/管理员） |
| `.bot [on/off]` | 插件信息与群聊服务开关（群主/管理员，需 @） |

### 帮助

| 命令 | 说明 |
| --- | --- |
| `.帮助` / `.help` | 命令总览 |
| `.help <命令>` | 指定命令的详细用法（如 `.help r`、`.帮助 战斗轮`） |
