——提示（记录时请仅复制上方模板段并修改）——
属性段六个数值依次对应: 力量/敏捷/体质/智力/感知/魅力
熟练段 = 六属性/技能/豁免条目/先攻
额外加值段键 = 六属性/技能/豁免条目/豁免（作用于全部豁免）
额外加值取值 = 可选 优势/劣势 ±掷骰表达式, 如: 隐匿:优势+2
武器段格式 = 名称+命中加值,伤害表达式+类型（多项用 / 分隔），如 匕首+5,1d4+2穿刺
能力段格式 = 名称:当前/上限恢复方式（短休/长休/两者/手动，可加 +N 或 满），多项用 ; 分隔
法术段格式 = 施法属性:属性; 法术名:环阶（0 为戏法，尾部 * 表示今日已准备），用 ; 分隔
法术位段格式 = 环阶:当前/上限（契约魔法写 契约3:2/2），多项用 ; 分隔
