——提示（记录时请仅复制上方模板段并修改）——
属性段六个数值依次对应: 力量/敏捷/体质/智力/感知/魅力
熟练段 = 六属性/技能/豁免条目/先攻，可加护甲/武器/工具/语言分组
额外加值段键 = 六属性/技能/豁免条目/豁免（作用于全部豁免）
额外加值取值 = 可选 优势/劣势 ±掷骰表达式, 如: 隐匿:优势+2
武器段格式 = 名称+命中加值,伤害表达式+类型[,备注]（多项用 / 分隔）
能力段格式 = 名称:当前/上限恢复方式[|说明]（短休/长休/两者/手动，可加 +N 或 满）
法术段格式 = 施法属性:属性; 豁免DC:15; 法术攻击:+7; 法术名:环阶[*][|时间=…,距离=…,专注=是,仪式=否,材料=是,备注=…]
法术位段格式 = 环阶:当前/上限（契约魔法写 契约3:2/2），多项用 ; 分隔
属性值段格式 = 力量:18/+4; 敏捷:12/+1（六项全写，仅展示）
战斗段格式 = AC:18; 先攻:+1; 速度:30; 被动察觉:13
进度段格式 = 经验:6500/14000; 激励:有
豁免 / 技能段格式 = 条目:+加值（技能尾部 * 表示专精），多项用 ; 分隔
专长 / 特性段多项用 / 分隔，可写 名称:说明；特性可写 名称（来源）:说明
物品段格式 = 名称x数量[装备]，多项用 ; 分隔；钱币段格式 = CP:0; SP:8; EP:0; GP:18; PP:0
背景段格式 = 键:值，多项用 ; 分隔；故事段为单行长文本；战斗记录段每项用 ; 分隔
